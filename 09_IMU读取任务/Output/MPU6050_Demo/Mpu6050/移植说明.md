# DMP HAL 移植说明

本次修改位于 mpu读取数据处理 分支的 09_IMU读取任务/Output/MPU6050_Demo 工程.
来源为用户桌面“源码资料/Mpu6050”. 原始桌面资料未修改.

## 文件和改动

- Mpu6050/mpu6050.c: 软件 I2C 读写替换为 HAL_I2C_Mem_Read/Write, 使用 hi2c1. 输入设备地址为 7 位, 在 HAL 接口处左移一次. 通信失败返回非零, 拒绝空指针和零长度.
- Mpu6050/mpu6050.h: 移除 sys.h 和软件 I2C 依赖, 使用 HAL 的标准整数类型.
- Mpu6050/inv_mpu.c: delay_ms 映射 HAL_Delay, get_ms 使用 HAL_GetTick. DMP 初始化逐项检查错误, 返回失败步骤. 欧拉角接口检查空指针, 对 asin 输入限幅.
- Mpu6050/inv_mpu.h: 移除标准外设库 stm32f10x.h, 使用 stm32f1xx_hal.h 和 uint8_t.
- Mpu6050/inv_mpu_dmp_motion_driver.c: 保留 DMP 固件及算法, 恢复 FIFO 数据读取后的时间戳赋值. 时间戳为主机读取时间, 不是传感器精确采样时刻.
- Mpu6050/inv_mpu_dmp_motion_driver.h, dmpKey.h, dmpmap.h: 导入核心接口与固件映射定义.
- MDK-ARM/.eide/eide.yml: 加入 ../Mpu6050 源码目录及头文件目录.
- MDK-ARM/MPU6050_Demo.uvprojx: 增加 MPU6050_DMP 文件组和头文件路径, 兼容 Keil 构建.

原始 GBK 源文件转换为 UTF-8. 没有导入旧 system 或 MPU6050_I2C 软件模拟驱动.
main.c 和 CubeMX 引脚/时钟配置保持原样. 应用层 DMP 调用留待下一次练习.

## 使用约定

1. 现有接线 PB6=SCL, PB7=SDA, AD0 接地, 7 位地址 0x68. CubeMX 的 MX_I2C1_Init 必须先执行.
2. 初始化调用 MPU6050_DMP_Init(), 返回 0 才成功. 返回 1~9 分别为: 芯片初始化, 传感器使能, FIFO 配置, 采样率, 固件装载, 方向配置, 功能使能, FIFO 速率, DMP 启动失败.
3. DEFAULT_MPU_HZ=100, 需要约每 10 ms 读取 FIFO. 不要沿用旧 HAL_Delay(100) 的读取周期. 串口打印可以降低频率. dmp_read_fifo 的 more 非零时继续读, 防止积压.
4. MPU6050_DMP_Get_Data 返回角度单位为度, 参数 pitch/roll/yaw. 返回 0=成功, 1=暂时无数据或读取错误, 2=没有四元数, 3=输出指针为空.
5. 六轴原始值可通过 dmp_read_fifo 的 gyro/accel 参数取得, 量程以当前驱动配置及 mpu_get_gyro_sens/mpu_get_accel_sens 为准. 不要沿用旧程序写死的灵敏度或重新写寄存器覆盖 DMP 配置.
6. 保持启动时静止. 已开启 DMP_GYRO_CAL. 原始 run_self_test 保留为可选接口, 初始化不强制执行自检. 六轴没有磁力计, yaw 无绝对航向基准.
