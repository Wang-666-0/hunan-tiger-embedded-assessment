## 当前配置与使用

CAN1 为 1 Mbps（PA11 RX、PA12 TX），USART1 为 115200、8N1（PA9 TX、PA10 RX）。默认电机 ID1、电压协议；电机使用外部供电，接 CAN1，断开原 CAN1↔CAN2 测试桥接。CAN2 不启动。

1. 在 EIDE 选择 GM6020_FreeRTOS，编译并烧录。配置目标名保留 CAN_FreeRTOS。
2. VOFA 选择 FireWater、115200、8N1，先确认在线通道为1，手动转轴角度变化。
3. 电机内部模式与默认电压协议匹配后，发送 V500 加真实换行试转；V-500 为负给定。
4. V0 或 STOP 加换行撤销请求。没有更新或续期时，三秒后自动撤销给定；K 只续期尚未超时的已启用请求。
5. 要持续测试，可每秒发 K；结束试验先 STOP。

电压教学限幅 ±2000，电流教学限幅 ±1000。参数集中在 App/app_config.h；额外原始帧、硬件采样和栈余量诊断默认关闭，正常功能不依赖调试器。

给定值不是目标转速，工程没有外部速度/位置 PID；零给定不等于机械抱闸。软件测试与编译记录不代替实际电机的接线、设置和执行验证。
