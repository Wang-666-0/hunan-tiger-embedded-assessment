# 摩擦轮受限点动：直接通过N630/VESC控制电机

最新档为JOG_L300_R200_V1：用户请求稍加左电流，左上限300mA、右200mA，时长及保护不变，新增只读WHEEL INFO。现在按[最新测试步骤](左轮0.3A点动与版本核对.md)核对板上版本；本页200mA说明作为此前档位保留。

两只摩擦轮已连接N630/VESC，主控可以直接向CAN2节点70、71发送电流给定，不必先查电机商品型号。此次先验证单轮控制链路；电调保存的极数和传动比尚未等同实物标定，不能据此宣布机械6000 rpm达标。

## 当前固件和边界

使用同一套 `Output/Gimbal_Control` 工程，默认 `APP_FLYWHEEL_JOG_ENABLED=1`，上电选轮状态OFF。只有明确选轮并完成遥控解锁后才能点动。Yaw、Pitch、拨盘正式动力驱动仍未开放，`APP_MOTOR_DRIVERS_IMPLEMENTED=0`。没有电机检测、校准、配置写入、反向或主动制动。

2026-10-13方向修正：用户规定左轮顺时针、右轮逆时针，原正给定两轮均逆时针。新版左70固定负电流、右71固定正电流；峰值幅度仍0.2A、斜率幅度100mA/20ms、最长500ms，不能运行中换向。CH1仍向通道值增大的方向触发，两轮方向由节点配置决定。回中/负向取消、CH5/CH6保护和重新解锁流程不变。实物转向须按[新版步骤](摩擦轮方向复核与波形记录.md)复核。

两轮STATUS1必须在100 ms内、STATUS4在600 ms内。超过绝对2000 ERPM、反馈电机/输入电流绝对值超过1 A或FET温度达到60℃时锁定。这里的电流反馈是滤波值，不能当作瞬时硬件过流保护；负电机温度为无效读数，不作为温度放行依据。

停机发两轮零电流并取消旧发送，失败保持禁止输出、每20 ms重试；这是滑行释放，轮子可能继续惯性旋转。MCU卡死、复位或CAN断开时不能继续发送零电流，现有VESC配置的1000 ms通信超时/零制动电流是最后兜底，不能保证100 ms机械停转。调试时手边须能切断摩擦轮动力。

## 第一步：接回云台板并下载

1. 断动力、轮子停稳后操作。清空发射机构、解除飞行动力；仅为主控、接收机和待测CAN2电调供电。GL60Ⅱ、DM3507和拨盘电调的动力需隔离，不能用“代码没发指令”代替断开其动力。GL上电可能自行进入电机模式。
2. 将用于GL串口的USB转TTL接回云台板USART1；保持先前正确的交叉TX/RX和共地接线。主控串口为115200、8数据位、无校验、1停止位。关闭CubeMars和其他占用同一COM口的软件。
3. 接收机接线和第15项遥控配置不改：CH1回中、CH5 OFF；失联输出CH1=1500、CH5=1000、CH6=1000。
4. 在VS Code打开 `Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace`。App源文件须有16个，尤其包括 `flywheel_jog.c`、`app_diagnostics.c`、`dm_diag.c`、`vesc_diag.c`。已打开的EIDE可能保存旧内存配置；缺文件时App右键添加并保存，再运行“eide: 重新构建”。
5. 按用户指定的VS Code/EIDE+ST-Link流程，在原Gimbal_Control工作区重新构建成功，再Ctrl+Alt+D烧录当前工程。方向修正已写入源码，详见[方向版步骤](摩擦轮方向复核与波形记录.md)。无需另选固件文件或操作选项字节；本次没有代用户烧录。

## 第二步：先验证没有选轮时的保护

1. 先只给逻辑电源，VOFA打开主控COM口，115200 / 8N1、FireWater。遥测为39列，前29列保持原编号。
2. 下标0/4/5分别看CH1/5/6；10应为1。下标33应为0（未选轮）、34为0（给定mA）、35为0（点动不活动）。12动力许可保持0，轮子不会收到点动正电流。
3. 保持CH1中位、CH6高位，CH5做OFF→ON，只演示遥控逻辑解锁；关闭遥控器确认10失效或CH6低位、11/12均为0。恢复遥控后CH1回中、CH5先OFF再ON。此次仍未选轮，不产生点动。
4. 把CH5恢复OFF、CH1中位，再给两只摩擦轮电调上电。等待至少1秒让两轮反馈稳定；静止时29/30应接近0。不能用接收帧总数代替新鲜有效的两轮反馈。

## 第三步：左轮一次点动

所有文本命令为大写，末尾必须带回车或换行。在VOFA发送区选择文本/ASCII发送。串口只由一个程序打开。

1. CH1回中，CH5 OFF，CH6高位。发送 `DIAG OFF`（退出上次参数采集模式），然后 `WHEEL STATUS`。
2. 发送 `WHEEL LEFT`。成功回复 `W|OK|LEFT`；此时仍不运行。`W|ERROR|UNSAFE`表示遥控、停转、反馈、故障或会话条件未满足；不要改保护阈值跳过。切换轮子须先OFF。
3. 收到成功回复后，保持CH1回中、CH5 OFF至少0.5秒，让选择后新的遥控OFF帧进入；再把CH5拨ON。VOFA12应为1，38应为1（点动待触发）。若不是，保持OFF回中并查看故障码。
4. 短暂把CH1推到数值增大的方向，随即回中。活动时35为1，方向版左轮34为0到-200；最长500ms取消，12回0。右轮34为0到+200。符号表示给定方向，实际顺/逆时针按观测视角确认。
5. 如果0.2 A下没有转动，只记录29/30 ERPM、31/32 mA、34给定和36故障码。无感电机可能无法在这么小的电流下起转；不要自行加流或反复长时间尝试。电机抖动、异响、异常发热或任何意外运动时，先CH5 OFF并发送 `WHEEL OFF`；必要时立即切断动力，停稳后再检查。
6. 点动结束发送 `WHEEL OFF`，等待轮子停稳。改测右轮时重复CH1中位、CH5 OFF、`WHEEL RIGHT`、等待新OFF帧、CH5 ON、正向短推步骤。

电脑选轮不会直接启动电机，实际触发仍由原遥控器完成。`STOP`撤权并要求重新解锁，保留选择；`WHEEL OFF`还取消选择。`DIAG ON`会停机并取消选择，然后保持原参数采集协议；进入诊断后重新选轮会被拒绝。

## 状态字段与问题定位

| VOFA下标 | 内容 |
| --- | --- |
| 29 / 30 | 左 / 右电气转速ERPM，不能直接当轮速RPM |
| 31 / 32 | 左 / 右反馈电机电流mA，分辨率100 mA |
| 33 | 选择：0 OFF、1 LEFT、2 RIGHT |
| 34 / 35 | 给定电流mA / 点动活动标志 |
| 36 | 故障位；无故障为0 |
| 37 / 38 | 停机提交待重试 / 可接受下一次正向触发 |

`WHEEL STATUS`返回 `W|STATUS|左ERPM|右ERPM|左mA|右mA|选择|给定mA|活动|故障位|停机待重试|待触发`。缺失反馈时ERPM字段可能是旧值，不能仅凭显示0判断在线；36会包含反馈失效位。两轮反馈未全齐时默认OFF也可能显示故障1，此时不表示已发动力。

| 故障位数值 | 含义 |
| --- | --- |
| 1 | 缺少或过期STATUS1/4 |
| 2 | 被识别的状态帧长度/数据无效 |
| 4 | FET温度达到60℃ |
| 8 | 反馈电流绝对值超过1 A |
| 16 | ERPM绝对值超过2000 |
| 32 | CAN故障代次非零 |
| 64 | 电流给定提交失败 |

多个故障位可以相加。CAN故障代次非零永久拒绝本次上电周期内的非零指令；须先断动力，修复接线/总线故障，再复位主控，并重新验证反馈与遥控。其他反馈故障也不会自动恢复点动：OFF、回中、轮子停稳且反馈健康后才能重新选择和解锁。

先完成左右单轮响应和停机验证，保存VOFA数据。随后再确认实际轮速与ERPM换算、方向以及安全电流，才能开展6000 rpm稳速和噪声测试；此次不驱动拨盘。
