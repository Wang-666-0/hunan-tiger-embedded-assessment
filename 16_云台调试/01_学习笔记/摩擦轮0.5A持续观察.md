# 摩擦轮0.5A持续观察

此页为V1历史步骤。用户最新反馈左轮反向、停止时故障16；当前源码已修正左极性并加入低速滑行调节，请使用[最新V2操作步骤](摩擦轮低速观察与方向修正.md)。

当前源码HOLD_L500_R500_V1，左右电流幅值统一上限0.5A。一次仅选择一只轮子：左70给定0至−500mA，目标顺时针；右71给定0至+500mA，目标逆时针。方向沿用此前用户确认的观察视角。

CH1保持正向请求时持续给定，取消原500ms自动结束；回中、负向、CH5关闭、遥控失联标记或故障仍停止。电流5mA/ms上升，约100ms达到上限。上电不选轮、不启动，停止后仍须新的OFF回中→ON才能再次触发。

这是电流观察模式，尚无机械稳速闭环。两轮反馈新鲜、停转、遥控保护、2000ERPM、1A反馈电流监测、60℃FET及CAN故障保护保留。ERPM绝对值超过2000会锁存故障16，持续按住也会停止给定。0mA是滑行给定，轮子不会立即机械停转。

## 1. VS Code构建和烧录

1. CH1回中、CH5 OFF，发送WHEEL OFF，等轮子停稳后断开电机动力。清空弹丸，保持飞行、云台和拨盘动力隔离。
2. 在原[Gimbal_Control工作区](../Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace)选择Gimbal_Control目标。Ctrl+Shift+P执行“eide: 重新构建”，成功后Ctrl+Alt+D通过现有ST-Link/SWD烧录。
3. 复位后用USART1连接VOFA，115200/8N1，保持CH5 OFF、CH1中位，发送带换行的WHEEL INFO。

预期回复：

```text
W|INFO|HOLD_L500_R500_V1|LEFT_MA|500|RIGHT_MA|500|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|0|ERPM|2000|ENABLED|1|HOLD_TO_RUN|1
```

MS=0及HOLD_TO_RUN=1表示按住运行，没有计时结束；ENABLED=1才开放受限观察功能。版本或限流不符时核对工程目标与烧录日志。INFO只读配置，不启动电机。

## 2. 先观察左轮

1. CH1中位、CH5 OFF、CH6高位，给两只摩擦轮电调上电，等反馈稳定且两轮停稳。先发送WHEEL OFF，再WHEEL LEFT，收到W|OK|LEFT后继续。
2. 保持OFF、回中至少0.5秒，再CH5 ON；确认I12（输出许可）和I38（可触发）为1。
3. 将CH1向通道值增大的方向推并保持。先观察1～2秒，再回中；本档无500ms计时结束，保护正常时可由持续遥控请求维持。
4. I34给定应逐步变负，最多−500mA；I35活动为1。回中后I34/I35应变0。CH5 OFF并发送WHEEL OFF，等待惯性滑行结束。

## 3. 再观察右轮

两轮停稳后，CH1保持中位、CH5 OFF、CH6高位。WHEEL OFF后发送WHEEL RIGHT，收到W|OK|RIGHT。再次OFF回中至少0.5秒→CH5 ON，确认I12/I38，再推住CH1。右I34最多+500mA；先观察1～2秒，回中、CH5 OFF、WHEEL OFF。

结束后不能只推回摇杆来重新启动，须完成新OFF回中→ON。选另一轮也须先WHEEL OFF且两轮停稳。不要用手拨动带电轮子。

## 4. 波形和异常

VOFA曲线数据间隔50ms，放大单次观察窗口并保存原始串口记录。

| 通道 | 左轮 | 右轮 |
| --- | --- | --- |
| ERPM | I29 | I30 |
| 反馈电流mA | I31 | I32 |
| 当前所选轮给定mA | I34，最低−500 | I34，最高+500 |
| 活动/故障 | I35 / I36 | I35 / I36 |

I36正常为0。出现故障、方向变化、抖动或异响时，CH5 OFF、WHEEL OFF并保存波形；故障16意味着收到过超过2000ERPM的反馈，不等同于电机未收到命令。此时不继续加电流或放宽阈值。

请反馈左右实际方向、给定峰值及I36，保留I29/I30、I31/I32、I34/I35/I36原始数据。0.5A实物结果和6000rpm稳速仍待验证。
