# 左轮0.4A点动与版本核对

此页为500ms点动历史步骤。当前源码已按用户请求更新为左右0.5A按住运行，请使用[持续观察步骤](摩擦轮0.5A持续观察.md)。

用户已反馈0.3A档方向正确，并请求继续小幅增加电流。当前源码为JOG_L400_R200_V1：左轮节点70固定负给定，幅值上限400mA；右轮节点71仍固定正给定，上限200mA。方向沿用已确认的左顺时针、右逆时针。

电流幅值仍按5mA/ms上升，左轮约80ms到达上限；单次最长500ms，回中或撤权提前结束。两轮反馈新鲜、停转检查、遥控保护、2000ERPM、1A反馈电流监测及60℃FET保护保留。提高给定电流不保证机械转速，0mA停机给定为滑行。

## 1. VS Code重新构建并烧录

1. CH1回中、CH5 OFF，发送`WHEEL OFF`，等两轮停稳后断开电机动力。清空弹丸，并保持飞行、云台及拨盘动力隔离。
2. 打开原[Gimbal_Control工作区](../Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace)，选Gimbal_Control目标。Ctrl+Shift+P执行`eide: 重新构建`，确认成功。
3. 按Ctrl+Alt+D，通过现有ST-Link/SWD配置烧录；确认VS Code烧录成功后复位。整个过程沿用原工作区，无需选择独立固件文件。

## 2. 先核对板上版本

USART1连接VOFA，串口115200、8N1，CH1中位、CH5 OFF。发送带换行命令：

```text
WHEEL INFO
```

预期完整回复：

```text
W|INFO|JOG_L400_R200_V1|LEFT_MA|400|RIGHT_MA|200|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|500|ERPM|2000|ENABLED|1
```

版本不同、LEFT_MA不是400或ENABLED不是1时，先核对工程目标与烧录日志。INFO只读编译配置，不选轮、不发送CAN、不启动电机。

## 3. 单次左轮点动

1. CH1回中、CH5 OFF、CH6高位，给两只摩擦轮电调上电，等反馈稳定、两轮停稳。先发送`WHEEL OFF`，再发送`WHEEL LEFT`，必须收到`W|OK|LEFT`。
2. 保持CH5 OFF且CH1回中至少0.5秒，再CH5 ON。I12（输出许可）和I38（可触发）应为1。
3. CH1向通道值增大的方向推约0.2～0.3秒，然后回中。当前只选择左轮；给定逐步变负，最多−400mA。若一直保持摇杆，固件也会在500ms结束给定。
4. CH5 OFF，发送`WHEEL OFF`，等轮子停稳。不要用手接触带电轮子；从前面已确认的外侧轮面视角观察左轮顺时针。
5. 再测一次必须先停稳，重新选择左轮并完成OFF回中→ON；保持摇杆不会自动重复。

## 4. 这次记录什么

VOFA曲线使用50ms数据间隔；放大单次触发前后3～5秒，并保留原始串口记录。

| 通道 | 含义 | 本次观察 |
| --- | --- | --- |
| I29 | 左ERPM | 记录符号、峰值与尖峰；不是机械RPM |
| I31 | 左反馈电流，mA | 记录反馈峰值，可能有量化或起动波动 |
| I34 | 所选轮带符号给定，mA | 左轮最小值应不低于−400 |
| I35 | 点动活动 | 触发时1，结束后0 |
| I36 | 故障位 | 正常0；非零先停机检查 |

反馈ERPM绝对值超过2000会锁存故障16并停止给定，因此本档也可能提前停。若有抖动、异响、方向变化或故障非零，CH5 OFF并发送WHEEL OFF，保存当次波形后查原因；不继续加电流或放宽阈值。

回复本次左轮是否明显顺时针、I34最小值及I36；有I29/I31/I34单次波形或原始记录时一并提供。原始数据仍用于后续低速控制，6000rpm与整套考核尚未验收。
