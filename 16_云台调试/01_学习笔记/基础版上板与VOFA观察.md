# 基础版上板与 VOFA 观察

当前固件已补入只读参数采集，动力控制与闭环仍锁定。获取电机数据请先看[USART1电机参数采集步骤](USART1电机参数采集步骤.md)。本页用于VOFA遥控保护观察；默认沿用第15项CH1/5/6，离线通过与实机验收分别记录。

## 1. 编译与接线

1. 在 `Output/Gimbal_Control/MDK-ARM` 打开 Keil工程或EIDE工作区，完整编译。也可以在仓库根运行 `Scripts/build.ps1`，具体路径见[工程说明](../Output/Gimbal_Control/README.md)。
2. 首次检查只给云台板和接收机逻辑电源，先断开电机动力。通过现有ST-Link自行下载本次生成的HEX，复位后开始观察。本次代码生成未执行烧录。
3. 遥控配置沿用第15项，硬件更新为Cherrycoast4.8.1：FS-iA10B的i-BUS SERVO信号S接新板P2上层pin4 / PA1，+接P2 pin5 / 5V，−接P2 pin6 / GND。新板P1是GPIO，不照旧接口名插接。按原理图针号核对，上层不是照片方位；不要接下层反相DBUS信号。详见[4.8.1接收机接线](Cherrycoast4.8.1接收机接线.md)。
4. USART1继续接电脑串口，115200 / 8N1、VOFA选择FireWater。发送频率20 Hz，固定29通道，映射见[工程说明](../Output/Gimbal_Control/README.md)。

## 2. 先核对通道

保持第15项配置，核对CH1、CH5、CH6，对应VOFA下标0、4、5。默认只验证这三路，未设置的辅助通道不影响回中和保护。需要后续完整十通道演示时，再启用 `APP_REMOTE_PROFILE_LEGACY=0` 并按工程映射核对，当前不用改遥控器。

通道应大致为低1000、中1500、高2000。若某路固定、缺失或反向，先改遥控设置或 `App/app_config.h` 映射；不要修改保护条件来跳过检查。

VOFA 28持续增长但10一直为0时，表示UART4有字节、还没有新鲜合法i-BUS帧。先检查SERVO端口、PA1接线、波特率和对频。VOFA 10为1只说明有效串口帧新鲜，RF在线还要靠正确Failsafe设置。

## 3. 配置接收机 Failsafe

按遥控器实际菜单，将失联输出设为：

| 通道 | Failsafe值 |
| --- | --- |
| CH1 | 1500，回中 |
| CH5 / CH6 | 1000，停止与撤销许可，沿用第15项 |

运行时把CH6置高位。关闭发射机实测CH5/CH6落低，确认逻辑解锁撤销。若接收机继续发送“保持最后高位”的合法帧，校验和与100 ms超时无法识别无线失联，必须先修正Failsafe再继续。

## 4. 解锁与故障恢复

默认配置把CH1回中、CH6高位，CH5先OFF再ON。完整十通道映射才另外要求CH2回中、CH3/7/8/9低位、CH10中位。

- OFF后VOFA 13应为READY=1；ON后为ARMED=2，11应为1。
- 基础版12（动力许可）与26（后端就绪）始终为0；16/17只显示角速度请求，18只显示摩擦轮请求。
- 上电CH5已是ON时，11应保持0；CH1未回中也不能完成解锁。
- 拔接收机信号，100 ms后应锁定；恢复后CH5停在ON不能重启，须先OFF再ON。
- 关闭发射机，正确Failsafe也必须撤销解锁；恢复对频后仍需新的OFF→ON。
- 电脑发送 `STOP\r\n`，应显示原因7并清除请求；再次操作OFF→ON后才可恢复。若发生输入故障，先发送换行结束被丢弃的旧行，再发完整STOP。

保护原因是当前状态，回OFF后可以清零；故障测试时保存VOFA数据到[实机验收记录](../02_过程记录/实机验收记录.md)。

## 5. 可选完整映射的阶跃与发射逻辑观察

本节仅适用于 `APP_REMOTE_PROFILE_LEGACY=0`。默认旧配置不生成这些请求；不必为参数采集调整遥控器。

正常解锁后，将CH9置中位Yaw阶跃或高位Pitch阶跃；CH10先回中，再拨一端。VOFA 21显示轴模式，22显示±30°，23每次有效触发增加1。保持在端点不应连续计数，从一端直接到另一端也不应增加；回中后可以再次触发，切轴会清除旧偏移。此处只验证请求，不计入250/300 ms或0.2°实机成绩。

CH8高位时可观察摩擦轮请求18=1。单发/连发逻辑已经离线验证，但基础版没有真实摩擦轮稳速反馈，因此20（发射事件数）应保持0。不要为了看到事件计数而把电机在线或稳速条件写死为1。

CAN接收数24/25可以证明收到合法帧，不能证明来自指定电机或单位正确。未接CAN时为0是正常现象；此基础版尚不能完成电机反馈失联与停机验收。

## 6. 下一步准备

完成上述逻辑检查后，读取GL60Ⅱ和DM3507的驱动版本、模式、CAN波特率及完整命令/反馈ID；读取并核对摩擦轮极对数、电机/轮速关系与VESC配置，实测拨盘每发累计编码器计数。负责人已确认拨盘无需记住电机型号。按[资料清单](../03_参考资料/资料来源与待确认参数.md)记录，补驱动、机械保护和闭环控制。保护专项实机通过后再逐轴做低功率调试。
