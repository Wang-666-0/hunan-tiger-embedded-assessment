# Yaw 双环 PID 与 VOFA 操作

现行Yaw版本V2H，六PID/±50/90°每秒保持，新增裸YAW简洁状态、YAW HELP、YAW VIEW与TELEM OFF/ON；旧指令/VOFA控件兼容。见[统一串口速查](云台串口统一指令与启动_20261017.md)。以下旧版本性能记录保留历史。

当前源码版本 `GL60II_CASCADE_MANUAL50_V2G`，使用原 `Output/Gimbal_Control`。用户最终要求位置KP保持10，六默认值仍为位置10/.15/.01、速度.0037/.003/.000001。CH5中位手动模式，右摇杆CH1左右按原速度映射移动Yaw，目标角裁到相对软件零点−50°～+50°，回中保持目标；满杆90°/s、死区±30。CH5下位仍为原±30°阶跃模式。I26/RESP_MS沿用首次反馈进入目标±0.2°的时间，I27仍单独统计稳定到位。48列/5ms/921600、六控件、无180/.10业务限幅和MIT协议端点、摩擦轮6000rpm及CH8人工重解锁沿用。

**VOFA使用921600、Δt=5ms、FireWater，I0～I47绑定保留。** I13/I23=0表示速度限幅关闭，I22只表示协议±10端点。旧70列及单环命令仍不适用。

## 构建与首次检查

1. 打开原工作区 `D:/Project/27电软正式批考核/16_云台调试/Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace`。先Ctrl+Shift+P执行 `Developer: Reload Window`（重新加载窗口），确认EIDE的App分组含 `yaw_cascade.c`。配对头文件在同目录，EIDE/Keil清单已补齐；本轮最终核对发现EIDE曾缺此项，重载后须读取更新配置。执行EIDE“重新构建”，成功后按既有ST-Link流程烧录（Ctrl+Alt+D）。
2. 先关闭VOFA串口连接，再设USART1 **921600、8N1、FireWater、Δt=5ms** 后重连。仅修改Δt而不烧录，不会使旧50ms固件加快；烧录后仍用115200则无法正常通信。UART4遥控iBUS仍为115200，无需改遥控。
3. 发送 `YAW STATUS`，确认版本 `GL60II_CASCADE_MANUAL50_V2G`、`TARGET_LIMIT_DEG|50.0|HARD_LIMIT_DEG|60.0`、`TELEM_MS|5|BAUD|921600`、`OUTPUT_LIMITS|0`，再用 `YAW PID`确认下面六个默认增益。HARD_LIMIT为反馈角度门限，SPEED_GUARD0仍表示之前的速度停机已关闭；VREF_MAX_DPS0表示双环速度参考业务限幅关闭，实际目标速度看I2。电机CAN反馈仍约10ms，相邻5ms遥测可能是相同角度。

紧凑文本使用6位有效数字，可能出现 `2e-06`，数值含义与0.000002相同。PID数据绑定不依赖固定小数位。状态/结果仍打印可读文本；发送长查询或自动成绩时，低优先级串口可能暂时晚一帧，随后按固定周期继续，不补发旧快照。现场实际间隔仍需观察，软件模拟不替代USB串口实测。

200Hz下可在VOFA接收区设置隐藏采样数据包，保留Y|OK/Y|STEP文本，减少终端滚动；曲线和控件仍接收数据。[FireWater协议与采样包显示](https://www.vofa.plus/docs/learning/dataengines/firewater/)。原参数采集工具也改默认921600，读取旧固件可显式 `capture.ps1 -BaudRate 115200`。

## 参数与控件

V2G沿用用户20:36实物ID29固化六增益，位置KP最终保持10；这轮+30°首次响应194ms、超调0.070°、有效稳态误差−0.038°，PASS1。稳定到位时间另为2194ms。以下命令可读作这一组参数的手动恢复值，正常重启已自动加载：

```text
YAW POS 10 0.15 0.01
YAW VEL 0.0037 0.003 0.000001
```

`YAW POS`设置位置环三个增益，`YAW VEL`设置速度环三个增益；这两条是调参命令。`YAW PID`不带数字时只读查询两环当前值。

| 控件 | Str/ASCII命令模板 | 反馈通道 | 初始值 | 首轮控件范围 / 步进 |
| --- | --- | --- | --- | --- |
| 位置KP | `YAW PKP %f` | I7 | 10 | 0～20 / 0.5 |
| 位置KI | `YAW PKI %f` | I8 | 0.15 | 0～2 / 0.05 |
| 位置KD | `YAW PKD %f` | I9 | 0.01 | 0～0.5 / 0.01 |
| 速度KP | `YAW VKP %f` | I10 | 0.0037 | 0～0.005 / 0.0001 |
| 速度KI | `YAW VKI %f` | I11 | 0.003 | 0～0.02 / 0.001 |
| 速度KD | `YAW VKD %f` | I12 | 0.000001 | 0～0.00005 / 0.000001 |

在VOFA左栏添加这些Str命令；控件右键绑定相应命令，再绑定对应的数据通道。参数占位符使用 `%f`，发送结尾带真实LF或CR。滑块上方绑定后的读数是主控反馈值；输入框里刚输入的数字不代表已经被接受。速度环增益显示建议保留6位小数。[VOFA命令和参数说明](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/)，[滑块数据与命令绑定](https://www.vofa.plus/docs/learning/widgets/slider/)。

固件接受的增益范围不变：位置KP 0～30、KI 0～10、KD 0～2；速度KP 0～0.02、KI 0～0.2、KD 0～0.001。上表为较窄GUI调参范围。`YAW VMAX 数字`现在明确回复 `OUTPUT_LIMITS_DISABLED`，不能用旧控件重新开启限幅。非有限数、超范围、缺失或多余增益均拒绝，整组校验后才生效。

两环单位分别为：位置KP=1/s、KI=1/s²、KD为无量纲；速度KP=协议Nm/(°/s)、KI=协议Nm/°、KD=协议Nm/(°/s²)。原单环用rad计算的1.3/0.1/0.04不能复制进速度环。`YAW PID 三个数`及旧`YAW KP/KI/KD`明确回复 `USE_YAW_POS_OR_VEL`，防止继续拖动旧控件却调错环。

在线实际改变增益会清两环积分、保持当前目标并重新计算；正在测量的一轮标为ABORTED/PID_CHANGE。同值写入不清积分或中止。V2G的六默认值保存在app_config.h并编译进固件，上电/主控复位自动加载10/.15/.01及.0037/.003/.000001。VOFA后续改动仅在RAM，本次OFF再ON仍保留，下一次重启恢复这组固化值；没有增加自动Flash写入。完成报告冻结当轮参数。软件零点和测试请求仍按原READY/遥控流程重新建立。

## 右摇杆手动Yaw −50°～+50°

1. CH5、CH6上位，CH7、CH8中位，所有摇杆回中；将静止云台放在希望作为零点的位置。
2. 发送 `YAW READY` 并等待 `Y|OK|READY|ZERO_SET|1|REQUESTED|1|ACTIVE|0`。这是沿用的FD/必要时FB/软件设零/准备流程。
3. CH5由上位拨到中位，等待Yaw活动；CH6继续上位，CH7/CH8保持中位。右摇杆水平CH1控制Yaw，CH2上下留给Pitch请求，当前没有Pitch驱动。
4. CH1高于中心控制正角方向，低于中心控制负角方向；偏转越多速度越大，满杆请求90°/s。回中保持最后目标角，不自动回零。I0看实际角，I1看目标；目标在软件零点−50°～+50°内截断，达到边界后继续同向拨杆不积累越界目标，反向可立即离开边界。
5. CH5上位关闭；CH8上位锁定/失联撤权，解除锁定或恢复信号后仍须摇杆回中、CH6上位、CH5新上→中人工解锁。若停机使请求撤销，按原READY/ON流程重新准备。CH6中/下位仍按原逻辑开启6000rpm轮子，不由CH1启停。

目标±50°是相对本次软件零点的控制范围，实际位置看反馈，不是新增的物理限位。原反馈角度保护从±40扩到±60，保留10°余量；无输出观察±65。边界±0.2°以内的量化/微小静差允许重新准备，目标仍裁到±50，更远位置继续拒绝。先小幅拨杆确认方向，再试完整范围。用户已确认V2F右杆能操作但稍慢；本轮V2G提速尚无实物回传。

CH5下位是测试模式，右摇杆的手动速度被屏蔽；沿用左摇杆CH4选择Yaw±30°及CH7确认/回零。遥控阶跃后切回普通模式仍按原停机重解锁逻辑执行。

## 从设零到遥控30°阶跃

1. 遥控器开机后，CH5、CH6上位1000，CH7、CH8中位1500，四个摇杆回中。将静止云台放在要作为零点的位置。
2. 点击绑定 `YAW READY` 的“设零并准备”按钮一次。先见 `Y|BUSY|READY`，等自动回复 `Y|OK|READY|ZERO_SET|1|REQUESTED|1|ACTIVE|0|NEXT|CH5_TEST`。这条命令沿用FD停机、必要单次FB、静止设零和准备流程。
3. 四个摇杆仍回中，CH5从上拨到下位2000进入测试，CH6仍上、CH7/8仍中。等约0.5秒，用 `YAW STATUS` 或数据显示确认活动I15=1、电机状态I17=1、故障I18=0、已设零I21=1，实际角度及目标角均接近0°。
4. 左摇杆水平CH4向右选+30°（向左选-30°），其纵轴CH3保持中位；CH7往下确认一次，随后CH7和摇杆都回中。收到 `Y|REMOTE_STEP|…|RESULT|STARTED|TARGET|30.0` 才是被接受。`START_GUARD`表示拒绝，不会延迟补发；须回中后排查近零/静止/活动状态，再重新确认。
5. 保持5秒，不改参数。串口自动输出 `Y|STEP|…|STATE|DONE|…`，I25变为2，指标显示更新；此后继续闭环保持30°。`YAW RESULT`可重读最近报告。
6. 测试下一组时，先CH7上位发回零事件，再回中，等实际角度进入±0.2°且静止。修改参数，再按第4步触发新的测试。结束用CH5上位；`YAW OFF`按钮同时取消Yaw准备请求。

若当前监测正常，只想在新的静止姿态设零，可先CH5/6上、CH7/8中，`YAW OFF`后等待失能确认，再点击 `YAW ZERO`。随后 `YAW ON`准备，按第3步人工解锁。通常一条READY更方便，它会重新设置当前姿态为零点。

## 指标如何读

每次测量窗口5秒，统计来自约10ms一次的实际CAN反馈，不按VOFA5ms显示快照推算；N与GAP_MS仍反映真实CAN采样。

| 字段 / 显示 | 解释 |
| --- | --- |
| RESP_MS / I26 | 首次反馈进入目标±0.2°的时间，无连续保持条件，后续离带不改写；-1代表本轮未取得 |
| T90_MS / I33 | 到90%步幅的时间，不等同于到位时间 |
| RISE_MS / I34 | 10%到90%的上升时间 |
| SETTLE_MS / I27 | 5秒结束仍在±0.2°内至少50ms的最后进入时间；-1表示未取得 |
| OS_DEG / I28 | 超过目标的最大角度，正负30°均按运动方向计算 |
| OS_PCT / I29 | 超调占本轮实际阶跃幅度的百分比 |
| SSE_DEG / I30 | 目标角减第4～5秒时间加权平均角，正值表示平均实际角小于目标 |
| SSE_VALID / I31 | 完整末秒采样且均在±0.2°内才为1；为0时I30只表示末秒偏差估计 |
| VALID / I25=2 | DONE只是完成采样窗口；ABORTED、RUNNING或IDLE不作为完成成绩 |
| PASS / I32 | 暂定软件判据：约30°、RESP≤250ms、超调≤0.2°、有效稳态误差≤0.2° |

V2D的I26是“首次到位时间”：+30°目标时，第一包角度落在29.8～30.2°便立即记时，后续偏离也保留这个值。I27用于单独判断稳定到位。计时从本轮命令接受开始，使用实际CAN接收时间；VOFA连线过带而实际样本未落入带内时，不凭图形插值记时。烧录后需重新做一轮阶跃，旧I26值不追溯重算。

文本报告保存六增益、VREF_MAX_DPS0、VFILTER_MS10、CTRL CASCADE及OUTPUT_LIMITS0。SAT_N现在只计最近成功提交请求达到协议端点的样本，原180/.10业务饱和不再发生。VMAX_DPS仍为原始反馈速度峰值；TMAX_NM/FIRST_NM为协议请求，CMD_N为HAL接受提交次数，不是实际机械力矩标定或总线完成计数。

内环速度由连续编码器位置差分及10ms时间常数滤波获得，避免电机原始速度零附近±2.8°/s量化偏置形成长期力矩。两环积分仅在新反馈到达时按实际时间推进；D对测量求导，目标阶跃不产生微分冲击。采样约10ms仍限制峰值与到位时刻的可观测精度，不能由软件合成测试保证实物考核结果。

## 首轮怎么调

V2G重启自动恢复ID29六增益，先使用这组重新测一次同方向+30°确认重复性，再按需要测−30°；一次改一项。此前8/0/0及.001/.004/0是V2A～V2D的历史起点，不再是当前上电值。调整后若需长期保存，再明确更新固化默认值。

若I22为1，说明已达到MIT映射端点±10，继续加增益不能编码更大请求。I23固定0。比较同方向/同零点的5秒完成报告；SSE_VALID0时末秒误差还不能算有效稳态成绩。旧截图的位置17/1.25/0、速度0.0048/0.013/0在软件零点接受30°阶跃时产生初始510°/s及2.448协议力矩，和旧.10上限下的动作不同；该数字是计算结果，未标定实际机械Nm。

V2G生产SPEED_GUARD0、OUTPUT_LIMITS0：双环180参考限幅和.10业务力矩限制继续取消；右杆自身满杆90°/s是原遥控映射，与双环目标速度不限幅是不同环节。本轮只将手动目标速度从60提升到90°/s，未加入前馈；首次到位统计、CAN/温度/时序及遥控解锁沿用。

此前用户已确认动力关闭而USB/ST-Link维持主控供电，引发两路ACK发送错误并锁存。若出现 `CAN_FAULT_USE_YAW_BUS`，先 `YAW OFF`，读取 `YAW BUS` 保存证据；稳定动力后按原流程冷复位主控，再准备。换双环不会清CAN历史故障，ON/READY也不会自动重启故障中的电机。
