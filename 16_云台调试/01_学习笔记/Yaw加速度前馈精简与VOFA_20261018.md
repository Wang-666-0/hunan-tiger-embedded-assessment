# Yaw 加速度前馈精简与 VOFA（V2M）

当前固件版本：`GL60II_CASCADE_ACCEL_V2M`。继续使用原工程和 Ctrl+Alt+D 的编译下载流程。本次只完成软件修改与离线验证，没有连接电机、下载或确认实机达标。

## 为什么精简

现有角度曲线说明有回落、振荡或拖尾，但不能单凭角度认定全部由惯量造成。速度反馈延迟、环路增益、积分状态和机构柔性都会影响减速。加速度前馈的用途是提前提供规划加减速所需的力矩；规划结束后若仍有速度，继续制动仍依靠速度反馈。

删除原四项力矩补偿：FBIAS 固定偏置、FANG 实际角度线性补偿、FKV 闭环速度参考力矩补偿、FC 摩擦补偿。同时删除 FC 的辅助参数 FVS 和在线修改旧补偿时的积分转移逻辑。FMAX 保留，作为新加速度前馈的单独限幅。

当前结构：

```text
30° 命令 → 可选 SHAPE 五次多项式规划 → 位置 PID → 速度 PID → 力矩求和 → 电机
                     │                      ↑              ↑
                     ├─规划速度 × SHAPEV ───┘              │
                     └─规划加速度 × FKA → FMAX 限幅 ────────┘
```

保留已有 SHAPEV，默认0，不强制恢复曾造成大超调的权重1。本轮先固定 SHAPEV=0，只比较 FKA。保留双环 PID、编码器速度/加速度低通估计、积分抗饱和、原许可/反馈保护及原命令计时。Pitch 重力补偿、拨盘和摩擦轮控制不作本轮修改。

## 新前馈实际如何工作

仅在正式 `YAW STEP` 的规划运动段，且 FF ON 时：

```text
raw_ff = FKA * 规划加速度（deg/s²）
ff = clamp(raw_ff, -FMAX, +FMAX)
总力矩 = clamp(速度PID + ff, 协议力矩范围)
```

FKA 的单位是协议 Nm/(deg/s²)。协议 Nm 未经输出轴力矩标定，不能直接等同于精确的物理惯量。

对正向30°运动，前半段规划加速度为正，后半段为负；反向运动自动反号。前馈在起点、中点、终点归零。它不使用编码器测得的加速度作正向补偿，也不对理想角度阶跃直接求二阶差分。

`SHAPE=0`、规划结束、HOME/普通 TARGET、手动操作或停机时，没有规划加速度力矩前馈。FKA不用于到位后的恒定保持力矩。FF ON可以保留，但这些情况下实际 FF_NM 为0。

前馈与 PID 合计参加总力矩抗饱和；FMAX 只限制该前馈，不是总力矩限制。此次没有恢复原来已取消的180°/s或0.10业务总力矩限制。

这属于按规划时间执行的补偿。实际运动明显落后或提前时，单纯增大FKA可能使制动时机不合适；应回看实际速度与规划速度，调整速度环或规划，而非无限提高系数。

## 命令

| 命令 | 含义与范围 |
|---|---|
| `YAW FF` | 查看加速度前馈配置和实际输出，报告 TYPE=ACCEL |
| `YAW FF ON` / `YAW FF OFF` | 开关加速度力矩前馈 |
| `YAW FKA` / `YAW FKA 0.000002` | 查询/设置系数，允许0～0.001，默认0 |
| `YAW FMAX` / `YAW FMAX 0.05` | 查询/设置前馈幅值上限，允许0～1，默认0.1 |
| `YAW SHAPE 160` | 设置正式STEP的规划时长160 ms，允许0或80～500整数ms |
| `YAW SHAPE 0` | 关闭规划，恢复直接角度阶跃；加速度前馈随之没有输出 |
| `YAW SHAPEV 0` | 关闭规划速度前馈，保留平滑位置参考 |
| `YAW SHAPE` | 查看规划及规划速度前馈权重 |

FKA硬范围上限不是已经验证的适用值。上电默认 SHAPE=0、SHAPEV=0、FKA=0、FF OFF；参数只在RAM。原固化PID仍为位置7.5/.15/0，速度.0025/.003/0；需要复现最近截图的9/.2/.05与.003/.003/0时，应在下载后明确发送并读取确认。

完整5秒测试窗口内禁止修改FKA/FMAX和开启FF。需要关闭时，FF OFF仍接受并使本轮以FF_CHANGE中止；它只关闭加速度前馈，不关闭SHAPE或SHAPEV。STOP仍执行原停机流程。

旧 `YAW FBIAS/FANG/FKV/FC/FVS` 查询或设置返回 `Y|ERROR|REMOVED|...|USE|FKA|FMAX`，不会暗中解释成新参数。旧控件应删除或解绑，不能把FANG改个名字继续使用。

## 第一轮如何测

本轮目标是比较是否改善减速和最终稳定时间，以下是小幅起始试验，不是最终整定值。按既有准备、遥控解锁流程进入健康活动状态；不要每轮READY重设零点。

在没有进行STEP时，先设置：

```text
YAW FF OFF
YAW POS 9 0.2 0.05
YAW VEL 0.003 0.003 0
YAW SHAPE 160
YAW SHAPEV 0
YAW FKA 0
YAW FMAX 0.05
YAW PID
YAW SHAPE
YAW FF
```

先HOME到原零点，实际0±0.2°且静止，再统一等待5秒。执行 `YAW STEP 30`，完整等待5秒，读取 `YAW RESULT`，保存作为无加速度前馈基线。保持负载、Pitch姿态、摩擦轮状态和线束姿态一致。

完成后仅改变：

```text
YAW FKA 0.000002
YAW FF ON
YAW FF
```

然后同样HOME、静止、等待5秒、STEP30，完整等待5秒保存结果。不要直接在+30°位置再次STEP，也不要把+30→−30当作30°阶跃。

30°/160 ms的规划加速度峰值约6765.8°/s²，FKA=0.000002对应未截断前馈峰值约0.01353协议Nm。实际协议存在量化，微小补偿的效果也可能有限。

如果两次重复中最终稳定时间都改善、回落没有变深，再尝试0.000004、0.000006，每次只变FKA。出现更大超调、更深回落或稳定时间变长，就退回上一档；没有收益时停止增加，检查速度与力矩记录。I59反复为1表示新前馈受到FMAX截断，不能仅靠继续增大FKA解决。

比较最终 `SETTLE05_MS`，Yaw要求≤250 ms且之后保持29.5～30.5°。`RESP05_MS`只是首次进入，旧PASS也不是新考核判定。SHAPE的160 ms计入总250 ms；规划结束不会重置测量计时。运行中SETTLE05=-1是未结算，不是0 ms。

## VOFA 控件与数据通道

原I0～I70索引不移动，新增I71，当前共72列。I49～I53为固定零占位，以免旧面板后面的PID、积分、统计和规划通道错位；这些占位不参与控制。

| 控件/曲线 | 绑定通道 | 发送命令/建议 |
|---|---|---|
| FKA滑块/数字框 | I71 | `YAW FKA %f`；初始0，建议控件范围0～0.00002、步进0.000002、显示8位小数 |
| FMAX滑块 | I54 | `YAW FMAX %f`；本轮固定0.05 |
| FF ON按钮 | I48作状态显示 | `YAW FF ON`，仅按下发一次 |
| FF OFF按钮 | I48作状态显示 | `YAW FF OFF`，仅按下发一次 |
| SHAPEV控件 | I70 | `YAW SHAPEV %f`，本轮固定0 |
| 角度曲线 | I0、I1、I66 | 实际角度、最终30°目标、内部规划位置 |
| 速度曲线 | I2、I3、I67 | 内环目标、编码器滤波估计速度、原始规划速度 |
| 力矩曲线 | I5、I55、I57 | 总请求、实际加速度前馈、速度积分 |
| 规划加速度 | I68 | 应能看到前半正、后半负，反向阶跃反号 |
| 前馈截断 | I59 | FMAX是否正在截断加速度前馈 |
| 最终结果 | I61、I62 | 测试DONE后的SETTLE05、PASS05 |

命令格式用字符串浮点参数，末尾添加真实LF（0A）；关闭循环发送，按钮释放时不再重复发命令。控件显示值、命令发送值和MCU回读是不同环节，最终以 `YAW FF` / `YAW SHAPE` 回读为准。

提供了独立原生JSON面板 `Output/VOFA_Yaw_Accel_20261018/`，含加速度前馈、PID和诊断三页；没有改动你正在使用的VOFA配置。已核对JSON结构、绑定通道、命令LF和非循环设置，尚未实际导入VOFA验证。旧 `VOFA_Yaw_FF_20261017` 面板仅作历史保留，V2M请使用新面板或手工解绑旧控件。

## 验证范围与后续判断

离线覆盖了正反向、80/160/500 ms规划、MCU时钟回绕、加速/制动符号、静止到静止前馈净脉冲、限幅、关闭/停机、零系数与禁用输出一致、测量加速度不作前馈、抗饱和、完整测试期间的改参拒绝、历史参数冻结与遥测通道。Pitch重力前馈和其它模块参加完整回归。实机惯量、弹性、速度环带宽和通信延迟下的稳定性仍需测量。

前馈一般使用期望运动信号，并与反馈共同控制；可参考 [WPILib官方原理说明](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/introduction/introduction-to-feedforward.html)。本工程使用力矩接口，不能直接照搬其电压控制系数。
