# 拨盘遥控考核操作：V1F（沿用V1E遥控流程）

当前源码版本`C610_FEEDBACK_TIME_V1F`，仍为原`Output/Gimbal_Control`工程。Yaw V2K、Pitch V1F、双摩擦轮6000rpm和原遥控分配保持；拨盘为CAN2/C610/ID5。已测DIR−1、GEAR35.68、每发输出轴40°固化到源码。正常上电自动准备，不再逐条输入CAL/ZERO/ARM或查询串口才允许动作。

V1F针对V1E现场FAULT4作反馈时间量化修正：按真实接收时间戳差加1ms计算跳变边界，保留256counts余量和半圈歧义判据。STATUS/CHECK新增GAP_MARGIN_MS、TS_ALLOW，CHECK另有GAP_BOUND_MS；VOFA39列与运动参数不变。首次604counts/1ms样本已通过软件回放，实物是否不再误停仍待验证。

## 正常操作

1. 机构位于允许的单发起点，沿用原云台上电支撑条件。上电时CH5/CH6上位、CH7/CH8中位、摇杆居中，保持约2秒让原云台准备和拨盘静止参考捕获完成。
2. CH5拨中位，CH6先保持上位约1秒，再拨中位或下位。摩擦轮开始运行，等约5秒进入真实稳速；若过早按住扳机，松回中位后再触发，不会补发启动期间的请求。
3. CH6中位：CH8下→中触发一发，输出轴上视顺时针40°，到位自动停止。CH8持续下位不会重复单发。
4. CH6下位：CH8持续下位连发，松回中位后停止增加目标，完成当前40°边界并停稳。CH8上位立即锁定撤权；CH6上位关闭摩擦轮，CH5上位关闭总输出，CH5下位云台测试时轮子和拨盘均禁止。

正常运行只需遥控。空闲锁定后按原规则先CH6/CH5上、CH7/CH8中，再重新解锁。半发急停、通信/反馈/堵转等故障不会自动换零点或续发，须处理机构及故障后再人工恢复；CAN代次错误仍须按已有总线处理流程检查，不能清拨盘局部错误代替修复总线。

## 首次烧录本版

在原VS Code/EIDE工作区执行Rebuild，零错误后用原ST-Link流程下载。没有新增固件工程、App生产源文件或EIDE文件列表项，也不提供HEX文件。下载后按上述遥控流程操作；不用串口初始化。

首轮先无弹单发三次，再短按连发约0.3秒，确认方向、角度和释放停止正常后再延长。源码与离线测试完成不等于机构已通过20Hz实物验收，须观察实际拨盘动作/出弹数。首次实测V1F时仍需核对负载下的速度和电流。

## 单发与连发参数

| 参数 | V1F默认（运动参数与V1E相同） | 含义 |
| --- | --- | --- |
| STEP / GEAR / DIR | 40° / 35.68 / −1 | 输出轴步距、已测传动比、上视顺时针方向 |
| PKP / VKP / VKI | 8 / 2 / 5 | 转子位置到RPM、速度PI到电流给定raw |
| RPM | 3600 | 单发及连发释放收尾的转子速度上限 |
| CONT_RPM | 5800 | 连续位置跟踪的转子速度上限，反馈硬保护仍6000rpm |
| LIMIT | 3000raw | 电流给定上限，仍受原CAN白名单硬上限约束 |
| PHASE_MS / BRAKE_KP | 10ms / 30 | 软件参考相位延迟、接近已接受末端时的速度约束 |
| TOL / SETTLE | 1.5° / 10ms | 静止步进和释放收尾的到位容差/确认 |
| SETTLE_RPM | 30 | 静止到位的转子速度阈值 |
| TIMEOUT | 3000ms | 最早未完成步进的超时，不会让长连发每3秒中断 |
| 堵转 | 低速且≥1600raw持续300ms | 给定或反馈raw满足均检查；反馈raw不冒称实测A |
| 逐帧余量 | 256counts | 维持V1D现场放宽值，保留速度项、大跳变和半圈歧义保护 |

20Hz的平均转子速度按`40×35.68×20/6≈4757.33rpm`计算。连发使用50ms新鲜事件、线性位置参考与速度前馈，不逐发停稳；最多保留两个已经接受的40°边界。跟不上时拒绝新事件，不积压。松扳机/轮速离带取消尚未开始的前瞻，只收尾当前边界；锁定、模式退出、真实反馈失联/故障直接撤权。

## VOFA与结果读取（可选）

原Yaw/Pitch波形与控件不变。拨盘面板仍在`Output/VOFA_Feeder_20261017`，921600、FireWater、39列；I0至I35、I37/I38原定义保持，原预留I36现在显示最近一步的接受到完成延迟ms。I31仍为相邻完成间隔；连发流水执行时延迟可大于50ms，而相邻完成间隔仍可为50ms。

`FEEDER STATUS`读取位置、目标、RPM、给定/反馈raw、实际参数、完成/拒绝/中止/取消计数以及SHOT_MS、RATE_HZ、PENDING。`FEEDER RESULT`读取SINGLE_DONE、CONT_DONE、BURST_DONE、WINDOW_MS、RATE_VALID及实际边界完成频率；频率由本次连发实际完成边界的时间计算，首次仅一发时RATE_VALID0，不拿请求数冒充实际完成数。编码器跨界计数仍不能代替真实出弹传感器。

在线调参先回安全OFF，点击VOFA拨盘OFF（或`FEEDER OFF`），等待零电流握手。此命令会暂停自动准备，避免调参时自动重ARM。修改原RPM/LIMIT/PKP等控件后，按实际状态ZERO/ARM恢复；连发附加参数可用`FEEDER CONT_RPM/PHASE_MS/BRAKE_KP <值>`，实际值从RESULT读取。参数在线修改只在RAM，复位恢复表中编译默认。

故障现场先`FEEDER CHECK`保存首个跳变证据。机构已处于确认的单发起点且反馈静止后，可在安全OFF发送`FEEDER READY`，人工执行原CLEAR→ZERO→ARM保护流程；该命令用于异常恢复和调试，正常上电不需要发送。
