# 遥控保护与功能映射

## 设计原则

沿用上一任务中已验证的软件原则：i-BUS 帧必须校验并带真实接收时间戳；RF 失联时接收机仍可能继续发送 Failsafe 帧，所以同时检查帧新鲜度和独立许可通道；上电或故障恢复后必须重新做一次安全档到运行档的人工解锁动作。

参数采集版默认沿用第15项CH1/5/6和原接线，不要求重配遥控。`App/app_config.h` 中 `APP_REMOTE_PROFILE_LEGACY=1`。以下完整考核映射保留为后续可选方案，只有设为0并核对辅助通道后才启用；采集步骤见[USART1电机参数采集步骤](USART1电机参数采集步骤.md)。

| 逻辑输入 | 建议物理控件 | 行为 |
| --- | --- | --- |
| Yaw / Pitch 手动目标 | 两个自回中摇杆轴 | 正常模式下给角速度或小范围角度增量；死区内保持 |
| MASTER_ARM | 两段开关 | 总许可；必须观察到新的 OFF→ON 才能解锁 |
| FAILSAFE_OK | 独立通道 | 接收机 Failsafe 固定为低位，运行必须高位 |
| FRICTION_ENABLE | 两段开关 | 开启/关闭两只摩擦轮；关闭同时撤销发射许可 |
| FIRE_MODE | CH7 / SWC三段开关 | SAFE / SINGLE / CONTINUOUS；切模式不发射，扳机须先释放再到高位 |
| FIRE_TRIGGER | CH3摇杆轴 | 低位释放、高位触发；单发只取一次沿，连发最小间隔50 ms |
| TEST_MODE | CH9 / VRA旋钮 | MANUAL / YAW_STEP / PITCH_STEP；后两者禁止摩擦轮和拨盘 |
| STEP_SIGN | CH10 / VRB旋钮 | 先中位，后低/高位触发−30°/+30°；正式角度跳变待阶跃模块接入 |

如果实际可用通道不足，优先保留 MASTER_ARM、FAILSAFE_OK、FRICTION_ENABLE 和 FIRE_MODE；阶跃轴与方向可以通过组合动作选择，但必须防止普通摇杆误触发。

## 状态机

| 状态 | 进入条件 | 允许输出 |
| --- | --- | --- |
| SAFE=0 | 上电、复位 | 请求为零，原因初始为POWER_ON |
| READY=1 | 新鲜合法帧、Failsafe许可正常，已看到新的OFF档 | 动力仍锁定，等待回中后的新ON帧 |
| ARMED=2 | READY后操纵量安全、有效新ON帧 | 生成逻辑请求；动力还必须有正式后端和真实反馈就绪 |
| FAULT | 失联、总线/反馈/周期/越界/堵转等故障 | 立即撤销请求并执行各驱动已验证的安全动作 |

FAULT恢复前必须收到晚于故障时间的新OFF帧，再收到新ON帧；恢复通信本身不能恢复运行。基础版电机后端未实现，`output_allowed`始终为0，也不生成发射事件。正式版双摩擦轮达到稳定条件后，拨盘才获得发射许可。当前代码尚不能验收反馈掉线、堵转、温度和机械停机。

## 第一项必须完成的实机验收

1. 只接逻辑电源，确认每个摇杆和开关的通道号、范围、方向、更新周期。
2. 配置并实测接收机 Failsafe；关闭发射机时 MASTER_ARM 和 FAILSAFE_OK 都必须回安全值。
3. 上电时所有开关故意放在运行位置，系统仍不得启动。
4. 正常解锁后依次模拟停帧、UART 错误、CAN 反馈断开和主控复位，确认所有请求被清除。
5. 恢复链路但不重新拨动 MASTER_ARM，系统仍不得启动。
6. 摩擦轮开启后关闭 FRICTION_ENABLE，拨盘请求必须同时失效；再次开启也不补发旧单发事件。

验收过程写入 `02_过程记录/实机验收记录.md`。这项通过后才允许给电机恢复动力并开始后续调试。
