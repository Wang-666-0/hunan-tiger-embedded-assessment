# Yaw 新参数与 ±0.2° 考核通道（V2P）

2026-10-18 用户确认：时间判定的目标带也改为 **±0.2°**。Yaw 固件 `GL60II_FIXED_PID_V2P`，Pitch 测量版本 `DM3507_CASCADE_V1G`。

## 上电默认参数

| 环路 | KP | KI | KD |
|---|---:|---:|---:|
| Yaw 位置环 | 16.63 | 0.12 | 0.269 |
| Yaw 速度环 | 0.0081 | 0.003 | **0.000209** |

采用最新截图的实际回传值。Pitch PID 和重力前馈参数保持原值；Yaw 仍为直接双环 PID，实验规划/前馈关闭。

截图记录的超调为 **0.410608°**，超过本次 0.2° 标准。此前 ±0.5°规则下的 PASS05=1、218 ms，不能作为新标准的通过证明。

## 新判定

同一轮必须同时满足：

- Yaw 从原始命令接受时刻起 **250 ms 内最终进入 29.8～30.2°**，此后保持到本轮 5 秒测量窗口结束。Pitch 时限为 **300 ms**。
- 全测量窗口的方向性超调量 **≤0.2°**，是角度值，不是 0.2%。例如 +30° 的最大峰值应≤30.2°。
- 稳态误差绝对值 **≤0.2°**。保留第 4～5 秒的时间加权平均，同时要求该段反馈始终在 ±0.2°内，避免平均值掩盖波动。
- 测试完整结束、数据有效且无故障。

首次经过目标带的时间单独保留，仅用于分析起步速度。**总判定用最终稳定时间**，因此 200 ms 第一次到位、随后回弹、500 ms 才稳定，会判不通过。保持时间由窗口末检查，计时点仍记录最后一次进入目标带的时刻，不额外加 50 ms。

旧的独立 ±0.5°统计和 PASS05 已从当前源码与打印移除。浮点比较只加 0.00001°舍入余量，远小于一个编码器刻度；0.2001°仍判越界。

## VOFA 通道绑定

Yaw 仍为 **72 列**，Pitch 仍为 **58 列**，无需整体迁移既有通道。

| 数据 | Yaw 通道 | Pitch 通道 | 如何判断 |
|---|---|---|---|
| 实际角度 / 目标角度 | I0 / I1 | I0 / I1 | 观察最终目标带 ±0.2° |
| 六个实际 PID | I7～I12 | I7～I12 | 核对 MCU 回传值 |
| 首次进入 ±0.2°的时间 | **I60**（同 I26） | I26 | 分析首次接近速度，不代表稳定 |
| 最终进入并保持的时间 | **I61**（同 I27） | **I27** | Yaw≤250、Pitch≤300，单位 ms |
| 最大超调角度 | **I28** | **I28** | ≤0.2°；I29 才是百分比 |
| 有符号稳态误差 | **I30** | **I30** | 绝对值≤0.2°；只看有效的完整结果 |
| 稳态段有效标志 | I31 | I31 | 完整结果应为 1 |
| **综合通过标志** | **I62**（同 I32） | **I32** | 三项共同通过才为 1 |
| 测量状态 | I25 | I25 | 0未测、1测量中、2完成、3中止 |

时间 -1 表示尚未获得有效结果；测试进行中 PASS=0 还不能当作最终结论。超调一旦已超过 0.2°，这一轮就无法通过新标准。

你当前截图的第一个仪表绑定 I60。**若要显示考核的稳定时间，应把它改绑 I61**。另外两个仪表继续绑定 I28（超调）和 I30（稳态误差），建议新增 I62 作为总通过指示。误差和超调显示 4～6 位小数。

## 烧录和核对

按原 Ctrl+Alt+D 重烧录，完成原上电准备，然后发送：

```text
YAW STATUS
YAW PID
YAW VIEW
```

PID 回传应包含：

```text
Y|PID|POS|16.6300,0.1200,0.2690|VEL|0.008100,0.003000,0.000209
```

完整一轮 5 秒后发送 `YAW RESULT`，查看 `VALID=1、FAULT=0、SETTLE02_MS≤250、OS_DEG≤0.2、SSE_VALID=1、abs(SSE_DEG)≤0.2、PASS02=1`。`RESP_MS/RESP02_MS` 是首次进入，`SETTLE_MS/SETTLE02_MS` 是最终稳定，`PASS/PASS02` 是同一份新判定。

结果打印明确包含 `BAND02|0.2`、`TIME_LIMIT_MS`、`OS_LIMIT_DEG|0.2`、`SSE_LIMIT_DEG|0.2` 和 `ASSESSMENT|FINAL_SETTLE`。OS_DEG/SSE_DEG 改为六位小数，`SSE_PEAK_DEG` 是稳态段最大绝对偏差。Pitch 使用 `PITCH RESULT`，同样规则，时限 300 ms。

原遥控重复测试流程保持：CH5 测试档，**CH7中位 → 单轴选方向 → 高位 → 等5秒 → 低位HOME并实际回零静止 → 中位 → 再测**。未触发用 `YAW STEP CHECK` 查原因，无需每轮 READY。
