# 新遥控逻辑迁移与摩擦轮操作

当前Yaw已接入V2F双环及右杆CH1手动目标±50°；CH5中位普通/下位±30阶跃，CH6及CH8仍沿用本页分配。现行串口为921600、48列、Δt5ms，启动步骤及当前通道见[Yaw双环PID与VOFA操作](D:/Project/27电软正式批考核/16_云台调试/01_学习笔记/Yaw双环PID与VOFA操作_20261014.md)。下面115200/50ms/旧遥测通道及“Yaw尚未驱动”是10月13日迁移验收记录。

用户已实测CH5/6上1000、中1500、下2000；CH7/8相同，下拨松手回1500。失联预设CH1～4及CH7=1500，CH5/6/8=1000，已获用户正常反馈。

当前遥控配置为ASSESSMENT_CH5_CH8_V1，保留既有DUAL_RPM6000_I2000_V1摩擦轮版本。flywheel_speed、flywheel_jog、can_bus的.c/.h未改；目标6000rpm/42000ERPM、PI、滤波、斜坡、方向、2A限幅及原保护数值全部保留。本次只迁移遥控映射、启停适配和后续请求接口。云台、拨盘实际驱动仍关闭，flywheels_ready仍0。

## 操作分配

| 通道 | 上档1000 | 中档1500 | 下档2000 |
| --- | --- | --- | --- |
| CH5 | 总关闭 | 正常模式 | 测试模式，禁止摩擦轮和拨盘 |
| CH6 | 摩擦轮关闭 | 两轮开启，单发模式接口 | 两轮开启，连发模式接口 |
| CH7 | 测试回参考角接口 | 测试待命 | 确认一次所选阶跃接口，松手回中 |
| CH8 | 安全锁/失联标记，总撤权 | 扳机释放 | 扳机按住，松手回中；本次拨盘不动作 |

右大摇杆CH1/2只发布Yaw/Pitch请求，CH1不再启动摩擦轮，回中也不关闭摩擦轮。左大摇杆在测试中选择Yaw(CH4)/Pitch(CH3)±30°；CH7按钮确认，斜向输入不产生事件。按钮释放不清除已发布的阶跃目标；CH7上档发布回参考角事件。云台尚未接入，这些接口当前不产生电机运动。

## 1. 同一工程重新构建、烧录

1. 断开电机动力，保留主控和接收机供电。CH5/6上档、CH7/8中档，两个大摇杆全部回中；左纵轴不自动回中时手动置中。
2. 在原[工作区](../Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace)执行“eide: 重新构建”。确认成功后Ctrl+Alt+D，使用现有ST-Link烧录。
3. USART1、115200/8N1、VOFA FireWater、数据间隔50ms。发送REMOTE INFO并带换行，应返回：

```text
R|INFO|ASSESSMENT_CH5_CH8_V1|MODE_CH|5|WHEEL_CH|6|STEP_CH|7|TRIGGER_CH|8|FAILSAFE_CH|8|FAILSAFE|LOW|WHEEL|AUTO_BOTH|OTHER_DRIVERS|0
```

4. 发送WHEEL INFO核对仍为DUAL_RPM6000_I2000_V1，TARGET_RPM=6000、TARGET_ERPM=42000、左右限幅2000mA及原参数；遥控版本以REMOTE INFO单独区分。

## 2. 先断动力看请求

CH5先上档保持至少0.5秒，再到中档；I11应为1。CH6中档：I18=1、I19=1；下档：I18=1、I19=2；上档：I18=0。断动力时没有两轮健康反馈，不会运行，I12/I35可为0。CH8上档使I11归0；返回中档不会自动解锁，须CH6上档、各摇杆回中，再CH5上→中。

## 3. 摩擦轮上电与开启

1. CH5/6上档、CH7/8中档、大摇杆回中，给两只摩擦轮电调上电。等至少1秒，两轮反馈正常且机械停稳。
2. 程序在新的安全OFF帧中自动准备双轮，I33应为3，I36为0；CH5继续上档至少0.5秒，让准备后的新OFF帧通过。无需WHEEL BOTH或推住CH1。
3. CH5到中档，确认I11=1；随后CH6到中档，两轮进入既有6000rpm控制。I18=1、I35=1、I12=1。
4. 实时速度看I29/I30 ERPM，原有滤波估算轮速看I41/I47；两轮给定为I34/I44，故障为I36。I41/I47仍按原7对极配置估算，本次未修改轮速换算。
5. 首次确认CH6上档能停止给定后再延长运行。中档与下档切换仅改变单连发接口，两轮保持原6000rpm控制，不重新启动，也不驱动拨盘。

## 4. 关闭、恢复与故障

- CH6上档：正常关闭，两轮给定归0，I18/I35归0；总解锁I11可保持1。等两轮机械停稳，再CH6中/下档重新开启。尚未停稳时ON不会延迟自动启动，须再OFF后ON。
- CH5上档、CH8上档或遥控失联：撤权并双零停机。恢复信号/CH8中档不自动解锁；先CH6上档、CH7/8中档、各大摇杆回中，再CH5上档保持至少0.5秒→中档。
- CH5下档进入测试：两轮关闭。回到正常模式时若CH6仍在ON档，不恢复运行；先CH6上档，再中/下档。
- 故障时先保存WHEEL STATUS、WHEEL SPEED及触发前后的曲线。健康反馈恢复且双轮停稳后，CH5/6上档安全流程可重新准备双轮；CAN故障代次非0仍须断动力后复位，原规则保留。
- 0mA是原有滑行停机，机械轮子可能继续转动。软件自检不能替代新映射的实机保护验收。

## 命令与证据

REMOTE INFO、WHEEL INFO/STATUS/SPEED只读；STOP和WHEEL OFF仍撤权停机。新遥控配置中WHEEL LEFT/RIGHT/BOTH返回W|ERROR|REMOTE_CONTROL，避免串口选择与CH6控制混用。DIAG ON期间停止并取消选择，自动准备暂停；DIAG OFF后仍需安全OFF流程。
