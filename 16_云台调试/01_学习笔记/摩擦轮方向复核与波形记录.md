# 摩擦轮方向版：先复核左顺右逆，再保存数据

用户明确目标左轮顺时针、右轮逆时针。当前左轮从外侧正对轮面看为逆时针；当前右轮已确认逆时针、符合目标。方向版仅改变左CAN2节点70的SET_CURRENT极性：左0..-200mA、右0..+200mA。原遥控映射、默认OFF、两轮停转反馈检查、0.2A幅值、500ms、双零停机及保护条件保留。没有电调参数写入，没有遥控切换运行方向的入口。

后续更新：用户反馈左给定已为负但方向仍疑似相反，请求稍加电流。最新源码仅把左幅值改为300mA，右仍200mA，并增加WHEEL INFO；按[0.3A步骤](左轮0.3A点动与版本核对.md)操作，下文200mA为前一档记录。

## 下载并做一次方向复核

用户指定只通过VS Code/EIDE + ST-Link在原工程编译烧录。后续指导使用下面的IDE步骤，不提供单独固件文件下载。

1. CH1回中、CH5 OFF，WHEEL OFF。断开执行器动力，待全部停稳。清空发射机构，保持飞行动力及GL/DM/C610动力隔离。
2. 在VS Code原Gimbal_Control工作区选择同名目标，Ctrl+Shift+P执行“eide: 重新构建”，等待构建成功后Ctrl+Alt+D执行“eide: 烧录”。现有配置是ST-Link/SWD，使用本工程刚生成的输出。方向修改已在原源码中，LEFT_CURRENT_SIGN=-1、RIGHT_CURRENT_SIGN=1；App仍16个源文件，无需新增分组或另选固件文件。
3. 主控USART1仍115200/8N1，遥控接线及配置不变。先逻辑电源观察未选轮、给定0，再给摩擦轮电调上电并等待反馈稳定。
4. WHEEL LEFT成功后，保持CH1中位、CH6高位、CH5 OFF至少0.5秒，再CH5 ON；确认12和38为1。向CH1数值增大的方向短推一次并回中，观察同一视角下左轮是否改为顺时针。I34应为负给定，幅度<=200mA；未选右轮给定始终0。
5. CH5 OFF、WHEEL OFF，待停稳。再WHEEL RIGHT，按相同流程短推，确认右轮仍为用户目标逆时针。I34为正给定，幅度<=200mA。
6. 任一轮仍与目标相反、明显抖动/异响或出现非零故障，立即OFF，停止本轮测试并记录；不要改极性运行中反复试，也不要增加电流。软件极性已更改不能代替实物复核。

## 校正VOFA设置，保留单次点动段

原截图使用VOFA+1.3.10，Δt=5ms；原始接收时间戳约50ms一包，与APP_TELEMETRY_PERIOD_MS=50一致。把Δt改50ms，只校正时间换算，不会把已接收数据丢掉。[VOFA官方说明](https://www.vofa.plus/docs/learning/widgets/wave/)

先保存已有原始接收TXT/CSV，含gimbal的完整39字段及可用时间戳。鼠标放在横轴上滚轮缩放，截取一次点动前后约3～5秒；长历史总览中的多组尖峰不能全部归入本次点动。右键选择时间T为X，勾选所需Y通道并保留通道标识。旧图左I29、右I31已由用户确认。

建议按同一时间轴保存：

| 通道 | 含义 | 作用 |
| --- | --- | --- |
| I29 / I30 | 左 / 右ERPM | 判断实际反馈、未选轮情况 |
| I31 / I32 | 左 / 右反馈电流mA | 与给定比较；分辨率100mA |
| I34 | 所选轮带符号给定mA | 左负、右正；峰值看绝对值 |
| I35 | 点动活动0/1 | 标出启动和取消窗口 |
| I36 | 点动故障位 | 与ERPM尖峰及停止时刻对应 |

完成左右各一次方向复核后提供原始数据及近景波形，注明观察方向、是否手拨、是否抖动/异响。可以附慢动作视频，记录拍摄帧率与回放设置。已有原始数据优先保存；仅为调整Δt或放大画面无需再次点动。
