# Yaw平滑阶跃与参考速度前馈（V2K）

此版针对阶跃引起的回摆，增加可关闭的五次多项式参考轨迹、参考速度前馈和规划段外环积分冻结。默认关闭，原双环PID和六个力矩前馈参数仍保留。它是可对照验证的控制改动，尚未证明实机达到250 ms。

固件版本：`GL60II_CASCADE_SHAPE_V2K`。沿用原EIDE工作区重新构建、烧录；本次只做软件构建，没有连接串口、使能电机或烧录硬件。Pitch控制、原遥控流程和CAN发送周期未改。

## 1. 先分清两个开关

- `YAW FF ON/OFF`：控制原FBIAS/FANG/FKV/FC/FVS/FMAX力矩补偿，原I48表示它的开关。
- `YAW SHAPE 160`：让下一次正式Yaw阶跃使用160 ms平滑轨迹。参考速度前馈随这个模式一起工作，**不要求旧FF开关开启**。
- `YAW SHAPE 0`：关闭平滑模式，下一次正式阶跃使用原算法。
- `YAW SHAPE`：只读查询。`ENABLED|1|MS|160|ACTIVE|0`表示已经配置，当前没有正在执行的规划段；不代表配置丢失。

上电/MCU复位后SHAPE=0，旧FF也默认关闭。SHAPE配置只在RAM中，普通停机和重新设零保留规划时间，但取消正在执行的轨迹。配置本身不会启动电机。

## 2. 改动实际做了什么

只在串口`YAW STEP ±30`或原遥控Yaw阶跃入口生效；手动摇杆、HOME和普通TARGET保留原行为。

设原命令接受时刻为t0、规划时间T、实测起点p0、最终目标g，令s=(t-t0)/T。在0≤s<1期间：

```text
p_ref = p0 + (g-p0) * (10*s^3 - 15*s^4 + 6*s^5)
v_ref = (g-p0)/T   * 30*s^2*(1-s)^2
a_ref = (g-p0)/T^2 * 60*s*(1-s)*(1-2*s)

内环目标速度 = v_ref + Kp位置*(p_ref-p实际)
             + 位置积分 - Kd位置*(v估算-v_ref)
```

T以秒计算。两端参考速度、参考加速度均为0，规划位置单调到达最终目标。规划段保留但暂停积累外环积分；速度环积分、估速滤波和总力矩抗饱和继续按实际CAN反馈运行。到T后参考恰为最终目标、参考速度和加速度归零，继续原双环保持，外环积分恢复更新。

新速度前馈的单位是°/s，进入速度参考；与原FKV乘目标速度后产生协议力矩的作用位置不同。`a_ref`只用于观察，**本版没有惯量力矩前馈/FKA，也没有对理想角度阶跃求导**。

30°/160 ms规划的参考峰值速度约351.56°/s，峰值参考加速度约6765.8°/s²。缩短T会提高速度及加速度要求，不能用不断缩短T替代验证。

参考轨迹叠加闭环是常见做法，参见[WPILib的轨迹与PID组合](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/controllers/profiled-pidcontroller.html)和[ODrive的位置输入滤波与速度前馈](https://docs.odriverobotics.com/v/latest/manual/control.html)。本工程采用上面的五次多项式实现，并非直接移植这些库。

## 3. 验收口径保持原样

- I1和RESULT的TARGET始终为最终±30°；I66另行显示内部参考。
- STEP计时从原命令接受时刻t0开始，**包含全部规划时间**。
- RESP05、SETTLE05都以实际编码器角相对最终30°的±0.5°计算。
- 保持原5秒完整观察窗口，仍看`SETTLE05_MS≤250`和`PASS05|1`。
- RESULT增加`SHAPE_MS`，冻结本轮实际使用的配置；之后改配置不改变历史成绩。
- 内部规划完成不等于机械已停稳，也不等于通过考核。

若考核另行禁止任何内部轨迹规划，使用SHAPE=0；评估模式不得隐藏内部参考和原始目标。

## 4. 第一次实测按这个顺序

先沿用原物理基准/遥控准备、重新构建烧录。串口921600、8N1、FireWater、Δt=5 ms不变。版本应为V2K，Yaw VIEW应回报70列。

用户最新截图中的速度P=0.0073、I=0.010已高于前面较平稳的起点，不能期待规划模式自动稳定这组PID。以下是用于A/B对照的较温和起点，**不是已实测合格参数**：

```text
YAW FF OFF
YAW SHAPE 0
YAW POS 9 0.2 0.05
YAW VEL 0.003 0.003 0
YAW PID
YAW SHAPE
```

逐条等待回复。改PID清两环积分；等零位重新停稳并保持至少5秒。后续两种模式使用相同负载、Pitch姿态、线束走向、回零等待和遥控状态。不要为了每次试验重新READY。

### A：先记录原算法

1. `YAW HOME`，等实际角/目标角都在0±0.2°且停稳，保持至少5秒。
2. `YAW STEP 30`，期间不改参数，等完整5秒。
3. `TELEM OFF`，`YAW RESULT`，保存完整结果，再`TELEM ON`。TELEM OFF只暂停发送波形，不停控制和统计。

### B：只开启新模式

1. `YAW HOME`，同样回零停稳并保持至少5秒。
2. `YAW SHAPE 160`，应回复`Y|OK|SHAPE|MS|160`。
3. `YAW SHAPE`确认`ENABLED|1|MS|160`。旧FF保持OFF。
4. `YAW STEP 30`，等完整5秒；保存RESULT和三组曲线。RESULT应有`SHAPE_MS|160`。
5. 每个模式至少重复两次。比较SETTLE05、回摆最低角、超调、总请求与速度跟踪，不凭第一峰高低作结论。

如果振荡幅度增加，按原CH5 OFF/STOP流程停机，随后在测试不运行时`YAW SHAPE 0`恢复对照模式。只发FF OFF不会关闭SHAPE，反过来也一样。

先完成0与160的对比。若160确实减轻回摆但速度不足，再单独试140 ms；若140又明显增加回摆，恢复160。时间设置为80~500整数ms或0，但首轮不扫整个范围，不同时改PID与旧前馈。为了250 ms目标，T过长会挤占实际跟踪与稳定的时间预算。

## 5. 在已有VOFA面板加一个控件

不需要重做原面板。新增一个规划时间滑条和两个固定按钮：

| 控件 | Str命令（末尾另加真实LF） | 设置/回读 |
| --- | --- | --- |
| YAW SHAPE时间 | `YAW SHAPE %f` | from=80、to=240、step=10、小数位0；绑定数据I64 |
| SHAPE OFF按钮 | `YAW SHAPE 0` | 只在按下时发一次；不能循环 |
| SHAPE查询按钮 | `YAW SHAPE` | 只在按下时发一次；不能循环 |

滑条先设置范围和初值再绑定命令。`160.000000`可被接受，但非整数160.5、NaN、负数和1~79均拒绝。滑条窗口80~240不含关闭值0，单独使用OFF按钮；不要设置循环发送。

完整测试运行中改变SHAPE时间会拒绝，待DONE或STOP后再改。规划运动段改PID/旧FF参数也会拒绝；FF OFF、HOME和STOP仍可按原方式使用。HOME/手动接管会取消规划并中止本轮测试。通信、温度、行程、遥控和停机保护仍按原流程工作。

## 6. 能改善什么、仍需验证什么

它用于减少目标突变带来的机械激励，并用参考速度减少单纯平滑目标造成的跟踪滞后。它不能证明振荡来自哪一部分，也不能替代负载模型、合理的反馈增益、刚性连接和实际反馈时序。若规划开关两种状态下都存在类似的持续振荡，需要进一步用角度、速度、力矩时间序列检查闭环/结构，不能直接猜陷波频率或随意叠加扰动观测器。

软件自检验证了轨迹边界与连续性、正反向/时钟回绕、关模式计算等价、积分处理、停机/手动接管、命令与遥控入口、从原始指令起计时，以及Pitch回归。模拟反馈用于验证软件行为，**不是真实负载仿真或实机性能证明**。完整记录见`02_过程记录/Yaw平滑阶跃_20261017`。
