# 左轮0.3A点动与板上版本核对

此页保留0.3A档历史步骤。用户已反馈本档方向正确；当前源码为左0.4A/右0.2A，继续操作请使用[最新0.4A步骤](左轮0.4A点动与版本核对.md)。

用户反馈方向版左轮仍疑似逆时针，点动时I34约0到-200，说明观测到的遥测给定已为负。当前不能确定小幅动作是持续旋转还是起动摆动，也没有新的原始曲线。应保持左负极性，先按用户请求做下一档小幅电流测试，不重新翻转极性或提高转速阈值。

最新源码版本JOG_L300_R200_V1：仅左轮最高幅值0.2A→0.3A，右轮仍0.2A；默认OFF、100mA/20ms幅值斜率、500ms、两轮停转与反馈新鲜、2000ERPM、1A反馈监测及60℃保护保留。电调20A历史配置不变，软件给定限制不能代表瞬时硬件过流限制。零电流为滑行。

## 只用VS Code烧录

1. CH1回中、CH5 OFF，WHEEL OFF，等停稳；断开电机动力。保持其他执行器动力隔离。
2. 在原Gimbal_Control工作区执行“eide: 重新构建”，确认成功后Ctrl+Alt+D烧录。沿用ST-Link/SWD配置，本助手不连接烧录器，不发送独立.hex文件。
3. 复位后，USART1按115200/8N1连接VOFA，CH5保持OFF。先发送只读命令：

```text
WHEEL INFO
```

应回复：

```text
W|INFO|JOG_L300_R200_V1|LEFT_MA|300|RIGHT_MA|200|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|500|ERPM|2000|ENABLED|1
```

此命令没有CAN发送、不选轮、不解锁。无回复、版本不一致或ENABLED不是1时，先核对当前工作区/目标与VS Code烧录日志，不用运动来猜版本。查询回应TX失败会触发原UART停止保护。

## 一次左轮观察

1. 保持CH1中位、CH5 OFF、CH6高位；给两只摩擦轮电调上电，待反馈稳定，WHEEL LEFT成功后OFF回中至少0.5秒，再CH5 ON。确认I12/I38为1。
2. VOFA Δt=50ms；记录I29转速、I31反馈电流、I34给定、I35活动、I36故障。保留原始数据，放大单次触发前后3～5秒。
3. CH1向通道值增大的方向短推一次后回中。左I34应按0、-100、-200、-300附近斜坡变化，最多-300；右轮保持零给定。视角与上次一致：正对左轮外侧轮面。
4. CH5 OFF、WHEEL OFF，待停稳。报告左轮是持续顺时针/持续逆时针/仅抖动，及I34峰值、I29波形和I36。
5. 若左轮仍持续逆时针，或有明显抖动、异响、故障位非零，停止本轮；下一步核对电调运行反馈和相序/配置，不继续堆电流、调高ERPM上限或反复改变符号。上电不能用手拨动轮子。

这次测试用于观察方向与起动。没有完成6000rpm稳速、机械轮速标定或射击测试。
