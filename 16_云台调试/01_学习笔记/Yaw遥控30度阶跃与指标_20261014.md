**现行V2B双环指南：** `GL60II_CASCADE_STEP30_V2B`，取消双环180/.10业务限幅，保留48列和六PID；请按[双环PID与VOFA操作](D:/Project/27电软正式批考核/16_云台调试/01_学习笔记/Yaw双环PID与VOFA操作_20261014.md)操作。下列V1H/V1F为历史，旧70列及单环命令不适用。

## V1H当前操作：一次设零准备，再遥控阶跃

当前源码 **GL60II_PID_STEP30_V1H**：按用户明确要求取消生产考核档60°/s停机和40°/s抑制；不是把门限改大，活动状态不按速度触发FAULT16。原速度关联的位置跳变判据改为独立的1200°/s×帧间隔+1°通信连续性检查，避免用原60门槛换成FAULT32。直接30°目标、PID1/0/0.015、±0.10协议请求及原遥控保持，没有增加慢启动。CH5停机、通信撤权、±40°位置范围等保留。YAW READY/PID/BUS继续可用。完整构建0错误0警告，38组365533项检查通过；代理未烧录，V1H待实测。

1. 在原VS Code/EIDE工作区重新构建，再用ST-Link烧录；版本必须是V1H；V1G仍有60°/s停机，V1F没有READY/PID/BUS命令。全程CH5/CH6上位、CH7/CH8中位、摇杆回中。既有CAN故障会话须先整机主电源及所有可能供电的USB/ST-Link/串口连接均断开，确认指示灯熄灭至少10秒，再按现场统一供电重新上电；不拆单个电机动力线。
2. 确认软件零点处左右各有至少40°空间，姿态放稳且手离开。VOFA为115200/8N1、FireWater70列、Δt=50ms。正常上电尚未FD监测时ONLINE0/RX0不能直接推断电机没供电；READY会在请求关闭状态建立监测。
3. 当前会话若仍在诊断模式，先发送DIAG OFF。之后点击“设零并准备”按钮（Str `YAW READY`加真实换行）。收到BUSY后保持所有拨杆不动，最长5秒；仅收到 `Y|OK|READY|ZERO_SET|1|REQUESTED|1|ACTIVE|0|NEXT|CH5_TEST` 才能继续。它确认已人工软件设零并完成FD停机屏障，尚未使能。没有成功就不往下做，不反复重发或清错。
4. CH6保持1000、CH7/8保持1500、摇杆回中，CH5由上位1000直接拨到下位2000，等约1秒。发送YAW STATUS，确认ACTIVE1/STATUS1/FAULT0/ZERO_SET1/STOP_PENDING0且ANGLE、TARGET均在±0.2°内；用户本地核对后继续，无需逐条等代理回复。中位1500是正常模式，不是测试位；中位不是必经解锁条件。
5. 左摇杆水平向右选+30°（CH4高、CH3中），CH7中→弹簧下位2000确认一次，约0.3秒后CH7和摇杆回中。必须收到 `Y|REMOTE_STEP|...|RESULT|STARTED|TARGET|30.0` 才表示接受。START_GUARD并非开始，不排队、不自动重试。
6. 保持5秒不碰云台、不改PID，自动Y|STEP报告后仍闭环保持30°；缺失显示可YAW RESULT只读重查。回零用CH7上位1000后回中；结束/明显异常用CH5上位撤权，必要时YAW OFF。

任一步ERROR或故障则停止当前轮。CAN相关错误先读YAW BUS和YAW STATUS保留现场；不扩大保护、不持续清错、不自动重启。±0.2°启动门禁与0.10协议力矩请求保持，当前参数仍可能有负载静差，READY不保证物理闭环到位。

### 常用VOFA控件

| 控件 | 发送内容 | 含义 |
| --- | --- | --- |
| 设零并准备按钮 | YAW READY | OFF静止安全条件下发起一次准备，等自动READY成功 |
| 停机按钮 | YAW OFF | 取消READY并撤销Yaw请求 |
| 仅设零按钮（保留） | YAW ZERO | 已监测且真实失能静止时设置软件零点；不发FE |
| PID整组输入/宏 | YAW PID 1 0 0.015 | P/I/D分别为0..2、0..1、0..0.2；整组校验再原子更新 |
| 原三个PID滑块 | YAW KP %f / YAW KI %f / YAW KD %f | 原单项热调继续兼容 |
| 状态按钮 | YAW STATUS | 只读；REQUESTED是串口准备意愿，不是CH5实际位置 |
| 结果按钮 | YAW RESULT | 只读重查最近一轮，自动报告仍保留 |
| 通信诊断按钮 | YAW BUS | 无需DIAG ON，纯读取两路CAN首次/末次/HAL累计错误和计数 |

5秒测量期间改PID会把本轮标成PID_CHANGE并保持目标；完成后可热调，但旧报告参数/结果不会被改写，需回零并重新触发新轮。控件使用Str/ASCII加真实LF或CR；不把文字反斜杠n当换行。

READY每次最多一次FB；只处理已有允许的状态13人工恢复，不清CAN故障。等待反馈、静止、STOP屏障都是异步状态，Console任务不阻塞等待；超时或遥控失效取消，YAW OFF/全局STOP/DIAG切换取消会话，不在以后补执行。准备期间禁止参数/目标/旧ON等冲突命令；只读查询仍允许。

### 诊断字段

YAW BUS的C1_RX开始第一组CAN1字段，C2_RX开始第二组CAN2字段。每组TX为完成数，ERR为历史错误次数，LAST为应用最近捕获的HAL累计位，HAL为当前HAL累计位（不是刚发生的单一错误），FIRST为本次MCU会话该路第一次故障时的累计位。SOURCE=0无首次故障，1发送提交失败，2读取FIFO失败，3HAL错误回调，4软件接收队列溢出；FIRST_MS为MCU tick。PENDING为是否有待发邮箱。软件队列溢出保留原dropped/epoch统计，不额外算硬件错误。FIRST为0而SOURCE非0也有效，例如提交失败却无HAL硬件错误位。读取不清错误、不发CAN、不取消邮箱，首次记录不被后续错误覆盖。

V1H状态应有 `SOFT_DPS|0.0|HARD_DPS|0.0|SPEED_GUARD|0`。CMD_N为本轮成功提交的力矩请求次数，FIRST_NM为首条请求，TMAX_NM为请求峰值；不是CAN完成确认或实际力矩标定。14:48的10ms超速中止不算到位，N0/TMAX0在旧版不能证明未发力。新版本仍需真实曲线确定PID与考核性能。

## VOFA零点和PID

USART1 115200/8N1、FireWater仍70列/50ms，原I0～I69位置保持。目标/实际角度I52/I51同图，速度I53及力矩请求I54可另图；I56/57/58为MCU实际PID。将截图左下Δt从5改50ms。

| 控件 | Str命令，末尾使用真实LF/CR | 设置 |
| --- | --- | --- |
| 当前姿态设零按钮 | `YAW ZERO` | CH5/6上、CH7/8中、YAW OFF、真实失能且静止时单次点击 |
| KP滑块 | `YAW KP %f` | 0～2，步进0.05 |
| KI滑块 | `YAW KI %f` | 0～1，步进0.01，初轮保持0 |
| KD滑块 | `YAW KD %f` | 0～0.2，步进0.005 |
| 结果查询按钮 | `YAW RESULT` | 只读，可在保持期间查询上一轮指标 |
| Yaw关闭按钮 | `YAW OFF` | 取消准备请求并撤权 |
| 可选目标滑块 | `YAW TARGET %f` | -30～+30，步进1°；主测试由遥控CH7触发 |

软件零点不写电机FE或配置。成功回复SOFTWARE_ZERO，STATUS的ZERO_SET=1；ON和FC准备不会覆盖此人工零点，使能时先保持当前位置而非自动追赶零点。断线/位置跳变使连续角基准失效或MCU复位时须重新设零。若设零后挪动过云台，先CH7上位回到零点并静止，再确认新的30°测试；START_GUARD时先回传STATUS，不反复确认。

PID命令活动时可实时生效。5秒测量中改PID会标ABORTED/PID_CHANGE，仍保持30°目标，避免把两组参数混成一份指标。完成后调PID不会改写旧报告中的PID；回零并用CH7发起新一轮，得到新ID和新指标。目标变化、回零、退出测试或故障也会按原因中止正在进行的统计。

## 板端统计

遥控确认成功的目标接受时刻为t0；随后每个新CAN反馈参与测量，既不依赖VOFAΔt，也不从50ms遥测行推算峰值。观察窗口5秒，结束会自动打印一次 `Y|STEP|…`，继续保持±30°，直至明确回零、停机或故障。`YAW RESULT`重读相同记录。串口格式化/发送只在低优先级Console任务，接收和控制任务仅采样、保存状态，不在临界区printf。

| 字段 | 定义 |
| --- | --- |
| STATE / VALID | DONE/1表示采样窗口完成；ABORTED/0表示中止，不能当作完成响应；RUNNING和IDLE也为0 |
| RESP_MS | 暂定：首次进入目标±0.2°并连续保持至少50ms的进入时刻；-1表示未取得。正式考核口径仍待复核 |
| T90_MS / RISE_MS | 从t0到90%步幅、10%到90%上升时间；不可获得时为-1 |
| SETTLE_MS | 窗口结束时仍连续在带内至少50ms的最后一次进入时刻；-1表示末段未确认稳定 |
| OS_DEG / OS_PCT | 按运动方向统计超过目标的最大采样角度、相对实际步幅的百分比；负向阶跃也取正的超调量 |
| SSE_DEG | 第4～5秒角度的时间加权均值误差，目标减均值；按相邻样本线性积分，不以最后一帧代替 |
| SSE_VALID | 最后1秒完整覆盖、至少10个样本，且采样误差始终在±0.2°内才为1；为0时SSE只是末段均值，不宣称已稳态 |
| PASS | 采样口径同时满足约30°步幅、RESP≤250ms、OS≤0.2°、SSE_VALID1且误差≤0.2°；不是整机正式验收结论 |
| VMAX_DPS / TMAX_NM | 测量期间峰值速度及MCU请求绝对值；超速中止包含触发反馈的速度。TMAX不是实际电流或校准物理力矩 |
| N / GAP_MS / LIMIT_N | 样本数、最大接收间隔、速度抑制被观察到的样本数 |
| KP / KI / KD | 本轮开始时的参数，区别于后续实时调参值 |

测量中止会输出REASON和FAULT，SSE_VALID/PASS清零。反馈间隔达到100ms、坏数据、控制/驱动故障、STOP等不生成虚假的成功结果。当前250ms/0.2°判据依交接的暂定口径实现，不能由软件测试或一帧STATUS宣称实物达标。
