# 云台串口统一指令与启动

启动已进一步简化为 **Yaw V2I / Pitch V1F自动准备**。正常上电托在原水平基准、CH5上位等就绪后拨中档即可，不必逐轴READY；手动重设零点统一GIMBAL READY，STEP/HOME快速测试。优先按[自动启动与快速阶跃](云台自动启动与快速阶跃_20261017.md)执行。下面V2H/V1E手工启动步骤保留历史，七参数/原查询和控件仍适用。

2026-10-17现行版本：Yaw `GL60II_CASCADE_MANUAL50_V2H`，Pitch `DM3507_CASCADE_V1E`。原Gimbal_Control工程、USART1 921600/8N1/FireWater/5ms。源码已更新，用户仍需原EIDE重新构建、Ctrl+Alt+D按原ST-Link流程烧录；没有自动烧录/使能。

## 常用命令速查

两轴用同一结构，下面的AXIS替换为YAW或PITCH；命令为大写ASCII，每条以真实LF/CR结束，逐条发送等回执。VOFA的原命令/六PID控件继续可用。

| 用途 | Yaw | Pitch |
| --- | --- | --- |
| 简洁状态 | `YAW` | `PITCH` |
| 本轴帮助 | `YAW HELP` | `PITCH HELP` |
| 所有调参值 | `YAW PID` | `PITCH PID`（含Kg/水平标定） |
| 准备并设软件零点 | `YAW READY` | `PITCH READY` |
| 关闭输出 | `YAW OFF` | `PITCH OFF`（先支撑负载） |
| 切换波形 | `YAW VIEW` | `PITCH VIEW` |
| 最近阶跃报告 | `YAW RESULT` | `PITCH RESULT` |
| 整组位置PID | `YAW POS kp ki kd` | `PITCH POS kp ki kd` |
| 整组速度PID | `YAW VEL kp ki kd` | `PITCH VEL kp ki kd` |
| 单项调参 | `YAW PKP/PKI/PKD/VKP/VKI/VKD 值` | `PITCH PKP/PKI/PKD/VKP/VKI/VKD 值` |
| 完整诊断快照 | `YAW STATUS` / `YAW INFO` | `PITCH STATUS` / `PITCH INFO` |

`HELP`显示总帮助。`TELEM OFF`暂停连续波形，方便读文字；`TELEM ON`恢复。暂停不改变控制、遥控保护、查询和阶跃/故障报告，切VIEW只换组、不自动解除暂停。旧TELEM YAW/PITCH和原调参指令保留。

裸轴命令是纯快照：版本、ONLINE、ACTIVE、REQUESTED、ZERO_SET、FAULT、AGE_MS、ANGLE、TARGET、VEL_DPS、TORQUE_NM；Pitch另有KG/G_CAL。ACTIVE表示当前控制活动，REQUESTED是准备请求；两者不同。更详细状态仍使用STATUS。

## 固化的启动默认

| 参数 | Yaw | Pitch |
| --- | --- | --- |
| 位置KP/KI/KD | 10 / 0.15 / 0.01 | **18.2 / 0.44 / 0.04** |
| 速度KP/KI/KD | 0.0037 / 0.003 / 0.000001 | **0.0065 / 0.014 / 0.000004** |
| 重力Kg | 无该项 | **−0.13** |

这些值随固件保存在Flash，每次MCU重启自动载入。VOFA改参仍只影响当前RAM，会话内OFF保留，重启恢复表中默认；本次没有新增运行时Flash写入/自动保存。

Kg系数与物理水平标定分开：重启、换坐标或反馈超时重建参考后，保留Kg，清除G_CAL/水平偏置；未标定且Kg非0时Pitch不使能，当前前馈输出0。STATUS/FF里的G_REQUIRED1表示还需标水平。普通OFF保留现有标定。不能保存旧编码器参考冒充电机断电后的新零点。

## 烧录后启动Pitch

1. 托住负载，在此前量出上抬20°/低头35°余量的同一物理基准姿态停稳；CH5/CH6上位1000，CH7/CH8中位1500，四杆回中。
2. `PITCH CHECK`，等新反馈摘要，核V1E、ONLINE1、STATUS0、FAULT0、CAN_EPOCH0；若驱动还活动，先支撑后OFF并等失能确认。
3. `PITCH COORD 1`确认已实测的输出反馈换算；`PITCH READY`在该基准捕获软件零点并准备。分别等回执。
4. 如果该基准确实水平，停稳后 `PITCH GHORIZ`。如果基准不水平，保持失能、托到真实水平后GHORIZ，再托回原软件0。GHORIZ只标水平，不重新设零。已知水平偏置也可安全OFF时 `PITCH GOFF 度数`。
5. `PITCH PID`和`PITCH`核七参数及G_CAL1。无需再发送旧的6/0/.02等探索参数。
6. 保持摇杆中立，让CH5先上位收到新OFF帧，再拨**中位1500**进入手动；右杆纵轴CH2控制Pitch、横轴CH1控制Yaw。需要Yaw一起活动时，应先在安全OFF姿态完成YAW READY并等OK。单轴准备不替另一轴设零。

手动两个轴满杆目标速度均90°/s，扣死区后的半杆45°/s，回中保持目标；实际速度取决于PID/负载。Pitch目标仍[-18,+33]、越界保护[-19,+34]，Yaw目标±50/越界保护±60，速度相同不代表角度范围相同。当前CH2数值增大为Pitch正方向（低头），减小为抬头；若物理上推方向不合习惯，只按实际I49核实后调整发射机CH2反向，不改反馈/PID符号。

## 阶跃与保护

CH5下位2000仍是测试模式，右杆不控制目标；左杆CH3选Pitch/CH4选Yaw，CH7下位确认、上位回零、中位释放。Pitch当前仅零→+30°低头，−30°受机械范围拒绝；回零仍到软件0。Yaw保留±30°。本轮没有改变CH3测试方向，发射机是否已REV应以I50核对。

READY只准备，不代替人工遥控解锁；未回中/失联/UART/CAN故障仍撤权并要求人工新OFF，不能靠查询自动恢复。Pitch失能不是制动，停止前支撑负载。当前未标水平会阻止Pitch使能，不可用重新READY隐藏跟随误差。

## 低频诊断

- 两轴STATUS/INFO保留原完整快照，RESULT保留完整5秒报告，新增简洁命令不改变VOFA列序。
- Pitch专有：`PITCH FF`看速度P/I/D、前馈/总力矩；`PITCH KG 值`在线调系数；`PITCH FF OFF`等价Kg0，PID仍可活动；`PITCH GUARD`看冻结的撤权证据。
- Yaw专有：`YAW BUS`看共享CAN计数/首次故障，`YAW CHECK`看清错条件，`YAW CLEAR`保留原人工清通信故障门禁。
- `REMOTE RX`看接收错误/丢字节/重启统计。总STOP仍保留。
- PITCH CHECK会发送CC并启动只读监测；裸PITCH/PITCH PID/STATUS/HELP不发CAN。Yaw CHECK也是纯读诊断，两轴硬件准备流程不同，因此不强行把CHECK实现改成相同行为。
