位置控制在 MCU 内计算，输出形式为位置误差比例、积分和反馈速度阻尼，单位分别为 KP=N·m/rad、KI=N·m/(rad·s)、KD=N·m·s/rad。MIT 报文内部的 `kp`、`kd` 固定为 0，只发送 MCU 计算并限幅的 `t_ff`。VOFA 调的是 MCU 这组三个参数，不是厂家上位机保存的速度环 / 位置环参数。反馈角度对外显示为度，MCU 控制内部使用弧度。

本机 `KT_OUT=0`，不做“扭矩÷KT_OUT”的电流换算。TMAX=10的12位量化步长约0.004884 N·m，零附近存在约±0.002442 N·m的编码偏差；I54显示的是MCU请求，V1C实际发送还经过2028～2067的编码限幅。给定显示为0不代表发送位模式能精确表示零力矩。停止走`0xFD`失能路径；只有发送过`YAW ON`开始监测后，该路径才会周期发送。

## 第一轮：只构建、烧录和确认静止反馈

每轮只执行当前少量步骤，先回传结果，再进入运动。不要把下文后续测试一口气做完。

1. 按现场统一供电方式将整机断电，确认主控供电也已撤销；无需拆电机动力线。连接ST-Link，并按已验证的接法给主控提供烧录所需供电。使用原 [EIDE 工作区](D:/Project/27电软正式批考核/16_云台调试/Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace)，执行“eide: 重新构建”。确认 0 错误后按 Ctrl+Alt+D，用现有 ST-Link 烧录。无需下载独立 `.hex`，也无需另建工程。
2. VOFA 连接主控 USART1 的 USB 转 TTL：115200 / 8N1，协议 FireWater。CH5、CH6 上档，CH7、CH8 中档，两个大摇杆四轴回中。发送 `YAW STATUS`，命令末尾必须有回车或换行；先核对 `requested=0`、`active=0`。断动力时 `online=0` 合理。
3. 本轮指导允许整机重新供电后，保持上述开关位置，发送一次`YAW ON`，仍不拨CH5。这只是准备请求，应回复`Y|OK|PREPARE`；从此MCU周期发送`0xFD`失能命令以取得反馈。观察I59/I61/I63/I64/I65/I69，并再次发送`YAW STATUS`。期望在线、反馈状态为失能、角度静止、反馈计数增加。若I59仍为0，停在本轮，把状态文本反馈出来；程序不会靠试发使能来探测通信。

烧录后首次打开VOFA应看到原I0～I50和新增I51～I69。MCU复位会令Yaw请求及监测归0，此时不会主动发送`0xFD`；电机自身上电 / MCU复位后的行为仍需要实机确认。`YAW ON`之后发出失能，也不能当作机械已经停稳的证据。先保留切断动力的操作条件，再看反馈及实际状态。

首轮回传：重新构建结果、`YAW STATUS` 完整文本，以及 I51、I59、I61、I63、I64、I65、I69 的值。此轮不执行 `YAW TARGET 2`，不做 CH5 解锁。

## 第二轮：确认停机路径后小幅动作

这一轮需在前一轮反馈已确认后进行；具体步骤由对话按实物情况分批给出。

1. 检查机械在参考角两侧至少有首版所需活动空间，反馈静止、失能，CH6上档，CH7/8中档，四轴回中。若用过`YAW OFF`，先在CH5上档安全状态重新发送一次`YAW ON`；等反馈在线且失能。`STOP`保留准备请求，但总解锁撤销，仍必须新的CH5 OFF→中档。
2. CH5 上档保持至少 0.5 s，再人工拨到中档。启动时捕获本次参考角，目标先在本次参考角附近保持。观察 I60 活动、I61 使能以及 I54 输出；先确认 CH5 上档和 `YAW OFF` 都能撤权并令真实电机停下。
3. 按后续指导重新准备、解锁后，发送 `YAW TARGET 2`。对照 I51 实际角度与 I52 目标角度；只改变一个参数，观察后再改下一项。返回参考角用 `YAW TARGET 0`。首次出现明显抖动、持续向边界运动或反馈异常时，执行 `YAW OFF` / `STOP` 并保存状态，等待下一轮分析。

CH8上档及遥控失联会锁定撤权。CH8回中或信号恢复不会自动启动。恢复时CH5/6上档、CH7/8中档、四轴回中、电机停稳；准备请求仍为1时，按反馈完成新的人工CH5 OFF→中档；若已取消请求，再`YAW ON`准备。不要把`YAW ON`配成循环发送。

使能确认超时（I62含65536）或运行中意外失能（含262144）后，先`YAW OFF`，等待新的失能、静止反馈及I65=0，再在安全CH5 OFF状态`YAW ON`，最后人工CH5 OFF→中档。发送失败（含131072）或CAN故障当前锁存，需要断动力、排查原因后复位MCU；复位后重新从首轮准备开始，不能靠重复ON清故障。

正常模式CH1仍按原分配发布Yaw角速度请求，后端将实际手动目标变化速度限制到±10°/s，V1E目标限于±15°；VOFA调参时摇杆保持中位。CH7的±30°接口尚不执行实际30°运动。

`YAW ZERO` 只在 Yaw 已关闭及安全条件满足时，把当前位置捕获为软件参考。它不发送 `0xFE`，不写电机 EEPROM，也不改变厂家电机零点。先确认方向和停机，再讨论正式零点及限位。

## VOFA 控件配置

VOFA 官方说明：Str（ASCII）命令使用 `%f` 等参数占位符，控件可以绑定命令；slider 把当前位置作为浮点参数，并支持最小值、最大值和步进。见 [数据、命令、参数](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/) 与 [slider](https://www.vofa.plus/docs/learning/widgets/slider/)。

在 VOFA 命令区添加以下 Str 命令，然后在控件右键菜单绑定命令。表中 `\n` 表示行尾换行；请按当前 VOFA 命令编辑界面对转义的支持配置，最终串口必须实际发送 LF（0x0A）或 CR（0x0D），不能只发送反斜杠和字母 n。先用手动发送的 `YAW STATUS` 检查命令能收到回复，再绑定滑块。

| 控件 | Str 命令文本 | 范围 / 步进 | 读取绑定 |
| --- | --- | --- | --- |
| 目标角度 slider | `YAW TARGET %f\n` | V1E：-15～+15；1° | I52 |
| KP slider | `YAW KP %f\n` | 0～2；0.05 | I56 |
| KI slider | `YAW KI %f\n` | 0～1；0.01 | I57 |
| KD slider | `YAW KD %f\n` | 0～0.2；0.005 | I58 |
| Yaw 关闭按钮 | `YAW OFF\n` | 按下发一次 | I60 / I64 |
| 总停机按钮 | `STOP\n` | 按下发一次 | I11 / I60 |
| 状态查询按钮 | `YAW STATUS\n` | 按下发一次，只读 | 文本回复 |
| 准备按钮 | `YAW ON\n` | 按下发一次；CH5 OFF安全时使用 | I64 |
| 软件参考捕获按钮 | `YAW ZERO\n` | 按下发一次；Yaw关闭安全时使用 | I51 |

参数热调命令一次只设置一项，例如：

```text
YAW KP 1.0
YAW KI 0
YAW KD 0.015
YAW STATUS
```

每行单独发送并带行尾。初轮保持 KI=0，先观察 KP 和 KD，不同时改变多个参数。I56～I58 是板端返回的当前值，可用于核对控件发送是否生效；控件上的本地滑块值不等于 MCU 已接受参数。串口调参不保存到电机配置；MCU 复位后回到源码默认值。

## V1A补充：通信故障13的人工恢复

用户首轮已取得ONLINE1、STATUS13、FAULT4、AGE3ms、RX1386，说明Yaw反馈接收/解析已有实物证据，驱动仍报告通信丢失。V1A新增 `YAW CLEAR`：先在CH5 OFF安全中位下 `YAW OFF`，保持静止，再人工发送一次。只允许恢复当前通信故障13，不清其他故障，不自动使能，不修改CAN Timeout。`CLEAR_SENT`表示提交，清后继续FD失能；实际效果必须看新反馈。参数、通道和摩擦轮保持。

## V1C补充：带载输出上限与下一轮小角度动作

2026-10-14用户已回传V1B两次I60/I61变1、无明显转动，CH5关闭后STATUS0/ACTIVE0/FAULT0/STOP_PENDING0。该轮目标保持0°，用于短时使能与退出确认，不能由无明显转动认定力矩不足，也未证明运动中机械停止或30°性能。

根据此前带载增大力矩请求，V1C仅将控制器限幅提高至0.10，并将最终发送编码同步调整至2028～2067；STATUS追加 `LIMIT_NM|0.100`。默认PID、70列遥测、遥控、摩擦轮及既有保护条件保留。每次烧录后按实际状态重新准备，不把上一版的REQUESTED/FAULT/参考角沿用到新启动。

提高限幅并不会提高零误差时的P项输出。在重新确认健康准备、使能与退出后，后续对话会指导用VOFA单独设置KP=1.0（仍在允许0～2范围），保持KI=0、KD=0.015，再只试+2°、0°目标。按rad误差计算，KP=1.0的2°纯P项约0.0349协议N·m，默认KP=0.35时约0.0122；实际还包含速度阻尼、量化与限幅，不能据此换算真实电流。该段解释后续参数选择，本轮不提前执行全部动作。
