现行入口：[Yaw/Pitch统一串口指令与启动（V2H/V1E）](云台串口统一指令与启动_20261017.md)。Pitch最终七参已固化、右杆满杆90°/s；以下V1D及更早参数是历史。

现行操作已更新为 **2026-10-17 V1D重力前馈**，请优先按[完整前馈与VOFA操作步骤](Pitch重力前馈与VOFA调参_20261017.md)执行。Pitch现在58列（原0～51保持，52～57新增前馈），六PID控件继续使用，测试/回零仍由遥控触发。以下V1C/V1A“只做CHECK”和逐轮聊天指令是历史流程。

2026-10-17最新版本为V1C：GUARD已定位本次失能来自UART4输入故障代次，具体HAL错误位尚未取得。UART4改独立DMA+IDLE；故障自动输出R|RX，也可只读REMOTE RX查看LAST/RX_ERR/DROP/REARM_ERR。UART错误、100ms超时及人工重新解锁保持。56组软件自检与完整构建通过；原EIDE重烧录后先仅PITCH CHECK。机械基准仍为I13约102.97°，首轮只正30°低头。[实现与验证](../02_过程记录/UART4遥控DMA接收_20261017/实现与验证.md)。

当前版本 `DM3507_CASCADE_V1A`，继续原 `Output/Gimbal_Control` 工程。2026-10-17已取得实机反馈并确认反馈除数1、负方向抬头；曾短暂保持后失能，原因仍待停机记录定位，尚无有效阶跃成绩。失能会下垂，继续支撑负载。

**机械范围已更正：从用户实测的基准姿态，上抬约20°、下俯约35°会碰机械。烧录后必须在同一基准姿态进行READY设零。目标范围-18°～+33°，越界保护-19°～+34°，替代历史±50°。首轮采用正30°低头，负30°因越界明确拒绝。** 10:38:24该姿态在旧零点下ANGLE=0.071°，旧坐标端点约[-19.929,+35.071]；新零点与新限位按该姿态重新建立，不把旧快照当作新固件零点。

## 本轮只做反馈检查

1. 托住Pitch负载并保持刚才实测行程的基准姿态。CH5、CH6上位1000；CH7、CH8中位1500；四个摇杆回中。
2. 打开原EIDE工作区，重新加载VS Code窗口，确认App分组有 `dm3507.c`、`pitch_controller.c`、`pitch_step.c`、`pitch_backend.c`、`pitch_console.c`。执行“重新构建”，成功后按原ST-Link流程Ctrl+Alt+D烧录。重新烧录期间继续支撑负载。
3. VOFA设USART1为921600、8N1、FireWater、Δt=5ms。UART4接收机仍115200。COM号按现场现有连接选择。
4. 本轮唯一串口测试指令：`PITCH CHECK`，结尾发送真实LF或CR。复制所有 `P|` 开头的完整回复，包括BUSY和后续CHECK摘要，回传后再决定下一条。

CHECK显式启动每10ms一次的CC只读状态监测，不发送使能FC、失能FD、永久设零FE或参数写入。摘要会报告版本、真实Pitch反馈数量、在线/年龄、状态/故障/温度、原始rad/rad/s、六个实际PID、软件零点及坐标确认情况。上电不会自动启动监测或使能。若驱动原本已使能，查询不会自动改变这个状态，仍按回传处理。

## 后续接口参考

以下不是本轮执行清单。每次根据上轮回复只选一条指令。

- `PITCH STATUS`：读取当前快照；`PITCH CHECK`：请求新反馈摘要。
- `PITCH COORD 1` / `PITCH COORD 7`：关闭、健康反馈及安全遥控条件下确认反馈换算。1表示反馈已是输出轴，7表示需要除以7；必须依据实际角度变化确认，不能仅凭Gr=7选择。改坐标会取消软件零点。
- `PITCH READY`：在负载支撑于实测行程基准姿态、CH5/6上、CH7/8中及四杆回中的条件下，最多等待1000ms取得新鲜关闭/静止反馈并捕获软件零点、设置准备请求。READY不发送FC/FD，也不执行阶跃。成功后仍需新OFF帧和人工CH5上→中或上→下解锁；解锁会使能并保持当时姿态。重复发送且仍已准备/失能/健康时返回ALREADY_READY，保留原零点，不重复准备。
- `PITCH ZERO`：只捕获RAM软件零点，不写电机永久零点。MCU复位后重新确认姿态并设零。
- `PITCH STEP 30`：活动、健康且静止近软件0时接受真正正30°低头阶跃，保持目标，测量5秒后继续保持。`PITCH STEP -30`超出当前机械范围，明确拒绝；拒绝命令不排队补执行。
- `PITCH TARGET 0`：活动状态回软件0，为下一轮重复阶跃准备；回零不冒充30°测量成绩。
- `PITCH RESULT`：重读最近阶跃报告；`PITCH PID`：只读当前六参数。
- `PITCH GUARD`：纯读最近一次撤权证据及Pitch后端停机原因，不发CAN或改状态。首次撤权后自动输出同类P|GUARD摘要；之后的STOP/OFF和遥控恢复不覆盖该次首次原因，下一次成功解锁后的新撤权再更新。
- `PITCH OFF`、总STOP、CH5关闭、CH8锁定/失联都会撤权，已发生使能的Pitch会执行失能流程。失能确认不表示机械保持，执行前必须支撑负载。TIMEOUT=0的驱动行为仍待实机确认，软件不保证MCU掉电后仍能停机或保持。

首次运动目标按交接直接30°阶跃，不安排1°、2°、5°逐级试车。基础反馈、输出坐标、软件零点和准备状态必须先确认。初始PID没有重力前馈，准备与首次测试时继续托住负载，不把ACTIVE当作已经验证的带载保持能力。

## 六个PID控件

初始值是调试起点，尚未实机调定。位置用°、速度用°/s、力矩用DM协议Nm；实际输出轴力矩未独立标定。两环D对测量求导，位置差分速度做滤波，新CAN反馈才推进积分。位置外环速度参考不设业务限幅；速度内环只有协议±10端点饱和及抗积分饱和，不设低幅力矩档。

| 控件 | ASCII模板 | Pitch组反馈 | 初始值 | 输入范围 / 建议步进 |
| --- | --- | --- | --- | --- |
| 位置KP | `PITCH PKP %f` | I7 | 12 | 0～100 / 0.5 |
| 位置KI | `PITCH PKI %f` | I8 | 0.2 | 0～30 / 0.05 |
| 位置KD | `PITCH PKD %f` | I9 | 0.02 | 0～10 / 0.01 |
| 速度KP | `PITCH VKP %f` | I10 | 0.02 | 0～1 / 0.001 |
| 速度KI | `PITCH VKI %f` | I11 | 0.03 | 0～10 / 0.005 |
| 速度KD | `PITCH VKD %f` | I12 | 0.00005 | 0～0.02 / 0.00001 |

控件发送真实换行，并以主控回传的六值确认生效。整组设置接口为 `PITCH POS kp ki kd`、`PITCH VEL kp ki kd`。这些输入范围不是PID输出限幅。实际变参清控制积分、保持目标并中止当前测量为PID_CHANGE；同值写入不清积分、不中止。在线改参只影响RAM，主控复位恢复app_config.h的初值。

## 两个明确的数据组

上电默认 `gimbal:`，保留原Yaw I0～I47语义。`TELEM PITCH`明确切到 `pitch:`48列，`TELEM YAW`切回原组。一次只发一个组，避免在921600/5ms下拼接96列。Pitch控件的命令必须为PITCH，不能沿用YAW命令后以为在调Pitch。

| Pitch组通道 | 含义 |

| I0 / I1 | 相对软件零点实际角 / 目标角，°；ZERO_SET=0时不作为已标定输出角 |
| I2 / I3 / I4 | 外环目标速度 / 内环使用的位置差分滤波速度 / 原始反馈换算速度，°/s |
| I5 / I6 | MCU力矩请求 / 电机反馈协议力矩 |
| I7～I9 / I10～I12 | 位置 / 速度环的实际KP、KI、KD |
| I13 | 原始位置按当前divisor换算的绝对角，未减软件零点 |
| I14～I17 | 在线 / 活动 / 准备请求 / 驱动状态 |
| I18～I21 | 故障位 / 反馈年龄ms / 停机待确认 / 软件零点已设 |

## 遥控与成绩

普通模式CH5中，右杆CH2上下控制Pitch手动目标速度，满杆±45°/s，回中保持最后目标，目标限定-18°～+33°；45°/s仅为手动映射，不是阶跃闭环速度限幅。测试模式CH5下，CH3单轴选Pitch方向、CH4回中，CH7下确认一次；当前仅正30°在范围内，负30°拒绝，松回中保持已接受目标。斜向不产生阶跃。CH7上回参考时明确单轴优先，左杆回中则使用最后实际接受的阶跃轴；串口接受的阶跃也更新轴记忆，不让Pitch操作误驱动Yaw。

RESP_MS是首次新反馈进入目标±0.2°；SETTLE_MS是5秒窗口末仍在带内至少50ms的最后进入时间。SSE有效要求完整末秒及足够有效样本、末秒均在带内。DONE、VALID、SSE_VALID、FAULT和采样质量一起检查；中止、RUNNING和无效误差不算成绩。Pitch软件PASS使用约30°、首次响应≤300ms、超调≤0.2°及有效稳态误差≤0.2°。正式响应时间口径仍待考核方确认，软件PASS不证明300ms内完全稳定。当前机械范围下先取得同负载、同零点的正30°重复实测；反向30°方案需另选位于实际行程内的起止点，不能沿用零到-30°。
