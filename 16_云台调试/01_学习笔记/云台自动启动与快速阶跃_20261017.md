# 云台自动启动与快速阶跃

现行版本：Yaw `GL60II_CASCADE_MANUAL50_V2I` / Pitch `DM3507_CASCADE_V1F`。2026-10-17源码及软件验证完成，用户需原EIDE重新构建、Ctrl+Alt+D按原ST-Link流程烧录。没有代用户连接串口、烧录或控制电机。

## 正常上电：不需要串口命令

1. 托住Pitch，放在之前测出抬头20°/低头35°余量的**同一水平物理基准**；Yaw放在本次希望作为0°的中位。CH5、CH6上位1000，CH7、CH8中位1500，四个摇杆回中。
2. 上电后保持约1秒，让系统确认健康失能反馈、静止并自动建立双轴零点/水平补偿。串口连接时会看到 `G|AUTO|PHASE|READY|REASON|NONE|READY|1|REFERENCE|1`；正常使用无需打开串口。若未准备好，拨中档不会排队等待后突然启动，应回上位等就绪再拨。
3. CH5拨中档1500，等云台独立保持后使用右摇杆：左右CH1控制Yaw、上下CH2控制Pitch，满杆均90°/s，回中保持目标。CH6仍上位。

开机CH5已经在中/下档时不自启；先回上位、回中，再拨中档，保留原OFF→ON遥控保护。Pitch失能会下垂，上电/关闭时仍需接住负载。软件无法从编码器自动识别真实水平，所以启动水平姿态是物理前提，不能任意摆放后套用原机械限位。

普通运行后CH5上位停机，再上位等待反馈健康/停稳、拨中档即可重新操控，**不会重新捕获零点**；机械限位、水平相位沿用。本次MCU复位才重新建立启动基准。遥控失联恢复仍要求新的上位帧和人工拨档，不会仅恢复通信就重启。

## 快速设置零点与阶跃

正常上电已自动完成设零，不必再发各轴READY。需要主动重新建立双轴零点时：

1. 接住负载并CH5上位，四杆回中、CH6上、CH7/8中；恢复同一水平基准。
2. 单次发送 `GIMBAL READY`，等自动报告READY。它统一做失能确认、双轴软件设零、Pitch除数1和水平标定、双轴准备。
3. CH5在上位保持至收到新OFF帧，再拨中档，等活动且稳定保持；即可发送下表命令。

| 动作 | 命令 |
| --- | --- |
| Pitch正30°低头阶跃 | `PITCH STEP` 或 `PITCH STEP 30` |
| Yaw正30°阶跃 | `YAW STEP` 或 `YAW STEP 30` |
| Yaw负30°阶跃 | `YAW STEP -30` |
| Pitch回软件0 | `PITCH HOME` |
| Yaw回软件0 | `YAW HOME` |
| 最近完整报告 | `PITCH RESULT` / `YAW RESULT` |

每条命令加真实LF/CR换行，逐条单次发送、等回复。STEP要在本轴目标和实际角均为0±0.2°、静止至少20ms、健康活动状态且摇杆回中时接受；CH6须上、CH7中、CH8释放。序号/模式事件不排队补执行。中档手动和下档测试均可用串口STEP；原下档左杆选轴/CH7确认及回零逻辑保留。

STEP测量5秒后自动报告并保持目标。等DONE后HOME回零，停稳后再做下一轮；提前HOME会中止这轮统计（TARGET_CHANGE）。手动移过位置后需要回0时用HOME，不在任意姿态GIMBAL READY来隐藏跟随误差。Pitch−30°超出目前机械范围，继续拒绝。

## 简洁查询和异常

- `GIMBAL`：自动准备状态；`GIMBAL HELP`：快速流程。
- `YAW` / `PITCH`：本轴简洁状态；`PID`查看实际参数，`STATUS`查看完整诊断，`VIEW`选择波形。
- `TELEM OFF`暂停波形刷屏，查询、自动READY/故障/阶跃报告仍输出；`TELEM ON`恢复。
- `WAIT_OFF`等待安全上位；`PREPARING`等待新鲜失能静止反馈；`READY`可人工解锁；`BLOCKED`检查REASON；`MANUAL`表示明确的旧串口准备/STOP/DIAG操作接管了流程。
- 旧各轴READY/ZERO/COORD/OFF/ON/CLEAR等明确的手动准备或停止操作，以及STOP/DIAG ON，会暂停自动准备，避免它覆盖人工操作。恢复自动使用安全OFF下的GIMBAL READY或重新上电。纯查询/VIEW/PID调参不暂停。
- 反馈中断导致编码器参考失效时不会在任意姿态自动重新设零，报REFERENCE_LOST；恢复水平基准后GIMBAL READY。CAN/发送故障等原锁存仍保留，自动准备不会盲清硬故障。Yaw状态13只允许沿原静止/停机/邮箱/温度门禁做启动会话内一次恢复。
