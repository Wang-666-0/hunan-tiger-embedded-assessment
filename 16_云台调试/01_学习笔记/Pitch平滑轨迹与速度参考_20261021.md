## 新控制行为

离散目标从实测起点沿五次多项式在200ms内变化到最终目标，起止参考速度和加速度均为0。归一化时间u=t/T，位置比例为10u³−15u⁴+6u⁵。位置环跟随内部参考，速度环额外接收0.2倍规划参考速度。位置D仍只作用于实测速度；不叠加额外加速度力矩。轨迹期间只冻结位置积分的新增量，保留已有位置积分，速度积分继续按新CAN反馈更新并参加总力矩抗饱和。起止不清积分。

这使减速在到达目标前连续发生，避免旧回退判定的切入/退出。实际跟踪仍受负载、反馈延迟和PID影响，不能保证仅凭软件替换就达标；0.2是首轮试测权重，较小权重可能造成跟踪滞后。

STEP测量始终使用指令接收的原始t0与最终30°目标；不会把200ms规划时间扣除，也不会按移动参考判成绩。实际误差带、超调、稳态误差均保持0.2°，Pitch最终稳定仍须≤300ms，完整观察5s。最新截图386ms是旧方案这一轮的结果。

## 使用

重新构建并按原EIDE/ST-Link流程烧录。按既有READY/水平标定/解锁顺序操作，先用`PITCH PID`确认七参，`PITCH SHAPE`确认`MS|200`及`VEL_FF|0.2`，随后用原`PITCH STEP`、`PITCH HOME`测试0°↔30°。

- `PITCH SHAPE`：只读查询参考与配置。
- `PITCH SHAPE 200`：设置规划时间；支持100～250ms，`0`为直接目标对照。
- `PITCH SHAPEV 0.2`：设置速度参考权重，范围0～1；`0`保留位置规划，仅关闭速度参考项。
- `PITCH BRAKE`或`PITCH BRAKE OFF`：返回旧方案已移除；`ON`拒绝。
- `PITCH RESULT`：读取本轮实际稳定时间、超调与稳态误差。

设置只影响RAM，重启回到固化默认值。5s阶跃测量期间拒绝改变规划配置，同值写入幂等。规划尚未完成时不同目标（含HOME）会拒绝；轨迹结束并且实测/观测速度均≤6°/s才接受新的大角度规划。STOP和撤权随时生效。手动90°/s映射以及STEP保持后摇杆介入的原撤权/重解锁逻辑保持。Yaw控制保持原行为。

## 波形

原I0～I57含义保持；I58、I59保留为0，不再代表刹车。

| Pitch通道 | 含义 |
| --- | --- |
| I0 / I1 | 实际角度 / 最终目标 |
| I2 / I3 | 速度环总目标 / 观测速度 |
| I54 / I55 / I56 | 重力力矩 / 纯PID力矩 / 速度积分 |
| I60 | 内部位置参考，度 |
| I61 | 规划参考速度，度/秒 |
| I62 | 轨迹是否运行 |
| I63 / I64 | 规划时间ms / 速度参考权重 |

Pitch遥测共65列。观察实际角度与I60是否滞后，以及I2、I3和I56在接近目标时的变化，再判断是否改善回退；不以I62结束作为实机稳定。
