# 摩擦轮双轮6000rpm与快速升速测试

当前版本：**DUAL_RPM6000_I2000_V1**，继续使用原Gimbal_Control工程。用户已反馈两轮I29/I30基本能维持7000ERPM，要求升到6000rpm，并明确“阶跃响应”指摩擦轮启动升速更快。

本档控制目标各42000ERPM，暂按已同意的7极对、1:1直驱估算为6000rpm。真实极对数仍未独立确认，所以先验证这个电气转速目标，不把配置换算当作独立机械测速结果。

## 本档改动

| 项目 | 配置 |
| --- | --- |
| 左右目标 | 各42000ERPM，双轮独立电流PI，方向继续保留已确认的正给定 |
| 启动目标斜坡 | 42000ERPM/s；正常新反馈下约1秒从0到目标，上一档目标斜坡约4秒 |
| 给定限流 | 每轮最多2A，增加仍限制5mA/ms，最多约0.4秒从0加到2A；降低可立即执行 |
| 软件观察带 | 原始及滤波速度均在42000±700ERPM内，连续500ms；不是拨盘就绪 |
| 软滑行 / 恢复 | 原始绝对值≥44100 / ≤42000ERPM；单轮独立滑行，另一轮继续调速 |
| 硬超速 | 任一轮原始绝对值>46200ERPM，停止两轮并锁存故障 |
| 反馈保护 | 电机/输入电流绝对值>3A、FET≥60℃，及原反馈、遥控、CAN/UART保护 |
| 遥测 | 原51通道及50ms间隔保留，无新增通道 |

1秒是目标指令斜坡，0.4秒是给定加流斜率的计算值，都不是实测机械响应时间。当前只发受限SET_CURRENT，未用SET_RPM、未写电调配置；电调保存±20A未变，2A给定与3A反馈判据不能等同电调硬限幅。

## 1. 构建、烧录并核对版本

1. 保持CH1回中、CH5 OFF、CH6高位。使用原[VS Code/EIDE工作区](D:/Project/27电软正式批考核/16_云台调试/Output/Gimbal_Control/MDK-ARM/Gimbal_Control.code-workspace)，执行“eide: 重新构建”，成功后Ctrl+Alt+D通过原ST-Link配置烧录。
2. 本版没有新增App源文件；Keil/EIDE磁盘清单均54个源文件且一致，无需重新添加模块。
3. USART1继续115200/8N1，VOFA用FireWater，数据间隔50ms。发送`WHEEL INFO`并加换行，预期：

```text
W|INFO|DUAL_RPM6000_I2000_V1|LEFT_MA|2000|RIGHT_MA|2000|LEFT_SIGN|1|RIGHT_SIGN|1|MS|0|ERPM|46200|ENABLED|1|HOLD_TO_RUN|1|COAST_ERPM|44100|RESUME_ERPM|42000|MODE|CURRENT_PI|POLE_PAIRS_ASSUMED|7|TARGET_RPM|6000|TARGET_ERPM|42000|BOTH|1|FB_MAX_MA|3000|RAMP_ERPMS|42000|BAND_ERPM|700
```

先匹配新版本及参数再运动。旧1000rpm板上INFO不是本档确认。

## 2. 双轮启动与观察

1. 先发送`WHEEL OFF`，等两轮停稳，再发送`WHEEL BOTH`，预期`W|OK|BOTH`。
2. 保持CH5 OFF、CH1回中≥0.5秒，随后CH5 ON、仍回中约0.2秒，再正向推住CH1。
3. 先看约2秒，运行正常再保持至总计约8秒。I29/I30的目标从原7000提高至各约42000；可同时看I34/I44左右给定、I35活动和I36故障。
4. 回中CH1、CH5 OFF结束。明显异常或故障时直接用这个动作停止；0mA仍是滑行，不保证机械瞬停。再次启动需要两轮停稳和新的OFF回中→ON。

正常按住运行不会计时结束，软滑行仍保持I35=1。若运行时给定长期到2000mA而转速明显不足，请记录这一现象，先用本档结果判断限流，不直接解除上限或切换到电调内部速度模式。

## 3. 停止后读取加速成绩

分别发送`WHEEL SPEED`、`WHEEL STATUS`并加换行，把全部`W|...`行复制过来。双轮SPEED仍为三行：会话摘要、节点70统计、节点71统计。两行节点统计末尾新增：

```text
...|T90_MS|数值|BAND_FIRST_MS|数值
```

- **T90_MS**：从软件会话启动到第一次有效STATUS1报告绝对值≥37800ERPM（目标90%）的时间，使用反馈接收时间戳，不等20ms速度环更新。
- **BAND_FIRST_MS**：启动后第一次确认原始和滤波速度在41300～42700ERPM内连续500ms的时刻；它包含这500ms确认时间，不保证之后永远不离带。
- **−1**：该项尚未达到；0表示起始反馈就达到（正常停稳启动不会出现这种情况）。停止保留这两个值，重新启动才清空。
- **PEAK_ERPM / LIMIT_MS / BAND_MAX_MS**：原始绝对值峰值、给定到2A上限的累计控制时间、最长软件连续速度区间。结合T90及故障位评估加速、超调和持续调速。

T90是启动到90%的反馈指标，不是标准10%→90%上升时间；BAND_FIRST也不是已经验收的永久稳态时间。停止后RAMP_ERPM归零，FILTER_ERPM/RPM_EST保留最后控制样本，实时轮速看STATUS。无需视频或在运动时连续抄数。

VOFA关键通道：I29/I30原始ERPM，I31/I32反馈mA，I34/I44左右给定mA，I35/I36活动/故障，I41/I47按7极对估算rpm，I43/I49软件区间标志，I50停止原因。其他通道及停止/故障码沿用[1000rpm历史指南](摩擦轮双轮1000rpm持续测试.md)。

本档实际6000rpm、加速时间、持续稳速、噪声和完整动态保护仍待上板结果。软件证据见[版本与验证说明](../02_过程记录/摩擦轮双轮6000rpm快速升速_20261013/版本与验证说明.md)。
