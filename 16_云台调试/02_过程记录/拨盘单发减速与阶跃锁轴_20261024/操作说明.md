# 拨盘单发优化与云台阶跃锁轴

本轮修改直接位于当前 VS Code 原工程，拨盘版本 `C610_SINGLE_BRAKE_V1J`。使用 MDK-ARM 中现有 EIDE 构建、ST-Link 烧录配置，产物为 `build/Gimbal_Control/Gimbal_Control.hex`。

## 拨盘单发

截图中的单发目标约增加40°，实际角度越过目标后又往复摆动。本轮保留双环结构和原电流上限，为 `SINGLE` 单发增加：

1. **速度预测阻尼**：用实测转速预测12ms后的角度，接近目标时提前降低速度参考。静止起步仍允许原3600转子rpm和±3000原始电流命令。
2. **停车距离限速**：根据剩余转子角度限制目标转速，默认减速度设置为50000转子rpm/s，并留8ms延迟余量。这是控制设置，实际可用减速度仍需实机验证。
3. **减速释放积分**：实测速度需要减小时，将旧速度积分按12ms时间常数衰减，同时暂停反向积分累积，减少前段驱动力拖到终点及反向积分造成的再次回摆。

位置P=10、速度P=2、速度I=8和±3000原始电流上限保留。控制仍为2ms；连发仍每50ms请求一发、每发40°，连发参考与松手收尾的控制分支保持原逻辑。单发完成判定仍沿用原来的位置容差、静止速度和持续时间。

这轮着重减少超调后反复修正所占的稳定时间，提前减速可能让首次碰到目标略晚；不能以首次交叉代替稳定时间，也不能据软件检查承诺实机40°在50ms内稳定。

### 操作与观察

烧录后，先按原流程完成准备、进入普通模式、摩擦轮达到真实就绪状态。CH6中档选择单发，CH8从释放位置到触发位置发一发；连续两发之间先释放扳机。

VOFA发送：

```text
FEEDER ANGLE VIEW
TELEM ON
```

保持现有FireWater、921600/8N1；I0为实际输出轴角度的相反数，I1为目标输出轴角度的相反数，默认方向下向正数递增。I2/I3分别为实际/目标转子rpm，I4为原始电流命令。

完成后发送：

```text
FEEDER RESULT
```

新增字段：

| 字段 | 含义 |
| --- | --- |
| SINGLE_DECEL_RPM_S | 单发停车减速度设置，默认50000转子rpm/s |
| BRAKE_DELAY_MS | 停车距离预留延迟，8ms |
| PREVIEW_MS | 位置预测时间，12ms |
| I_RELAX_MS | 减速时积分衰减时间常数，12ms |
| SINGLE_BRAKE_N | 最近一次单发进入积分释放的反馈帧数 |
| SINGLE_OVERSHOOT_DEG | 最近一次单发从接受到完成期间实测的最大越界角度，输出轴° |
| SHOT_MS | 原有单发完成判定用时，不能等同于±0.2°稳定时间 |

若需对比原单发算法，在原安全OFF、空闲、健康遥控条件下发送 `FEEDER SINGLE_DECEL 0`；恢复新算法发送 `FEEDER SINGLE_DECEL 50000`。参数仅保存在RAM，重启恢复默认。数值越小越提前减速；范围为1000～200000，0专用于关闭新单发处理。无需为正常使用额外发送这些调参命令。

## CH5进入阶跃测试

CH5拨到测试档（当前映射通道值约2000）时：

- yaw、pitch各自把**当时实测位置**锁为目标，不再追赶进入前领先的位置目标。
- 取消旧轨迹、刹车状态和旧位置积分，保留软件零点、观测速度、速度积分和pitch重力标定，继续闭环保持。
- 测试档内右摇杆不再改变两轴位置。目标只在进入时锁定一次，后续反馈仍用来纠正位置扰动。
- yaw阶跃时pitch保持；pitch阶跃时yaw保持。遥控CH7和串口STEP使用相同的轴协同逻辑。
- 如果切换到另一轴时原轴尚在运动，则将原轴停在当前实测位置继续保持；被打断的测试记录为中止，不会计作通过。需要完整考核结果时，先等当前5秒测量窗口结束再测另一轴。

限位端点附近允许沿用原0.2°反馈量化容差，目标仍裁在合法范围内。更远的越限、失联、故障和STOP仍按原规则停机，不强行保持或重新使能。

### 原遥控步骤继续使用

1. 完成原安全OFF准备与解锁，CH5进入测试档，两轴先保持当前位置。
2. 左摇杆仅选一轴：CH4选择yaw方向，CH3选择pitch方向；斜向不发起测试。
3. CH7先中档、再高档，确认所选轴的阶跃；另一轴保持。
4. CH7低档归位所选轴；选择杆居中时归位最后真正接受测试的轴，另一轴仍保持。

原阶跃入口仍要求被测轴接近软件零点且静止，STEP仍是软件坐标的±30°绝对目标；本轮锁位置不会重设零点。若从非零位置进入测试档，需要先归位被测轴。pitch继续遵守−18°～+33°的目标限位。

串口仍可使用 `YAW STEP`、`PITCH STEP`、`YAW HOME`、`PITCH HOME`。测试档下串口新STEP也会在下一个2ms控制周期锁住另一轴。VIEW只切换显示，不发起运动。退出测试档后的停机、重新OFF解锁流程沿用原有规则。

## 验证范围

本轮编译实际原工程并运行ARM离线逻辑回归；没有连接电机、执行烧录或采集新的实机成绩。单发模型用例是不同惯性/阻尼/延迟下的软件回归，不能作为实机超调或稳定时间的证明。重新烧录后请用真实I0/I1曲线检查单发超调、回摆和最终稳定时间。
