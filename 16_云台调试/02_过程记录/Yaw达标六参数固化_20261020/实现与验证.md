- 更新当前工程说明、测试入口和根目录最新提示，新增本次操作笔记。现用 VOFA 面板与控制通道保持。
- 工作区开始时已有大量未提交改动，本次未回退。固件和四个测试的修改前文件保存在 `before/`；本次专属差异见 `firmware_and_tests.diff`。

## 软件验证

原 `Tests/run_selftests.py` 选择执行下列 8 组，使用 ARM GCC `-Wall -Wextra -Werror` 编译并以 Unicorn 运行真实 C 逻辑：

```text
yaw_cascade_unlimited yaw_cascade_unlimited_console yaw_manual50
yaw_repeat_step yaw_performance yaw_step_assessment
yaw_telemetry yaw_can_unlimited
```

共 **65,888 项，0 失败，全部完成并正常返回**。验证涵盖初始化默认、实际串口回读、RAM 改参后重启恢复固化值、手动范围、重复阶跃、测量判据、遥测和协议提交。未新增测试分组，未扩展为全量历史回归。

结果见 [测试报告](selftest_results.json)及[运行日志](selftests.log)。本次只改参数的离线验证不等同于实物惯量与机械振荡验证。

原 EIDE 构建器以当前原始 `builder.params` 执行 `--rebuild`：ARM Compiler 5.06、O0、68 C + 1 ASM，共 69 源项，完整编译链接成功，**0 错误、0 警告**。ROM 122,500 字节、RW/ZI 36,704 字节。构建前后任务均为空，仅编译，不下载。

证据见 [构建日志](build_o0.log)、[编译器日志](compiler.log)和[原 O0 参数](build_o0.params)。没有运行会重写 O3 参数的 `Scripts/build.ps1`。

## 使用

固件已在原 EIDE 工程构建成功，尚未烧录。按原 ST-Link **Ctrl+Alt+D** 流程烧录，重启后在任何在线改参之前发送 `YAW PID`，应得到：

```text
Y|PID|POS|15.5490,0.7340,0.1390|VEL|0.005170,0.003500,0.000074|VMAX_DPS|0.0|OUTPUT_LIMITS|0
```

后续在线改参仍仅在 RAM 中生效，重启恢复本次六个固化默认值。操作说明见[学习笔记](../../01_学习笔记/Yaw达标六参数固化_20261020.md)。
