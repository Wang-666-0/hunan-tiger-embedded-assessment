# V1F：拨盘反馈时间量化修正

当前版本为`C610_FEEDBACK_TIME_V1F`，继续使用原`Output/Gimbal_Control`。本轮未接触串口、CAN设备或烧录器，未生成HEX。

## 现场定位

用户反馈单发、连发均会导致拨盘和摩擦轮同时停止。V1E首次冻结诊断为：

```text
FAULT4 / CAUSE DELTA / AT_MS11291 / SEQ10909
PREV_RAW6444 / RAW5840 / DELTA_COUNTS-604 / GAP_MS1 / FRAME_AGE_MS0
PREV_RPM-2048 / RPM-2234 / LIMIT_COUNTS577.399 / EXPECTED_COUNTS305.015
FB_TORQUE_RAW-1584 / BEFORE_CMD-3000 / BEFORE_BUSY1 / BEFORE_ZERO1
FRAME16D0F746F9D00000 / JUMP_COUNT11 / CAN_EPOCH0
```

CAN1/CAN2错误均0、DROP0、EPOCH0；Pitch本身FAULT0、P_STOP EXTERNAL。拨盘跳变故障先撤销零点及ARM，再请求整机停止，因此摩擦轮一起停止。Safety reason10是共享撤权后的反馈状态，不能作为比冻结跳变更早的原因。原PITCH GUARD打印UNKNOWN，是来源名称列表遗漏新增FEEDER枚举，本轮仅修正日志标签。

累计11个跳变仅冻结第一条，不能假定11条大小相同。故障后位置−374.3985°不能作为完整有效行程或单发角度实测。

## 修正范围

CAN接收ISR记录的是`HAL_GetTick()`整数毫秒。两个时间戳相差N，不意味着真实接收间隔恰好N毫秒，其上界可接近N+1毫秒。旧判据遗漏这一量化误差；本轮保留实际时间戳差，并单独用`gap+1ms`计算位置增量合理性上界。

以本次样本最大速度2234rpm计算：旧上界`(2234+120)×1×8192/60000+256≈577.399`counts；修正上界`(2234+120)×2×8192/60000+256≈898.799`counts。604counts处于修正边界内，实际−604仍原样累计，不预测、插值或补圈。该样本可由量化误差覆盖，不代表已证明所有现场异常均来自时间量化。

半圈歧义也采用同一保守间隔；在6000rpm、时间戳差4ms时，按5ms可能跨半圈，立即失效零点。真实大跳变仍首帧故障。固定余量维持256counts，失联20ms、控制间断10ms、速度/电流/堵转/超时及CAN保护均保持。

新增只读字段：STATUS/CHECK中的`GAP_MARGIN_MS=1`、`TS_ALLOW`（本次上电中仅因时间量化余量而通过的样本数），以及CHECK冻结的`GAP_BOUND_MS`。TS_ALLOW不是故障计数，CLEAR不会重置；JUMP_COUNT仍是真正触发的跳变累计。原VOFA39列不改，原面板可继续使用。

除拨盘控制器c/h、拨盘状态格式、版本号外，仅修正Pitch日志来源标签。Yaw/Pitch控制参数、摩擦轮6000rpm参数、遥控映射、自动零参考/ARM、单发3600rpm、连发5800rpm上限及50ms事件逻辑均保持V1E。故障仍须人工恢复，不自动清错、不补发历史请求。

## 给用户的下一步

在原VS Code/EIDE执行Rebuild后使用原ST-Link流程下载。上电CH5/CH6上、CH7/CH8中、摇杆居中约2秒；CH5中保持CH6上约1秒，再CH6中等轮子稳速约5秒，CH8下→中单发。先确认三次单发不再联停，再CH6下短连发约0.3秒、CH8回中。正常启动无需串口命令；若复现，保留现场再读取FEEDER CHECK即可。
