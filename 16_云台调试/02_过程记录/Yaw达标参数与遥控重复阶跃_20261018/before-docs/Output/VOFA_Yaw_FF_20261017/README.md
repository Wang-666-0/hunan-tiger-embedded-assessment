# Yaw V2J 前馈调参面板

适用固件 `GL60II_CASCADE_FF_V2J`。这是单独生成的配置目录，没有修改正在运行的VOFA，也没有发送电机指令。

先保存自己的现有配置；选择性载入这里的命令/面板，或按[完整操作指南](../../01_学习笔记/Yaw前馈与VOFA控件调参_20261017.md)在原面板添加控件。串口921600/FireWater，Δt5ms，COM口需要自己选择。先发YAW VIEW，看到64列后再绑定新I48～I63。

前馈初始关闭，四个系数初值0，FVS5、FMAX0.1。前馈ON不等于电机使能，仍需原遥控准备/解锁。参数仅RAM；重新设零会关闭前馈。

本目录通过JSON结构、命令路径、数据索引、换行和循环关闭验证；尚未在用户的VOFA GUI中导入，也没有实机性能验证。原I0～I47顺序保持；角度稳定按新I61/SETTLE05、I62/PASS05判断，旧I26/I32不代表新考核通过。

三个页签：

1. Yaw前馈：六个前馈控件、开关、STEP/HOME/RESULT以及新指标。
2. Yaw PID：当前7.5/.15/0与.0025/.003/0基线的六个控件。
3. 角度-速度-力矩诊断：四张分单位绘图，I0/1，I2/3，I5/6/55/56/57，I58。

调参先每次只改一个值，在下一次完整5秒阶跃比较效果；不在测量过程中拖控件。前馈详情用YAW FF查询。
