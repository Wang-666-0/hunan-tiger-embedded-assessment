# Pitch回退捕获阻尼 · V2E

用户本轮V2D回读RETURN_GAIN=0.01、RETURN_MAX_NM=0.2，回退峰值已经达到0.20，RETURN_N=25。截图稳定372ms、超调约0.14695°、稳态误差约−0.09231°，回退仍明显。

V2E把回退上限0.20提高到0.30，保持增益0.010、加力斜率12协议Nm/s、原窗口与撤去条件。七参保持。数据只能确认计算附加项已触及限幅，不能仅凭峰值判定根因；同时增加不参与控制的到位快照，便于区分速度积分变化、滤波速度滞后和力矩缺口。

历史：V2B只处理到位前超速，V2C增加250ms回退窗口，V2D增益0.006提高到0.010并固化位置I=0.687。本版沿用V2D增益，不清积分或自动注入积分。

## 两段附加输出

到位前沿用V2B末段逻辑：前26°附加项为0，最后4°内仅对原方向的超速运动施加阻尼，最大0.12协议Nm、增益0.002，保持原前段加速。

首次进入目标附近（按原运动方向余量≤0.2°）开始250ms捕获窗口。首次降低速度后，不再对重新靠近目标的运动追加刹车；只有向起点侧远离目标时才输出回退阻尼，条件同时满足：

- 已在首次到位后的250ms窗口内。
- 位于目标起点侧0.03°～4°范围。
- 位置增量确认正在向起点回退。
- 原始速度与位置差分滤波速度都确认回退且幅值超过8°/s。

回退附加项幅值为`0.010 × (两路回退速度较小值 − 8)`，最大0.30协议Nm；靠近4°边界平滑淡出，加力最大斜率12协议Nm/s。低速、原始/滤波速度不一致、位置开始回到目标、反馈超过10ms未更新时立即撤去；窗口超时退出。力矩换向先从0缓升，避免沿用原方向幅值造成突跳。以上是试测参数，软件逻辑不能保证实机300ms达标。

附加力矩与PID、实际角度cos重力前馈参加同一总力矩抗饱和；不清积分，不加入固定保持力矩，不延迟阶跃计时。

## 查询与实测

按原工程烧录新固件后，查询：

```text
PITCH PID
PITCH SHAPE
PITCH BRAKE
```

版本应为`DM3507_CAPTURE_BRAKE_V2E`，BRAKE查询应显示`RETURN_GAIN|0.01|RETURN_MAX_NM|0.3`，模式为`TERMINAL_AND_RETURN`、`ENABLED|1`；SHAPE的MS和VEL_FF均为0。沿用原STEP/HOME操作。BRAKE ON/OFF接口与5s测量期间配置锁保持。

I58仍是当前附加力矩，I59是实际输出active。0→30°接近时I58可能为负；首次到位后向起点回退时可能为正。30→0°相反。停稳后I58应归零，不能用其最终值判定整轮是否介入。

一次STEP结束、发HOME之前查询`PITCH BRAKE`，重点看：

| 字段 | 含义 |
| --- | --- |
| PEAK_NM | 本次目标运动的最大附加力矩绝对值 |
| RETURN_PEAK_NM | 本次回退阻尼最大幅值 |
| N | 输出过附加力矩的新反馈帧数 |
| RETURN_N | 输出过回退阻尼的新反馈帧数 |

峰值/帧数在附加项退出或停机后保留，新目标运动时清零；同目标重复写入不清零。HOME是新目标运动，也会清零，因此先读再HOME。

若RETURN_N=0，只能说明本轮没有满足完整回退触发条件；不能把它当成已经加力仍无效。若峰值接近0.30仍明显回退，应结合速度积分及重力交接判断，避免继续盲目增加力矩。

I0～I64仍共65列，原成绩判定仍为300ms/0.2°，没有放宽。最新软件证据见`02_过程记录/Pitch回退上限与到位快照_20261021`，本轮未自动烧录。


## 到位快照：仍然只读同一条BRAKE命令

诊断最多记录一次目标运动前600ms，按实际参与控制的新CAN反馈更新；不改变控制参考、积分或阶跃计时，也不增加等待。首次进入目标附近后，原始速度沿本次目标方向降低到6°/s或开始反向时，捕获一帧本周期计算结果；原始速度可能已经反向，不能把这一帧一律称为静止。

| 字段 | 含义 |
| --- | --- |
| LAND_SEEN | 1表示已经取得到位快照；0时快照字段不能用于判断 |
| LAND_MS | 快照相对原始目标接受时刻的毫秒数 |
| VI_START_NM | 目标发出前的速度积分状态，协议Nm |
| LAND_RAW_DPS / LAND_FILT_DPS / LAND_VREF_DPS | 快照时原始速度、位置差分滤波速度、速度目标，度/秒 |
| LAND_VI_NM | 同一周期速度积分状态，协议Nm |
| LAND_G_NM / LAND_BRAKE_NM / LAND_OUT_NM | 同一周期重力项、附加阻尼、总计算请求；不是轴上实测力矩 |
| VI_MIN_AFTER_NM / VI_MAX_AFTER_NM | 首次入目标附近后、前600ms窗口内速度积分最小/最大值 |
| DIP_DEG / DIP_MS | 首次入目标附近后的最大起点侧位置误差及其原始命令相对时间 |

停机或600ms记录结束后保留快照，新目标（包括HOME）会清零；因此仍在STEP完成后、HOME前查询PITCH BRAKE。BRAKE OFF时也可记录同类快照作对照。帧在命令接受前入队时不作为新运动快照。

若原始速度已经降低，滤波速度仍沿旧方向很高，说明需要关注观测滞后；若速度积分相比出发值明显下降、总请求在该阶段推动回退，则需要关注积分及重力交接。两者可能同时存在，不能单个数值直接认定根因。完整原始/滤波速度和力矩符号需结合目标方向判断。
