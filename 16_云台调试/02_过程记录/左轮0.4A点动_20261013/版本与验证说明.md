# JOG_L400_R200_V1：左轮0.4A档

用户在0.3A档后反馈方向正确，并请求继续小幅增加电流以观察。本档仅将左节点70上限300mA提高到400mA，负极性保留；右节点71仍正200mA。幅值斜坡5mA/ms、单次最长500ms、上电OFF、两轮停转与反馈新鲜、遥控撤权、2000ERPM、1A反馈监测、60℃FET保护及双零停机路径保留。0mA为滑行给定。

上限仍由app_config.h统一定义，纯逻辑和CAN分别按节点校验。左−400mA的CAN大端报文为FF FF FE 70；右+200mA为00 00 00 C8。测试验证−401mA、错误符号、右201mA及撤权发送均拒绝。原WHEEL STATUS十字段及gimbal39通道布局不变，I34左最小给定−400mA。

只读WHEEL INFO的板上预期回复：

```text
W|INFO|JOG_L400_R200_V1|LEFT_MA|400|RIGHT_MA|200|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|500|ERPM|2000|ENABLED|1
```

ARM GCC -Wall/-Wextra/-Werror + Unicorn运行正式C逻辑与HAL/RTOS模拟接口：12组、156591项检查、0失败，全部正常返回。覆盖左右独立限幅、左400mA斜坡及保持、500ms结束、CAN端序与拒绝条件、故障/停机/重新触发，以及INFO的两种编译模式和只读行为。

ARM Compiler 5.06全量构建52C+1汇编，0错误、0警告，ROM34084字节、RAM33608字节。[compiler.log](compiler.log)保存本次完整构建输出副本，避免编辑器后续构建覆盖工程目录日志；[自检报告](自检报告.json)与[构建核验](构建与自检核验.json)保存结果及源码哈希。构建后所有测试输入哈希仍一致。

本助手没有连接串口、CAN或ST-Link，也没有烧录；0.4A实物结果待用户提供。上一档方向正确为用户反馈，未附原始峰值或测速数据。用户继续使用原VS Code/EIDE工作区及ST-Link重新构建和烧录，步骤见[0.4A操作指南](../../01_学习笔记/左轮0.4A点动与版本核对.md)。
