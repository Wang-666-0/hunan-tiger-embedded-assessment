# Yaw遥控30度阶跃、软件零点与指标

当前源码：`GL60II_PID_STEP30_V1F`，仍为原 `Output/Gimbal_Control`。用户在原VS Code/EIDE重新构建后用ST-Link烧录；代理未烧录，不交付.hex。默认PID=1/0/0.015，目标±30°、运行相对位置保护±40°、协议请求±0.10；6000rpm摩擦轮和遥控分配保持。

## 本轮实物证据与速度设置

11:09实机仍V1E，15°尝试后STATUS为ACTIVE0/STATUS0/FAULT16。16是运行超速锁存，闭环已经退出；目标从15降到7.246是故障Stop后的目标显示，不能当作正常稳态跟踪。蓝线回落至约3.4°不证明稳态误差合格。11:16已回传OFF及ACTIVE0/REQUESTED0/STATUS0/STOP_PENDING0，FAULT16保留。

截图VOFA的Δt=5ms，而固件目标遥测间隔50ms；曲线时间轴应先改50ms。串口文字会影响实际显示间隔，图只用于观察；新指标直接使用CAN接收时间戳，避免用绘图Δt换算考核时间。传感器采样间隔及最大间隔见报告N/GAP_MS，不将显示精度当作机械测量精度。

V1F新增40°/s以上的反向制动抑制，保留60°/s硬超速停机；积分在速度抑制时冻结，避免积累。该档先验证保持和统计：30°在60°/s上限下至少约500ms，不能满足250ms指标。后续依据真实峰值、曲线与机械空间再提速，不将本档假记为考核通过。目标仍为直接30°跳变，没有用目标斜坡替代阶跃。

## 原遥控分配的实际触发

| 操作 | V1F行为 |
| --- | --- |
| CH5上位 | 总关闭，撤销输出，未完成测量标为中止 |
| CH5下位 | 测试模式，必须先安全OFF/中位准备并获得新的人工解锁；此模式禁止摩擦轮/拨盘输出 |
| CH4向右 / 向左 | 左摇杆水平选择Yaw +30° / -30°；CH3须居中，斜向不产生有效轴选择 |
| CH7中位→下位 | 确认一次所选方向；只有已设置零点、活动健康、近零且静止才开始 |
| CH7回中、CH4回中 | 保持已接受的±30°目标，不重复触发 |
| CH7上位 | 回软件零点0°，之后仍可闭环保持；未完成的统计标为TARGET_CHANGE |
| 测量期间CH5由测试切到中位 | 退出测试并停机、要求新的OFF解锁，防止混入手动控制 |
| 选到Pitch | 串口提示PITCH_NOT_IMPLEMENTED，当前不发送Pitch动力命令 |

测试前确认以软件零点为中心左右至少40°机械/线束空间，整机放稳，手离开运动部件。CH6保持上位，CH8中位；上位锁定仍总撤权。遥控失联、反馈/CAN/温度/位置/时序/超速等保护继续有效。动力线不可单独拆卸，按现场整机统一供电。

新的遥控事件会打印 `Y|REMOTE_STEP|SEQ|…|RESULT|STARTED|TARGET|30.0`，或RETURN_ZERO、START_GUARD、PITCH_NOT_IMPLEMENTED。拒绝的事件不排队补发；回中后重新确认，不能靠持续按住等待自动启动。STEP_STARTED/STARTED只表示目标和测量被接受，是否运动完成看后续统计与实际曲线。

## VOFA零点和PID

USART1 115200/8N1、FireWater仍70列/50ms，原I0～I69位置保持。目标/实际角度I52/I51同图，速度I53及力矩请求I54可另图；I56/57/58为MCU实际PID。将截图左下Δt从5改50ms。

| 控件 | Str命令，末尾使用真实LF/CR | 设置 |
| --- | --- | --- |
| 当前姿态设零按钮 | `YAW ZERO` | CH5/6上、CH7/8中、YAW OFF、真实失能且静止时单次点击 |
| KP滑块 | `YAW KP %f` | 0～2，步进0.05 |
| KI滑块 | `YAW KI %f` | 0～1，步进0.01，初轮保持0 |
| KD滑块 | `YAW KD %f` | 0～0.2，步进0.005 |
| 结果查询按钮 | `YAW RESULT` | 只读，可在保持期间查询上一轮指标 |
| Yaw关闭按钮 | `YAW OFF` | 取消准备请求并撤权 |
| 可选目标滑块 | `YAW TARGET %f` | -30～+30，步进1°；主测试由遥控CH7触发 |

软件零点不写电机FE或配置。成功回复SOFTWARE_ZERO，STATUS的ZERO_SET=1；ON和FC准备不会覆盖此人工零点，使能时先保持当前位置而非自动追赶零点。断线/位置跳变使连续角基准失效或MCU复位时须重新设零。若设零后挪动过云台，先CH7上位回到零点并静止，再确认新的30°测试；START_GUARD时先回传STATUS，不反复确认。

PID命令活动时可实时生效。5秒测量中改PID会标ABORTED/PID_CHANGE，仍保持30°目标，避免把两组参数混成一份指标。完成后调PID不会改写旧报告中的PID；回零并用CH7发起新一轮，得到新ID和新指标。目标变化、回零、退出测试或故障也会按原因中止正在进行的统计。

## 板端统计

遥控确认成功的目标接受时刻为t0；随后每个新CAN反馈参与测量，既不依赖VOFAΔt，也不从50ms遥测行推算峰值。观察窗口5秒，结束会自动打印一次 `Y|STEP|…`，继续保持±30°，直至明确回零、停机或故障。`YAW RESULT`重读相同记录。串口格式化/发送只在低优先级Console任务，接收和控制任务仅采样、保存状态，不在临界区printf。

| 字段 | 定义 |
| --- | --- |
| STATE / VALID | DONE/1表示采样窗口完成；ABORTED/0表示中止，不能当作完成响应；RUNNING和IDLE也为0 |
| RESP_MS | 暂定：首次进入目标±0.2°并连续保持至少50ms的进入时刻；-1表示未取得。正式考核口径仍待复核 |
| T90_MS / RISE_MS | 从t0到90%步幅、10%到90%上升时间；不可获得时为-1 |
| SETTLE_MS | 窗口结束时仍连续在带内至少50ms的最后一次进入时刻；-1表示末段未确认稳定 |
| OS_DEG / OS_PCT | 按运动方向统计超过目标的最大采样角度、相对实际步幅的百分比；负向阶跃也取正的超调量 |
| SSE_DEG | 第4～5秒角度的时间加权均值误差，目标减均值；按相邻样本线性积分，不以最后一帧代替 |
| SSE_VALID | 最后1秒完整覆盖、至少10个样本，且采样误差始终在±0.2°内才为1；为0时SSE只是末段均值，不宣称已稳态 |
| PASS | 采样口径同时满足约30°步幅、RESP≤250ms、OS≤0.2°、SSE_VALID1且误差≤0.2°；不是整机正式验收结论 |
| VMAX_DPS / TMAX_NM | 测量期间峰值速度及MCU请求绝对值；超速中止包含触发反馈的速度。TMAX不是实际电流或校准物理力矩 |
| N / GAP_MS / LIMIT_N | 样本数、最大接收间隔、速度抑制被观察到的样本数 |
| KP / KI / KD | 本轮开始时的参数，区别于后续实时调参值 |

测量中止会输出REASON和FAULT，SSE_VALID/PASS清零。反馈间隔达到100ms、坏数据、控制/驱动故障、STOP等不生成虚假的成功结果。当前250ms/0.2°判据依交接的暂定口径实现，不能由软件测试或一帧STATUS宣称实物达标。
