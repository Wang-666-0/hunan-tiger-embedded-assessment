# 双轴阶跃互锁实现与验证（2026-10-20）

> **已回退**：用户随后要求撤销本次互锁。当前工程已恢复 **Yaw V2Q / Pitch V1G**，保留此前固化的六个 Yaw PID。下文为回退前的历史实现与验证，不代表当前启用功能；详见[回退说明](回退说明.md)。原操作笔记已归档至 `rolled_back_additions/01_学习笔记/`。

用户要求一轴阶跃时锁住另一轴。本次在原后端实现双向位置保持：Yaw `GL60II_FIXED_PID_V2R`、Pitch `DM3507_CASCADE_V1H`。没有改动本日已固化的六个 Yaw PID、Pitch PID、重力系数或控制周期。

## 行为

1. 串口和遥控共用各自后端的正式 STEP 接受点。先验证原门禁，再验证另一轴已使能、反馈新鲜、无故障、处于原目标范围并已静止；未就绪则拒绝，不替用户使能另一轴。
2. 接受时捕获另一轴的实测角为目标，设置 `peer_step_locked`。保留 PID 积分和 Pitch 重力补偿，持续发送原闭环力矩。重复健康检查不重新捕获，扰动后仍追踪原捕获角。
3. 被锁轴忽略手动速度，拒绝 TARGET/HOME、PID/前馈写入和另一次 STEP。查询、STOP/OFF、失联与故障撤权保留。不会同时运行两轴测量。
4. 五秒测量完成、选中测试轴 HOME、改参中止或停机时，释放对轴互锁；对轴目标保留捕获角，不恢复旧目标。原测试轴完成后的保持及遥控模式规则继续沿用。
5. 控制更新和采样结束前均检查被锁轴健康。另一轴停止、断反馈或故障时，中止本轮，沿用原停止/重新解锁链路。

`YAW STATUS` / `PITCH STATUS` 新增 `PEER_STEP_LOCK`。Yaw STEP门禁新增位11，`YAW STEP CHECK` 可报告 `OTHER_AXIS_NOT_READY_OR_STEP_LOCKED`。没有新增 C 编译单元或控制任务。

## 验证结果

完整原运行器执行 **71 组、553,157 项，0 失败，全部完成并正常返回**；ARM GCC使用 `-Wall -Wextra -Werror`。新增互锁组为 **6,336 项**，覆盖：

- 双轴实测位置捕获，目标与旧目标不同；保持软件零点和 Pitch 重力配置。
- 锁定轴摇杆输入无效，目标/PID/前馈写入与第二轴 STEP 被拒绝。
- 扰动后不重捕获；串口和遥控两个方向均经过正式后端。
- 双向五秒结束后解锁且目标不跳回；测试轴 HOME 中止立即释放。
- 对轴未就绪拒绝、对轴停止/反馈丢失中止、全局 STOP 和故障后禁止自动重启。

证据：[完整测试报告](selftest_results.json)、[完整日志](selftests.log)、[互锁专项日志](step_lock_selftests.log)。原 Yaw/Pitch/拨盘遥测最大长度与线时维持 344/314/151 字节及 3733/3408/1639 µs。

第一次完整执行中，新增组扩展至双向完整五秒后达到 Unicorn 原 80,000,000 指令预算，0 断言失败但未完成，不能计为通过；保存在 `initial_full_selftests.json/log`。随后只将整窗生命周期循环调整为已允许的最大10ms控制间隔，普通交互阶段仍为2ms，没有放宽生产时序或仿真预算。专项与完整71组均重新完成并通过。

原 EIDE `unify_builder --rebuild`：ARM Compiler 5.06 / O0，68 C + 1 ASM，**69 源项完整构建成功，0 错误、0 警告**。ROM 123,920 字节，静态 RW/ZI 36,704 字节。原参数、发送周期和构建任务保持。见[构建日志](build_o0.log)、[编译日志](compiler.log)、[O0参数](build_o0.params)。
