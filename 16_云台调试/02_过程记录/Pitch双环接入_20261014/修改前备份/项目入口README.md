## 当前连接与代码约定

- 主控Cherrycoast4.8.1 / STM32F405RGT6；两路CAN均1Mbps。
- Yaw CAN1 ID1/Master0；Pitch CAN1 ID2/Master2；双摩擦轮CAN2 ID70/71；拨盘CAN2 ID5。
- 当前VOFA为USART1 921600/8N1、FireWater、5ms、48列；UART4 iBUS仍115200。旧115200/50ms和旧51/70列仅作历史。
- App平铺、配对.c/.h，更新新模块时同步EIDE和Keil源清单。用户只在原EIDE构建/ST-Link烧录，不发送.hex。
- 当前44组410882项离线检查通过；Pitch尚无驱动或实机成绩。本次交接与目录整理不改固件源码。
