# HOLD_L500_R500_V1：左右0.5A按住运行

用户要求持续转动以观察方向，并要求同时提高两边电流。本档左右电流幅值统一至500mA，固定左负/右正，一次只选一轮。仍按5mA/ms斜坡，约100ms达到上限；默认时长配置0表示按住正向请求持续给定，不再在500ms结束。回中、负向、撤权、反馈及CAN故障仍进入原双零停机路径。停止后要求新的OFF回中→ON，不能自动重新起动。

2000ERPM、1A反馈电流、60℃FET、两轮反馈新鲜、停转与遥控保护保留。当前为电流模式，无法保证持续恒速；超过反馈阈值会提前停机。0mA是滑行给定。GL/DM/C610与泛用动力发送仍关闭，没有写电调配置。

INFO回复新增HOLD_TO_RUN，MS=0明确表示按住运行，不表示关闭其他保护。WHEEL STATUS及gimbal39字段保持原布局，I34为所选轮带符号请求，左最低−500、右最高+500mA。

```text
W|INFO|HOLD_L500_R500_V1|LEFT_MA|500|RIGHT_MA|500|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|0|ERPM|2000|ENABLED|1|HOLD_TO_RUN|1
```

ARM GCC -Wall/-Wextra/-Werror + Unicorn运行正式C逻辑与HAL/RTOS模拟接口：14组、159997项检查、0失败，全部正常返回。覆盖左右500mA斜坡/限幅/保持、左FF FF FE 0C与右00 00 01 F4端序、501mA及错误方向拒绝、跨越500ms持续给定、两秒后回中撤权、重新OFF→ON、反馈/故障/停机重试及时间回卷。新增两组用同一正式源码和500ms编译配置保留原点动结束回归验证。

ARM Compiler 5.06全量构建52C+1汇编，0错误、0警告，ROM34072字节、RAM33608字节。[compiler.log](compiler.log)归档本次完整构建输出；[自检报告](自检报告.json)与[构建核验](构建与自检核验.json)保存结果及源码哈希。全部测试输入哈希经构建后核对一致。

本助手没有连接串口、CAN或ST-Link，也没有烧录。0.5A持续观察的实物方向、峰值及停止时间待用户记录。用户沿用原VS Code/EIDE工作区和ST-Link重新构建、烧录，操作见[持续观察指南](../../01_学习笔记/摩擦轮0.5A持续观察.md)。
