# 遥控逻辑迁移说明

用户授权在原Gimbal_Control工程迁入已约定的遥控逻辑，并要求保持已实现的6000rpm摩擦轮代码，其余电机驱动以后再加入。本次未连接硬件或烧录。

遥控设置已获用户反馈：CH5/6为三档保持，CH7/8下档回弹；档位1000/1500/2000；失联CH1～4及CH7回1500、CH5/6/8回1000。此记录不量化射频失联时间或机械停转时间。

软件默认遥控版本ASSESSMENT_CH5_CH8_V1，摩擦轮版本DUAL_RPM6000_I2000_V1保持原值。修改remote_mapper、target_manager、motor_backend、app_tasks、app_console及对应头文件/遥控配置；保留平铺App及配对.c/.h，App仍17个.c，工程仍53C+1汇编，没有新建固件工程。

flywheel_speed.c/.h、flywheel_jog.c/.h、can_bus.c/.h与迁移前备份SHA256全部相同；原6000rpm目标、42000ERPM、PI、滤波、目标斜坡、方向、限流及硬保护宏文本也全部相同。safety_manager、app_logic、remote_input、ibus核心文件未变。其余动力驱动仍关闭、拨盘就绪仍为0。

主要行为：CH5上档安全流程自动准备双轮；CH5中档正常解锁，CH6中/下开启双轮、上档关闭。CH1现在只发布云台请求，不再触发摩擦轮。CH8上档总锁存、恢复后重新人工解锁；正常CH6 OFF保留总解锁。未停稳时开启不延迟自启；测试退出不恢复旧CH6 ON。严格停止提交失败撤权并要求重新解锁。双轮准备后仍保留新OFF帧屏障，不能复用故障前或同毫秒输入。

CH7测试及CH8单发/连发只迁移请求接口，不增加云台/拨盘实际驱动。REMOTE INFO用于核对新遥控版本；原WHEEL INFO、STATUS、SPEED与51列遥测保持。新配置拒绝串口LEFT/RIGHT/BOTH选轮，避免绕过或混淆遥控双轮流程；STOP、WHEEL OFF及只读采集保留。

ARM Compiler 5.06全量53C+1汇编构建成功，0错误、0警告，ROM38188字节、RAM33784字节。ARM GCC -Wall/-Wextra/-Werror加Unicorn：28组307386项检查、0失败，全部返回；26组历史映射显式回归，2组验证生产默认新映射、保护及实际摩擦轮模块集成。报告文件与当前被测源码哈希一致。软件检查不等同于新映射实机验收。
