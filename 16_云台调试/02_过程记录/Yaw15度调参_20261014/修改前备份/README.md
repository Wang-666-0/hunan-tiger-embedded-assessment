# Gimbal_Control：Yaw首版驱动与摩擦轮双轮6000rpm

当前遥控配置**ASSESSMENT_CH5_CH8_V1**：安全OFF帧自动准备双轮，CH5上→中总解锁，CH6中/下开启既有6000rpm控制，上档关闭；CH8上档安全锁/失联总撤权。摩擦轮版本仍为DUAL_RPM6000_I2000_V1，`flywheel_speed.c/.h`及`flywheel_jog.c/.h`保持原样，全部原参数保留：各目标42000ERPM、2A限幅、约1秒目标斜坡、44100/42000软区间及>46200硬保护。共同CAN模块扩展了Yaw专用受限发送，保留原摩擦轮发送限制和停止路径。默认70通道、50ms，App21个.c，工程清单58项。摩擦轮操作见[新遥控逻辑与摩擦轮步骤](../../01_学习笔记/新遥控逻辑迁移与摩擦轮操作_20261013.md)；原CH1按住、串口WHEEL BOTH步骤保留为历史版本资料。

Yaw当前源码为**GL60II_PID_BENCH_V1D**：GL60Ⅱ、CAN1 ID1 / 反馈ID0、MIT模式，`gl60_ii`、`yaw_controller`、`yaw_backend`、`yaw_console`四组配对模块。上电Yaw请求及监测关闭；安全CH5 OFF状态下`YAW ON`只开启失能监测，取得静止失能反馈后，再人工CH5 OFF→中档才使能。MCU位置PID默认仍0.35/0/0.015，目标±5°、运行位置硬边界±8°，协议力矩请求±0.10 N·m，发送编码2028～2067。V1D只放宽首次使能前状态0/13的无输出观察阈值：速度360°/s、位置跳变360×接收间隔秒+3°、相对位置45°；FC尝试或实际状态1后立即恢复原60°/s、跳变60×间隔秒+0.1°及±8°限制，STOP/OFF不取消严格保护。关闭监测中来源明确的速度/跳变记录，静止500ms后可经单次人工CLEAR、新FD/状态0、人工ON重新捕获参考恢复；其他故障仍拒绝。STATUS的LIMIT_NM、70列FireWater及VOFA控件分配保留。步骤见[Yaw首版与VOFA调参](../../01_学习笔记/Yaw首版驱动与VOFA调参_20261013.md)。V1D完整构建及35组离线测试通过，10:43实机已确认V1D初始状态；后续仍由用户通过EIDE/ST-Link构建烧录，带载非零目标、运动中保护及30°指标尚未验收。现场电机动力线不能单独拆卸，按整机统一断电/上电操作。

本工程沿用上一份考核的平铺App、配对.c/.h、Core、Drivers、Middlewares、MDK-ARM和Tests格式。当前支持遥控保护、USART1电机参数采集、CAN2受限单/双轮控制和CAN1 Yaw小角度位置控制。Pitch、拨盘实际驱动尚未加入，`flywheels_ready`仍0。读取DM/VESC仍见[参数采集步骤](../../01_学习笔记/USART1电机参数采集步骤.md)。1000rpm双轮档、200rpm首档、0.5A观察及500ms点动保留为独立编译回归，完整考核性能尚未实机验收。

`APP_MOTOR_DRIVERS_IMPLEMENTED=0`继续关闭泛用动力发送，`APP_YAW_ENABLED=1`只开放CAN1 ID1固定命令及受限MIT给定。CAN2受限控制仍仅70/71，上电未选轮；只发SET_CURRENT，不发SET_RPM或写电调配置。每轮软滑行独立，硬超速、反馈电流绝对值>3A、FET≥60℃、坏帧或反馈过期停止两轮。原遥控和双零失败重试保护保留，拨盘就绪始终0。2A为主控给定上限，3A为反馈判据，均不能等同于电调保存的±20A硬限幅。时长默认0表示按住运行；关闭速度环或启用非0时长时回归历史0.5A、2000ERPM保护档。INFO和SPEED均只读。

## 工程入口

用户指定烧录流程为VS Code + EIDE + ST-Link。后续直接修改原工程源码，指导在同一工作区“eide: 重新构建”成功后“eide: 烧录”（Ctrl+Alt+D）；不向用户发送独立.hex文件。现有ST-Link/SWD配置使用本工程构建输出。

- Keil：`MDK-ARM/Gimbal_Control.uvprojx`。
- EIDE：`MDK-ARM/Gimbal_Control.code-workspace`，目标 Gimbal_Control，ARM Compiler 5。
- CubeMX：`Gimbal_Control.ioc`；重新生成时保留 USER CODE，并检查 App 源文件分组。
- 模块说明：[App/README.md](App/README.md)。上板步骤：[基础版上板与VOFA观察](../../01_学习笔记/基础版上板与VOFA观察.md)。

在考核仓库根目录只编译、不下载：

```powershell
& '.\16_云台调试\Output\Gimbal_Control\Scripts\build.ps1'
```

构建脚本从 Keil 工程读取完整源文件列表，调用本机 EIDE 构建器和 ARM Compiler 5。工具路径不同可通过 `-ToolchainRoot`、`-BuilderPath` 指定。默认产物：`MDK-ARM/build/Gimbal_Control/Gimbal_Control.hex`。Keil 自身构建的目录为 `MDK-ARM/Gimbal_Control/`。

之前EIDE旧内存配置写回的问题已由用户处理；当前磁盘源清单与Keil一致，App包含21个.c，完整工程清单58项。若重新构建提示缺少模块，再核对当前EIDE的App分组是否包含新增四个Yaw源文件；无需另建工程、锁定配置或停止编辑器。

本机EIDE 3.27.2的“选项字节配置 / Option Bytes Config”是打开INI文件的按钮，没有None下拉选项；None是“外部加载算法”的值。本次无需操作选项字节配置。当前引用的 `.eide/gimbal_control.st.option.bytes.ini` 不存在，下载器不会附加选项字节写入命令；若之后点击该按钮创建了文件，应检查是否含有效键值，避免无意改变芯片配置。

## 遥控映射

默认APP_REMOTE_PROFILE_ASSESSMENT=1、APP_REMOTE_PROFILE_LEGACY=0。用户已验证四个小开关上1000、中1500、下2000，CH7/8下档松手回中；Failsafe为CH1～4及CH7=1500、CH5/6/8=1000。CH8低档先锁存故障，故障期间的预设CH5 OFF不能用于恢复解锁。

| 通道 | 建议控件 | 行为 |
| --- | --- | --- |
| CH1 / CH2 | 自回中摇杆轴 | Yaw / Pitch角速度请求，最大±60 / ±45 °/s，中心死区±30通道值；Yaw首版后端实际手动目标变化限±10°/s、目标±5° |
| CH3 / CH4 | 左大摇杆纵/横轴 | 测试选择Pitch/Yaw的±30°，由CH7确认；斜向拒绝 |
| CH5 | 左侧总模式开关 | 上关闭、中正常、下测试；上→中/下且安全中位才解锁 |
| CH6 | 左侧摩擦轮开关 | 上关闭、中两轮开启+单发接口、下两轮开启+连发接口 |
| CH7 | 右侧测试回弹开关 | 上回参考角接口、中待命、下确认一次所选阶跃 |
| CH8 | 右侧扳机回弹开关 | 上总撤权/失联锁、中释放、下扳机；拨盘驱动仍关闭 |
| CH9 / CH10 | 备用 | 不参与新遥控动作 |

阈值：≤1300为低档，>1700为高档，其余中档。新Mapper检查CH1～8范围800～2200；既有iBUS帧校验保持原样。历史映射通过APP_REMOTE_PROFILE_ASSESSMENT=0显式回归。

解锁前两个大摇杆全部回中、CH6上档关闭、CH7/8中档；CH5先上档保持至少0.5秒，再中档正常或下档测试。上电已处于ON不自动解锁；故障后新OFF帧必须晚于故障/自动双轮准备屏障。正常CH6 OFF保留总解锁，重新ON仍需双轮停稳；失联、安全锁、STOP、发送故障要求CH5重新解锁。

CH5测试模式禁止摩擦轮和拨盘，CH7确认或回参考角只发布接口；Yaw首版不执行CH7的±30°阶跃。退出测试时旧CH6 ON不恢复，必须先OFF再ON。Pitch和拨盘后续再加入真实驱动，Yaw先通过串口±5°目标逐轮调试。

## VOFA 和 STOP

USART1输出`gimbal:...\r\n`，VOFA选择FireWater，数据间隔50ms。生产默认共70通道，下标从0开始，原I0～I50位置保留，新增I51～I69为Yaw。历史39 / 29通道观察配置需同时关闭`APP_YAW_ENABLED`；表格如下：

| 下标 | 含义 |
| --- | --- |
| 0..9 | CH1..10原始通道值 |
| 10 | 合法i-BUS帧新鲜度；不能独立证明RF链路正常 |
| 11 / 12 | 遥控逻辑解锁 / 点动实际输出许可；未选轮12为0 |
| 13 | SAFE=0、READY=1、ARMED=2、FAULT=3 |
| 14 / 15 | 当前保护原因 / 最后合法帧年龄ms（从未收到帧时年龄显示0） |
| 16 / 17 | Yaw / Pitch角速度请求°/s |
| 18 / 19 / 20 | 摩擦轮请求 / 发射模式0/1/2 / 发射事件累计数 |
| 21 / 22 / 23 | 云台模式（新配置0正常/3测试） / 阶跃偏移° / 阶跃事件累计数 |
| 24 / 25 | CAN1 / CAN2合法接收帧数，不能替代电机在线判定 |
| 26 | 受限点动后端就绪；不代表完整考核驱动就绪 |
| 27 / 28 | 遥控UART故障代次 / UART4接收字节累计数 |
| 29 / 30 | 左 / 右ERPM |
| 31 / 32 | 左 / 右反馈电机电流mA |
| 33 / 34 / 35 | 选择0关/1左/2右/3双轮 / 主给定mA（双轮时左） / 会话活动 |
| 36 / 37 / 38 | 点动故障位 / 停机待重试 / 可触发下一点动 |
| 39 / 40 / 41 | 主控制器斜坡目标ERPM / 滤波ERPM / 按7对极估算rpm（双轮时左） |
| 42 / 43 | 主控制器给定到限 / 软件速度区间标志 |

| 51 / 52 / 53 | Yaw相对参考实际角° / 目标角° / 反馈角速度°/s |
| 54 / 55 | MCU力矩请求 / MIT反馈力矩字段，N·m |
| 56 / 57 / 58 | MCU位置控制KP / KI / KD |

| 66 / 67 / 68 / 69 | 驱动温度℃ / 电机温度℃ / 绝对位置rad / 有效反馈累计 |

原因码：0无、1上电、2帧失效/超时、3Failsafe、4UART、5CAN、6控制迟到、7STOP、8未回中、9开关中位、10关键反馈失效、11执行器故障。摩擦轮故障位另见点动步骤。

文本命令带回车或换行：REMOTE INFO查询新遥控版本，WHEEL INFO/STATUS/SPEED查询原摩擦轮配置和状态，WHEEL OFF及STOP撤权停机。YAW STATUS/INFO只读；YAW KP/KI/KD为ASCII单参数热调，YAW TARGET为相对本次参考的角度目标。YAW OFF取消Yaw请求并总撤权，STOP保留Yaw请求但需要人工新的CH5 OFF→ON；YAW ZERO只在关闭且静止安全状态捕获软件参考，不发电机0xFE。新配置中WHEEL LEFT/RIGHT/BOTH返回REMOTE_CONTROL拒绝，双轮由安全OFF流程自动准备。DIAG ON停止并取消选择/自动准备；DIAG OFF后仍须新的OFF安全流程。原0mA滑行停机和拨盘就绪恒0保留。

SPEED双轮输出会话摘要及两行SPEED_NODE，统计停止后保留。停止原因0无、1输入请求消失、2许可撤销、3硬故障、4外部Stop接口、5定时结束、6启动时未停稳。BAND_MAX_MS/IN_BAND仅表示原始及滤波速度在42000±700ERPM的软件区间，不授权拨盘。FILTER_ERPM/RPM_EST停止后是最后控制样本，实时速度看STATUS；统计详细含义见双轮操作指南。

## 下一阶段补全位置

参数采集启动器为 `Scripts/capture.ps1`，电脑解码及保存放在 `Tools`。采集会暂停FireWater输出，结束后恢复；关闭VOFA串口后再运行。固件标识为`GIMBAL_DIAG_1`，每笔查询1200ms超时，电脑逐项等待并保存原始报文，完整VESC配置只在已知签名和长度匹配时解码。GL60Ⅱ驱动配置、机械方向/零点/限位、拨盘每发步距不能由本工具完整获取。

当前`flywheel_jog`解码两轮STATUS1/4、验证新鲜度和受限会话，`flywheel_speed`提供独立PI，`motor_backend`聚合到原摩擦轮保护流程；Yaw使用专用协议、控制器和后端接入统一遥控保护。下一阶段分轮取得Yaw静止反馈及真实撤权结果，确认方向、参考与限位，调小角度闭环后再扩大到30°。继续核对双轮6000rpm档的实际轮速换算、启动响应、持续稳速与降噪，并补DM、C610正式驱动和拨盘每发步距。软件通过不等于实机指标达标。泛用`CanBus_Send`继续关闭，摩擦轮停机走固定双零接口。VESC现有1000ms超时作为MCU失效时兜底；GL的CAN Timeout=20000单位和真实停机效果未知，两者实机仍须验证。

软件检查见 [Tests说明](Tests/README.md) 和 [软件验证记录](../../02_过程记录/软件验证记录.md)。软件通过后仍需按[实机验收记录](../../02_过程记录/实机验收记录.md)完成遥控保护专项，再开始动力调试。
