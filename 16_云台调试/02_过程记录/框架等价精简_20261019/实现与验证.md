# 框架等价精简与验证（2026-10-19）

## 结论

已在用户指定的原 EIDE/Keil 工程内完成等价精简。现有功能、PID、机械边界、周期、串口协议和考核判据保持；未连接串口/CAN、未烧录、未驱动电机。用户已明确选择保留旧单环、限幅对照及 Yaw 实验前馈/轨迹能力。

本次改善的是代码重复和控制周期内不必要的数据复制，没有实机证据证明 30°阶跃响应时间或超调改善。

## 修改内容

| 位置 | 改动 | 保持行为的依据 |
| --- | --- | --- |
| app_console.c | 删除两个恒假的旧遥测代码块，共14行 | 位于 APP_YAW_ENABLED 的 else 内，却再次要求同一宏为真，所有配置均不可达 |
| console_parse.h、yaw_console.c、pitch_console.c | 两份数字/PID三参数解析器共用头文件中的静态内联实现 | 原 strtof、有限值、空格、尾字符检查和失败时部分写入语义逐项保留；没有新任务或 C 编译单元 |
| app_tasks.c、yaw_backend.c/.h、pitch_backend.c/.h | 新增只读 GetStepId；控制任务改用编号接口 | 临界区、四次同步的宏条件/位置/顺序完全保留；原 GetStep 和 TakeStepReport 接口保留 |
| yaw_backend.c | 阶跃参数快照按单环/双环二选一 | 删除双环模式下随后必被覆盖的三项单环赋值；两种编译配置的最终字段相同 |
| pitch_controller.c | 删除更新函数中 age >= HALF_TICK_RANGE | age 为 uint32_t，固定100ms超时已包含所有半周期以上的取值；反馈接收函数的时间方向判断保留 |
| remote_mapper.c | 遥控回中复用 step_selection_centered | 此字段在同一函数前面已用相同四项范围判断计算 |
| 4个现有测试文件 | 增加轻量编号接口的一致性断言 | 覆盖重置/拒绝启动/启动/中止/完成/报告消费/三个周期递增，无新增分组或改动测试轨迹 |
| README.md、App/README.md | 整理为当前入口、参数、模块依赖和操作概要 | 精简前全文保存在 before 中，学习笔记及过程记录未删除 |

当前双轴配置每2ms控制周期原为读取编号复制4份完整192字节阶跃结构，新接口只读4个 uint32_t。辅助读取函数在 AC5/O0 下的栈帧由200字节降至8字节；控制任务总体最大调用路径仍由启动准备链决定，链接器估计的最大深度仍为1784字节，不能宣称整体任务栈已减少192字节。

同一 EIDE AC5/O0 参数下，ROM 从 **122,560字节降至122,500字节，减少60字节**；静态 RW/ZI 保持928/35,776字节。减小源码重复不等于大幅减小固件体积，关闭的实验代码本就受预处理/链接裁剪。

## 没有删除的内容

- 全部32个 App C 文件都有工程引用，原69源项清单保留；没有发现可直接移除的完整业务模块。
- yaw_cascade 同时负责 Pitch 双环及重力补偿；yaw_step 是双轴测量基础。Pitch 的独立300ms判定和重力快照不是冗余。
- 摩擦轮6000rpm、拨盘、遥控映射、自动准备、新OFF解锁屏障、故障代次、停机确认/重试和CAN邮箱撤销均仍在调用链。
- 旧单环、限幅双环、Yaw实验规划/前馈和历史遥控/轮子档按用户确认保留，生产默认关闭的路径仍由原测试显式验证。
- 两轴准备/清错/使能/停机握手及坐标失效规则不等价，没有合并状态机。

## 保持的考核与机械约束

Yaw 位置PID 16.63/0.12/0.269、速度PID 0.0081/0.003/0.000209；Pitch 位置PID 18.2/0.44/0.04、速度PID 0.0065/0.014/0.000004、重力系数−0.13均未改动。滤波、控制任务2ms、Yaw提交10ms、Pitch提交2ms及CAN设置保持。

正式判定继续按5秒观察、末1秒时间加权稳态误差、最终进入±0.2°并保持至窗口末，Yaw250ms/Pitch300ms、超调和稳态误差各0.2°。没有把首次入带误当最终稳定通过。

Pitch目标范围仍为−18°～+33°，越界保护−19°～+34°；−30°绝对目标按原设计拒绝。若要新增反向30°实物试验，必须先由用户确定机械范围内的试验基准和方案，不能直接放宽限位。
