# Yaw规划速度前馈权重修正（V2L）

用户实测V2K、SHAPE=160、位置9/.2/.05、速度.003/.003/0时，超调约9.43053°，峰值约39.43°。这次结果明显不适合继续沿用。先在本轮完成后`YAW SHAPE 0`恢复原阶跃；仍在大幅往返时使用原CH5 OFF/STOP流程。

## 修正原因

V2K将规划速度固定以1倍加入内环参考，并对位置D补偿对应参考速度：

```text
v_cmd = P位置*(p_ref-p实际) + I位置 - D位置*v估算
        + (1+D位置)*v_ref
```

这不是仅仅把位置目标变平滑。30°/160 ms的参考速度峰值约351.56°/s，在位置D=0.05时，单独的规划速度项峰值约369.14°/s，之外还有位置跟踪修正。尚未辨识实际速度环跟踪能力就固定使用这个权重，缺少了单独关闭和逐步验证的入口。它是需要修正的设计；角度截图还不能证明全部9.43°超调都由该项导致。

`YAW FF OFF`和FMAX只作用于原六项力矩前馈，不会关闭/限制上述速度参考项。

## V2L新增独立权重

固件版本：`GL60II_CASCADE_SHAPE_V2L`。

```text
v_cmd = P位置*(p_ref-p实际) + I位置 - D位置*v估算
        + β*(1+D位置)*v_ref
```

- β默认0，配置命令`YAW SHAPEV 0`。这时只有平滑位置参考，规划速度项完全关闭。
- `YAW SHAPEV`查询当前权重；`YAW SHAPE`中的`VEL_FF`现在也是数值权重。
- `YAW SHAPEV 0.05`表示5%的规划速度项，不是0.05协议Nm，也不是原FKV。
- β=1在数学上保留V2K的旧行为。代码范围0~1不是本机实测安全范围，当前不再建议测试1。
- SHAPE默认仍0。`YAW SHAPE 0`完全退出轨迹/参考速度路径，与β设了多少无关。
- 规划时间和速度权重均保存在RAM，复位后分别归0。正常停机/设零保留配置并取消活动轨迹。
- 全部5秒试验运行中拒绝修改β，同值重复写入不改变状态；配置不启动电机、不清当前保持积分。
- 规划段外环积分冻结、内环积分与抗饱和、原始最终30°目标及验收计时保留。

## 当前先怎样验证

重新构建、烧录原EIDE工程，沿原物理基准和遥控准备流程，确认版本V2L。完成当前测试后，在零位设置：

```text
YAW FF OFF
YAW SHAPE 0
YAW SHAPEV 0
YAW POS 9 0.2 0.05
YAW VEL 0.003 0.003 0
YAW SHAPE
```

逐条等待回复。先保存同负载、同基准下的SHAPE=0对照。改PID后等零位重新停稳并保持至少5秒。

再只试：

```text
YAW SHAPEV 0
YAW SHAPE 160
YAW SHAPE
```

查询应有`ENABLED|1|MS|160`和`VEL_FF|0`。HOME回零停稳并按相同时间等待后，`YAW STEP 30`，完整5秒后`YAW RESULT`。结果应带`SHAPE_MS|160|SHAPE_V|0`。

**这一步仅验证纯平滑参考是否有益，尚未证明会消振或达到250 ms。** 不同时改PID/六个旧前馈系数，不直接从β=0跳回1。若β=0也出现大超调或持续振荡，退出SHAPE并检查速度/力矩过程，不能继续盲加β。

只有纯平滑模式可重复、回摆可控之后，才考虑以0.05的小步验证速度权重；是否保留仍看完整SETTLE05和超调，而非仅看第一次峰值。250 ms验收从原始指令开始，包含轨迹时间；不能把规划结束时刻作为新起点。

## VOFA只新增一个滑条

| 项目 | 设置 |
| --- | --- |
| 名称 | YAW SHAPEV |
| Str命令 | `YAW SHAPEV %f`，末尾附加真实LF |
| 回读通道 | I70 |
| 初始建议窗口 | 0~0.30，步长0.05，小数位2 |
| 初始值 | 0 |

先配置范围/初值，再绑定命令；关闭循环发送。上方回读与`YAW SHAPE`都确认0后再测。

Yaw扩为71列，原I0~I69顺序保持，I70是配置的速度前馈权重；Pitch原58列保持。I67仍显示未乘β的轨迹速度，所以β=0时I67运动中可以非零，实际加入的参考速度项为`β*(1+位置D)*I67`。

观察三组曲线：I0/I1/I66角度，I2/I3/I67速度，I5/I55/I57总请求/旧前馈/速度积分。I61/I62仍是新验收稳定时间/结果。只发一个稳态瞬间无法判断到位前发生了什么。

## 软件验证边界

修正增加了β默认0、0/.25/1权重缩放、非法输入、测试中改参拒绝、历史条件冻结与I70回读的检查。编译/回归结果详见`02_过程记录/Yaw规划速度前馈权重修正_20261018`。软件行为验证不等于真实闭环稳定性验证；没有连接串口或烧录硬件。
