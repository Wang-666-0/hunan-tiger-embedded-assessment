# JOG_L300_R200_V1：左轮0.3A档

用户反馈左轮仍疑似逆时针，并确认运动时I34约0至-200，请求稍加电流以观察。仅提高左节点70幅值至300mA，负极性保留；右71仍正200mA。没有实物确认持续反转的波形/视频，因此本档不继续翻转极性、不升转速阈值或延长点动。

## 变化与检查

app_config.h统一登记左右限流，纯点动按所选轮限幅，CAN按节点再次检查；头文件引用配置上限，消除重复200/300常量。幅值仍100mA/20ms斜坡、单次500ms，上电OFF，两轮反馈/停转与遥控保护不变。左-300mA报文为FF FF FE D4，右+200为00 00 00 C8；错符号、超节点范围、INT32极值与撤权发送拒绝。

新增WHEEL INFO，只读取编译版本、左右幅值/符号、时长、ERPM保护与ENABLED，不选轮、不发送CAN、不改变诊断/运行许可；若UART发送失败按原逻辑撤权。预期板上回复：

```text
W|INFO|JOG_L300_R200_V1|LEFT_MA|300|RIGHT_MA|200|LEFT_SIGN|-1|RIGHT_SIGN|1|MS|500|ERPM|2000|ENABLED|1
```

原WHEEL STATUS的10字段及gimbal39字段保持布局，I34带符号且左绝对值最多300、右200。原GIMBAL_DIAG_1采集标识与读白名单保留，不写电调配置、不开放GL/DM/C610动力。

## 验证证据

ARM GCC -Wall/-Wextra/-Werror + Unicorn，12组、156578断言、0失败，全部正常返回。覆盖左300与右200独立限幅、300mA端序/错符号、符号与遥测一致、500ms/故障/停机重试，以及INFO的两种feature模式、只读无副作用、诊断不中断和UART错误停止。

ARM Compiler 5.06全量53项（52C+1汇编），0错误、0警告，ROM34084字节、RAM33608字节。构建后源码与测试报告哈希一致，见[核验JSON](构建与自检核验.json)、[自检报告](自检报告.json)、[编译日志](compiler.log)及完整构建输出。此次没有连接串口/CAN/ST-Link或执行烧录。

用户只通过原VS Code/EIDE+ST-Link工作区重新构建后Ctrl+Alt+D烧录；不向用户发送独立固件文件。下一步先只读INFO核对版本，再按[测试步骤](../../01_学习笔记/左轮0.3A点动与版本核对.md)做一次左轮点动，报告实际方向、I34/I29与故障。出现反向持续转动、抖动、异响或故障时结束本档，不自动加流。实物结果尚待用户反馈。
