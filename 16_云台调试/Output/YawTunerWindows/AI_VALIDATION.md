## 本次新增

- 配置模型地址、API 类型、模型 ID 和 API Key，支持 Responses API 与 Chat Completions 兼容接口。请求格式参照 [OpenAI 结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。
- 软件自动完成“真实六参回读 → 双向基线 → 模型建议 → 本地检查范围和预算 → 候选阶跃实测 → 本地比较 → 固定参数独立验收”。
- 全局变化以本次 AI 启动六参为固定中心，最多 ±15%，不能通过多轮调整累计越界；始终为独立验收预留 10 次阶跃。

- 默认不保存密钥；勾选记住后使用 Windows DPAPI CurrentUser 加密，设置文件与试验目录分开，分发包排除设置和运行数据。

## 仍需实机确认

真实 API 连接、模型实际建议效果、USB 串口持续吞吐和云台动态指标尚未联调。程序不会自动读取本聊天的登录凭据，需要用户在软件填写可用接口、模型和密钥。模型建议不构成达标证据，只有实机独立验收满足三项硬条件及完整采集才能认定本轮通过。

当前协议没有输出板端阶跃精确起点毫秒戳，精确响应时间仍依据板端成绩。主机波形覆盖不等于捕获了每一个 CAN 反馈。独立速度环辨识、贝叶斯优化及 Pitch/摩擦轮/拨盘的完整考核未纳入本次新增范围。
