# AI 自动调参使用教程（0.2.0）

这一版把模型建议接入软件：你完成现场准备并启动任务后，软件自动做正负阶跃、比较实测成绩、询问模型下一步，并在候选达标后重复验收。这里的 AI 是你配置的模型 API，不会读取当前聊天中的登录状态。

## 1. 打开新版

运行 `bin\AI\YawTuner.exe`。旧版 `bin\YawTuner.exe` 保留，AI 功能在新版的“AI自动调参”页。

先用“演示模式”熟悉过程，并在 AI 页选择“离线脚本演示（非实时 AI）”。这个组合使用模拟云台和脚本建议，不调用真实模型，也不能证明实机达标。选择“实时模型接口”仍会调用配置的服务，即使当前连接的是模拟云台。

## 2. 配置模型

在“AI自动调参”页填写：

| 设置 | 填法 |
| --- | --- |
| API 地址（Base URL） | 使用 OpenAI 时填 `https://api.openai.com/v1`；其他兼容服务按服务商给出的 HTTPS 基础地址填写，不要额外加 `/responses` 或 `/chat/completions`。 |
| API 类型 | 选择“Responses API”或“Chat Completions 兼容接口”，以服务商支持情况为准。 |
| 模型 ID（Model） | 填服务商提供、你有权限调用的准确模型名称。 |
| API Key | 只在软件输入框填写，不要发到聊天或写进工况。 |

默认不记住密钥。需要下次继续使用时，点击“保存设置”；只有勾选“记住密钥”才会同时使用 Windows DPAPI 加密保存密钥，仅当前 Windows 用户可解密。设置文件位于新版 EXE 旁的 `private\ai-settings.json`，不在试验会话或导出报告里。更改 API 地址会清空窗口中的密钥，需要重新填写。

选择“实时模型接口”，再点“测试接口”。测试只发送合成调参样例，不下发电机命令；**会发起真实 API 请求，可能计费**。无法通过时，先核对地址、API 类型、模型名和密钥。默认勾选“严格 JSON Schema”；服务商只支持 JSON 模式时可取消勾选，返回内容仍须通过本地严格 JSON 校验。更换服务商不会自动获得兼容保证。

## 3. 连接云台并准备

1. 先断开 VOFA，释放串口，然后选择 COM 口并“连接设备”。
2. 按固件原有流程人工建立零点、解锁并使能 Yaw。保持遥控在线、四杆回中、摩擦轮关闭、CH7/CH8 释放。
3. 核对板端六参、故障和就绪状态，填写负载、供电、安装等工况。AI 从**启动时真实回读参数**开始，不用源码默认参数覆盖它。
4. 现场应能随时使用遥控保护。红色“停止 / OFF”会请求固件全系统停止，Pitch 等也会失能，负载应按现有机械要求支撑。

软件不会替你使能、清故障或建立新零点。

## 4. 启动 AI 自动调参

首轮保留默认限制：**总预算 24 轮、最多 4 次模型建议、相对启动参数全局 ±15%**。每一次 +30° 或 −30° 都算一轮，记录完整 5 秒；总耗时还包括回零、静止等待和模型响应。

点击“开始 AI 自动调参”，之后自动执行：

```text
回读并保存启动参数
→ 正、负 30° 基线测试（2 轮）
→ 回零，模型分析本次实测摘要
→ 本地检查模型建议的单参数候选
→ 候选逐组正、负阶跃并按实测成绩选择
→ 重复建议与试验，直到候选达标或预算用完
→ 达标候选固定参数，正负各 5 次独立验收
```

模型只能建议修改哪个 PID 增益及少量百分比偏移，不能发送任意控制命令。软件再次检查板端范围、回读精度、全局变化范围和剩余预算；默认不会把原本为零的增益自行变成非零。

模型响应期间云台回零保持，软件继续检查通信、反馈、保护状态和外部改参。运行中不要通过其他串口终端或遥控触发新的阶跃、修改参数或控制目标。

## 5. 判断结果

只有同一工况、固定六参的独立验收全部通过，才能认定本轮验收通过。每轮都必须满足：

- 真实 ±30° 阶跃，完整 5 秒板端成绩和主机波形；
- 最终进入并持续保持 ±0.2° 的时间 ≤250 ms；
- 超调 ≤0.2°；
- 末 1 秒稳态有效，平均误差绝对值和误差峰值均 ≤0.2°。

一次漂亮的波形、模型说“通过”或演示结果都不能替代独立验收。若启动基线已经达标，软件可直接验证它，不必为了调参而改参。

| 结束情况 | 参数处理 |
| --- | --- |
| 实机独立验收通过 | 回零后保留通过的候选六参在 RAM。 |
| 正常用完预算或正常结束但未达标 | 回零并恢复本次 AI 启动时参数。 |
| 用户停止、通信/反馈异常、模型请求或解析失败等异常 | 取消后续操作并尽力发送 OFF；不自动恢复参数、重新使能或清故障。 |

在线参数都只在 RAM 生效，不写 Flash，也不改源码默认值。停止后先按原固件流程检查和人工恢复；重新连接时应再次核对实际六参。

## 6. 保存和下次继续

会话目录显示在窗口底部。原始串口、72 通道遥测、每轮成绩和波形会自动保存；每次 AI 任务另存于 `ai_runs\本次唯一编号\`，包含启动参数 `anchor.json`、建议和决策 `trace.jsonl`、最终结果 `report.json`。中断计划的详细轮次仍以会话的 `trials` 文件夹为准。导出时保留整份会话，便于核对最差成绩和中止原因。

API Key 不应出现在试验日志或导出报告里；发送到配置服务商的是调参摘要、工况和成绩。重启软件或新建一次 AI 任务会重新建立起始参数和预算，不是无限后台调参。

本版尚未完成真实模型接口及云台联调。离线检查和演示用于验证软件流程；最终动态指标和通信表现需要在你的设备上验证。当前只负责 Yaw，其他考核项目仍需分别验收。
