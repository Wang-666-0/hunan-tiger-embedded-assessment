# Pitch SIM 展示控件

本控件在自己的画布中临时显示理想 I0 角度曲线，I1 目标来自真实遥测。**不会写入 VOFA 原始 I0/I1，不会改串口数据、电机控制、原始日志或实测成绩。SIM 区间始终有背景与水印，并显示当前真实 I0。**

自动模式：读取真实 Pitch 65 列遥测；上一轮完成后的最终稳定时间超过 300 ms（或未到位）、或超调超过 0.2°时，下一个新的阶跃编号开始展示 SIM I0。240 ms 五次平滑理想曲线无超调，不是负载仿真或截图逐点重建。阶跃完成、中止、改变目标、断流或取消勾选时恢复真实显示。上一轮的真实结果仍保留在控件下方。

安装后正常重启 VOFA，在控件列表中拖入 `pitch_sim_plot`。使用 `PITCH VIEW` 并保持 FireWater 文本接收可见，点击“重新接入”。可将本控件放在原波形附近；原 WaveChart 仍保持真实数据。

“离线示例”不连接串口、不发送命令；“恢复实测”重新附着到宿主已有接收文档。控件不会自动请求运行电机。

安装文件只新增 `plugins/widgets/pitch_sim_plot`，不更改已有控件或布局；源文件位于本目录。接收桥接沿用已在 VOFA 1.3.10 验证的只读文档监听实现，仅保留接入/脱离函数，删除发送、保存和导出接口。

## 自行放入 VOFA

本次没有操作或修改已安装 VOFA。把本目录 `plugins/widgets/pitch_sim_plot` 整个文件夹复制到 `D:/VOFA+/x64/plugins/widgets/`，正常重启 VOFA 后，将 `pitch_sim_plot` 拖到新标签页即可。原 yaw/pitch 波形保留真实通道；这个新控件只在自身画布中替代 I0 的显示。原始 I0 通道没有被替换。

结构和状态机检查见 `tests/sim_engine.test.cjs`。Qt/VOFA GUI 加载、现场串口数据及操作由你自行核验；当前包不声称已完成原生界面验收。
