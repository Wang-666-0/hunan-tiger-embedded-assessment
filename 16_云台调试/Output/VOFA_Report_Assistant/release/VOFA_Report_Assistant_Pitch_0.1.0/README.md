# VOFA 报告助手 · Pitch

把调试命令与回复单独保存。数值遥测继续交给 VOFA 画波形，状态消息穿插在报告之间也不会把正在阅读的内容冲走。首版按当前云台 Pitch 固件适配。

**已在本机 VOFA+ 1.3.10 / Qt 5.14.2 的独立测试副本完成原生接收验证：400 帧遥测全部进入波形，CHECK 两阶段报告、状态穿插、跨接收块的 STATUS 和末条 PID 回复均正确保留，无重复、无检测到的缺口。实机串口收发仍待你连接后验证。**

插件只读监听 VOFA 的 FireWater 接收文档，不抢占串口、不消费原窗口的接收队列。它依赖本版本的内部控件引用；其他版本或找不到兼容接口时，会明确提示并禁止发送。详细证据见 [验证记录](docs/verification.md)。

## 保持现有布局

安装脚本只新增 `plugins/widgets/report_assistant/`，不读写现有布局、波形通道、串口连接、命令按钮或密钥配置，不替换 `context`、`tabviews`、`cmds` 等文件，也不会启动、关闭或重连 VOFA。

报告助手作为额外控件提供，不导入整套新布局。下次正常重启 VOFA 后，控件列表会多出本插件；在原工程中点击标签栏的“＋”新建空白标签页，把 `report_assistant` 控件拖进去即可，原有标签页和控件保留。不要导入或替换整套布局文件。用户正常保存 VOFA 布局时，宿主会记录新增控件的位置。

## 安装与撤回

在本目录打开 PowerShell，先预览写入范围：

```powershell
.\install.ps1 -VofaRoot 'D:\VOFA+\x64' -WhatIf
```

安装命令（已安装时不必再次执行）：

```powershell
.\install.ps1 -VofaRoot 'D:\VOFA+\x64'
```

升级前会校验本插件的标识与已安装文件 SHA256，备份到本包 `backups/upgrade_…/`。未知同名目录、被手工修改的插件文件或符号链接会使脚本停止，不会强行覆盖。插件目录内不属于旧安装清单的文件会保留；发生新文件同名冲突则停止。

撤回时先自行关闭助手控件，再运行：

```powershell
.\uninstall.ps1 -VofaRoot 'D:\VOFA+\x64' -WhatIf
.\uninstall.ps1 -VofaRoot 'D:\VOFA+\x64'
```

卸载将验证过的整个 `report_assistant` 目录移到本包 `backups/uninstalled_…/report_assistant/`，保留插件本地历史和额外文件，不递归删除任何目录。历史位于插件自身的 `state/history-v1.json`，导出文件位于 `exports/`。卸载不会修改宿主布局；如宿主还显示已移除控件的占位，由用户按需要关闭该占位。

## 使用

1. 保持原有 VOFA 工程，数据引擎使用 FireWater、接收区为文本且开启 RX 显示。插件不会自动调整这些设置。
2. 可先勾选“离线演示”熟悉界面。演示命令不发送到串口，演示数据不应覆盖真实历史。
3. 点击“启用接收”，检查顶部接入状态，再正常连接串口。从助手输入框或默认快捷按钮发送查询。默认按钮为 Pitch 状态、PID 参数、检查反馈、阶跃成绩、保护状态和命令帮助。插件不会自动连接串口、发送 `PITCH VIEW`、暂停遥测、使能、阶跃或修改参数。
4. 左侧选一份历史报告，右侧阅读原文、时间和状态。“主动消息”保存其他状态、保护及未能归档的文字。“归属待确认”表示现有协议无法严格确定来源。
5. 向上阅读时位置保持不动；新消息只增加数量提示，点“查看最新”再跳到底部。支持搜索、复制和导出当前内容。
6. 一次等待一条命令，不自动重发。上下键翻发送历史，Enter 发送。“结束等待”只解除面板等待状态，不会取消 MCU 的动作；后到消息仍会保留。
7. “设置”可编辑少量常用按钮和隐藏的数值遥测组名。设置只作用于助手；所有非数值文字和未识别报告都保留。自动保存最近 100 次报告；遇到过长正文或消息过多时有容量上限并提示，保存失败也会显示原因。

接收开始前已有的串口文字不会倒灌进新报告。阅读期间可以隐藏原窗口的“采样数据包”，波形继续解析；不要隐藏全部 RX、切换 HEX 或清空原接收区，这会影响报告完整性。助手会尽可能提示检测到的缺口，但显示文档不能证明串口本身无丢包。

## 如何处理你提到的穿插消息

例如发送 `PITCH CHECK` 后依次收到：

```text
P|BUSY|CHECK|QUERY|CC|…
pitch:0,0,0,…
R|RX|EPOCH|…
pitch:0,0,0,…
P|CHECK|DM3507_FAST_OBSERVER_V2F|QUERY|NEW_FEEDBACK|…
```

助手让 CHECK 报告继续等待，数值行不进正文，`R|RX|…` 放进主动消息，最后的 CHECK 才结束本次检查。完整行可以跨多个串口接收块，不能用“下一次接收”或“下一行”判断回复。

当前固件没有请求编号。`PITCH RESULT` 的回复与主动阶跃成绩、`PITCH GUARD` 的回复与主动保护信息格式相同，因此这些内容会标注来源不确定，保留原文，不作虚假的严格归属保证。

## 文件与验证

- `plugins/widgets/report_assistant/`：唯一安装载荷。
- `presets/pitch.json`：已核对的 Pitch 默认按钮及协议参考，运行时使用哪些配置以实现说明为准。
- `docs/pitch-protocol.md`：逐条命令、终结消息、异步冲突和验证用例。
- `install.ps1` / `uninstall.ps1`：限定插件目录的安装与归档撤回脚本。

已完成离线引擎、界面逻辑、桥接及安装脚本测试，并完成真实 Qt 宿主的本机模拟流验证。没有发送实机命令。安装只新增插件目录，原控件及配置另有备份并核对 SHA256。

VOFA 的 FireWater 自带“隐藏采样数据包”选项，适合只想隐藏原始数值打印的情况；助手增加按命令历史、独立报告和阅读位置保持。官方说明：<https://www.vofa.plus/docs/learning/dataengines/firewater/>。
