# Yaw V2P ±0.2° 考核面板

适用 `GL60II_FIXED_PID_V2P`。六参默认：位置 **16.63/0.12/0.269**，速度 **0.0081/0.003/0.000209**。保留直接双环 PID。

新版总通过要求：**最终稳定到 ±0.2°的时间≤250 ms，超调≤0.2°，稳态误差绝对值≤0.2°**，并通过完整 5 秒有效测量。首次到位时间不是稳定时间。

四个仪表绑定：**I61 稳定时间(ms)、I28 超调(°)、I30 有符号稳态误差(°)、I62 总通过**。I60 仍打印首次进入 ±0.2°的时间；原有六 PID 索引 I7～I12 和 72 列顺序保留。

本目录是独立的 VOFA+ 原生 JSON 配置。备份现用配置，再按原导入方式载入三份 `vofa+.*.json`；选择实际串口，FireWater、921600、8N1、Δt5ms，关闭循环发送。共 2 页、19 条单次命令，按钮只按下发送，不在松开时重复发。

原面板也可继续使用：把“稳定时间”仪表从 I60 改绑 **I61**，超调/误差继续用 I28/I30，总通过用 I62。固件重烧后通道即使用新标准。

JSON 结构与绑定已检查，尚未在你的 VOFA GUI 中导入验证。最新截图超调约 0.4106°，仍超过新标准。详细见[参数与通道说明](../../01_学习笔记/Yaw新参数与02度考核通道_20261018.md)。
