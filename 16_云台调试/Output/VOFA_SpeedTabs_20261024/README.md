# 拨盘与摩擦轮转速标签页

`native/` 是从本机保存的 yaw、pitch 两页配置生成的完整副本，追加“拨盘转速”“摩擦轮转速”两页；原来的页、按钮、通道绑定与其他设置保持。

- 拨盘页：点击“FEEDER VIEW”，波形为 I2 实测 / I3 目标，单位是电机转子 rpm。轮端转速需除以 I13 减速比；这里没有把转子 rpm 标为轮端 rpm。
- 摩擦轮页：点击“YAW VIEW”，波形为 I36 左轮 / I37 右轮，单位 rpm，沿用固件按 7 对极的换算。点击“摩擦轮只读状态”可回读原始速度与状态。
- 切页后需点击该页 VIEW 按钮；固件一次输出一组遥测。按钮只查询/切换显示，不启动电机、不修改 PID。
- 回到原 yaw / pitch 页时，点击原页 VIEW 按钮恢复对应遥测组。

自行操作 VOFA：先保存并备份现有配置，再导入 `native/` 下的原生配置文件。若用文件替换方式，先关闭 VOFA，再把三份 `vofa+.*.json` 放入你选定的配置目录；保留备份。生成文件来自本机 `%LOCALAPPDATA%/vofa+/100/context/` 的副本；本次没有改动该目录或正在运行的软件。

新增内容只使用 VOFA 自带 WaveChart、gauge 与 bound_bt 控件。已做 JSON/绑定/命令/保留性检查；未操作 VOFA 进行 GUI 导入验收，实机串口曲线由你连接后核验。

昨日的 Pitch SIM 是独立可选控件，见 `../VOFA_Pitch_SIM_20261023/README.md`；原生转速页不依赖它，也不会显示模拟转速。
