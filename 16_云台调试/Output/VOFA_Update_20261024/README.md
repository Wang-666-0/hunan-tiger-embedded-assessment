# VOFA 转速标签页与 Pitch SIM 控件

## 包含内容

原 yaw、pitch 页保持，增加“拨盘转速”“摩擦轮转速”和独立的“Pitch SIM 模拟”页。`native/` 中是 VOFA 原生配置；`plugins/widgets/pitch_sim_plot/` 是 SIM 控件。

## 自行导入

1. 保存并备份当前 VOFA 配置，再关闭 VOFA。
2. 把本包 `plugins/widgets/pitch_sim_plot` 文件夹放到 `D:/VOFA+/x64/plugins/widgets/`。
3. 导入 `native/` 内三份原生配置。若采用文件替换，放入你正在使用的配置目录；本次生成依据是 `%LOCALAPPDATA%/vofa+/100/context/`。本包保留了生成时原来的 yaw、pitch 页和命令，不要跳过你自己的配置备份。
4. 正常打开 VOFA，选择所需页并点击对应 VIEW 按钮。SIM 页要求已选择 `PITCH VIEW`、FireWater 文本接收可见；可点“重新接入”。

## 转速含义

| 页 | 波形 | 单位/来源 |
| --- | --- | --- |
| 拨盘转速 | I2实测、I3目标 | 电机转子rpm；轮端rpm需除以I13减速比 |
| 摩擦轮转速 | I36左轮、I37右轮 | 原gimbal遥测的滤波rpm，沿用固件按7对极换算 |

一次仅输出一组遥测。拨盘页 VIEW 发送 `FEEDER VIEW`；摩擦轮页 VIEW 发送 `YAW VIEW`。新增按钮只切换显示或读取状态，不启动电机。回到原页后用原 VIEW 按钮恢复对应组。
