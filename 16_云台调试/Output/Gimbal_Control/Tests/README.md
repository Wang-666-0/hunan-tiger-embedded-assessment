# 考核功能离线回归

运行 `run_selftests.py`，省略 `--groups` 执行当前全部 49 组；指定组名可定位问题。编译使用真实 App C 源码、ARM GCC 的 `-Wall -Wextra -Werror`；执行使用 Unicorn 和 HAL/RTOS 替身，不连接串口、CAN 或烧录器。

正式固件固定双轴、拨盘、摩擦轮及 DMA 接收。测试不再关闭单个电机；只为正常联动与拨盘独立模式分别设置唯一的模式宏。`mocks/console_peers.c` 是未纳入该单元组的外围查询接口替身，真实被测实现和具体夹具会覆盖 weak 定义；完整固件链接不使用这些替身。

覆盖内容：iBUS 和遥控保护、双轴协议与 PID、Pitch 观测/重力/制动、上电准备、阶跃/归位/视图保持、真实统计、SIM/遥测/串口 DMA、摩擦轮 PI、拨盘单发/连发/独立模式及 CAN 邮箱行为。

本轮适配说明：

- 可选轨迹整形已删除，移除对应 pitch_shape 组；专用保持包装已合并进普通控制，移除重复的 pitch_view_stiffness 组。视图锁轴的真实后端用例继续执行。
- 删除只检查落点快照、停机追踪和旧轨迹字段的断言；保留实际安全状态、PID、制动和测量结果检查。
- 旧 yaw_performance 仍按 60°硬边界断言，现改为沿当前配置边界逐步采样，并验证越界故障；控制器边界未改。
- 旧 pitch_manual90 固化了过期 PID 字面量，现与本轮开始时已有的 11.500/24.775/0.00408 默认值对齐；控制参数未改。
- 串口夹具改为 DMA 批次接收；CAN 夹具按真实 HAL 契约识别单个邮箱掩码。

报告记录源码哈希、编译选项、断言数、首个失败位置和返回状态。当前完整报告为 `selftest_results.json`；本轮开始时的 51 组基线和源码备份在 `MDK-ARM/build/refactor_20261028/`，其中三组历史失败已分别说明或随功能删除。

离线检查验证的是逻辑、协议与边界行为，不证明电机实际惯量、时延、30°稳定性能或实弹出弹频率。
