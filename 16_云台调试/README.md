## 当前源码快照

- **当前是拨盘独立测试模式**：`App/app_config.h` 中 `APP_FEEDER_STANDALONE_TEST_ENABLED=1`。摩擦轮动力输出关闭，拨盘不等待双轮稳速；改为 0 才恢复摩擦轮输出与稳速互锁。该状态是归档时的配置，不代表缺少摩擦轮实现。
- **两轴 SIM 显示默认开启**。展示真实响应前发送 `YAW SIM OFF`、`PITCH SIM OFF` 并查询确认。SIM 只影响显示；真实控制和 RESULT 一直使用真实反馈。
- 两轴共用 `App/control/gimbal_pid.c/.h`，原 `yaw_cascade.c/.h` 已替换。当前 App 分为 `system`、`drivers`、`control`、`motors`、`console`，不再平铺。
- 控制任务周期 2 ms；Yaw 正常力矩命令提交周期 10 ms，Pitch 为 2 ms。USART1 为 921600/8N1、FireWater、遥测配置间隔 5 ms；UART4 iBUS 为 115200。
- 默认 PID、重力系数、限位和遥控映射以 `App/app_config.h` 及[工程说明](Output/Gimbal_Control/README.md)为准。串口调参改变 RAM，重启恢复源码默认值；旧笔记参数不应直接当作当前值。

## 硬件与功能

| 子系统 | 当前实现 | 复盘重点 |
| --- | --- | --- |
| 遥控保护 | iBUS 解包、上电准备、人工解锁、失联及故障撤权 | 新 OFF 帧与新解锁操作为何必要 |
| Yaw | CAN1 GL60 II ID1，位置—速度串级 PID、手动与相对阶跃 | 反馈解环、独立 PID 状态、真实阶跃统计 |
| Pitch | CAN1 DM3507 ID2，双环 PID、重力前馈和末段制动 | 软件零点、负载、行程边界、重力与制动项 |
| 双摩擦轮 | CAN2 VESC ID70/71，6000 rpm 速度 PI、斜坡及稳速互锁 | ERPM/机械 rpm 换算；当前独立测试模式关闭轮输出 |
| 拨盘 | CAN2 C610 ID5，单发与 50 ms 连发请求 | 输出端角度、减速比、限流、收尾与实测频率 |
| 调参和测量 | 串口命令、VOFA 视图、真实 RESULT、SIM 显示 | 显示演示与真实反馈必须分清 |

主控为 Cherrycoast 4.8.1 / STM32F405RGT6，两路 CAN 均为 1 Mbps。上电准备使用已确认的水平机械基准；Pitch 失能会下垂，现场仍需按原操作记录支撑负载。

常用流程与命令以工程 README 为当前入口。旧[自动启动与快速阶跃](01_学习笔记/云台自动启动与快速阶跃_20261017.md)、[拨盘遥控操作](01_学习笔记/拨盘遥控考核操作_V1E_20261018.md)和[摩擦轮 6000 rpm 调试](01_学习笔记/摩擦轮双轮6000rpm与快速升速测试.md)用于解释实现演进；遇到旧接口或参数，优先查当前源码。

## 验收证据怎么读

Yaw 的 30°阶跃响应要求为 250 ms，Pitch 为 300 ms，超调和稳态误差不超过 0.2°。当前 RESULT 同时报告首次入带与最终稳定，完整测量窗口为 5 s，末 1 s 计算时间加权稳态误差。曲线截图、首次到位和完整 PASS 不是同一个指标。

同样，50 ms 连发请求对应 20 Hz 软件节拍，仍需真实完成计数或出弹记录确认实际频率。构建成功和离线模拟不证明机械动态达标；本次归档不新增或改写历史实测成绩。
