# 16 · 云台调试：双轴云台、摩擦轮与拨盘

## 任务目标

在一套 STM32F405 + FreeRTOS 固件中完成遥控保护、双轴云台、摩擦轮和拨盘控制，并全部通过富斯 FS-i6X / FS-iA10B 遥控器展示。

| 子系统 | 硬件分配 | 目标 |
| --- | --- | --- |
| Yaw | CAN1，GL60，设备 ID 1 | 30°真实阶跃，暂按进入并保持 ±0.2°误差带计时，要求不超过 250 ms；稳态误差和超调均不超过 0.2° |
| Pitch | CAN1，DM3507，设备 ID 2 | 30°真实阶跃，暂按同一方法计时，要求不超过 300 ms；稳态误差和超调均不超过 0.2° |
| 左/右摩擦轮 | CAN2，N630 + VESC 固件，ID 70 / 71 | 遥控启停，机械转速 6000 rpm，降低噪声 |
| 拨盘 | CAN2，C610 电调，ID 5 | 遥控单发与 20 Hz 连发 |

“响应时间”的正式定义、GL60 的准确型号与协议、VESC 极对数、拨盘电机和传动参数尚未取得。本目录先给出不会依赖这些未知值的总体架构，并把缺项列为上机前检查项。

## 硬件底座

- Comet V4.7.4 云台板：STM32F405RGT6、168 MHz、25 MHz 外部晶振、板载 BMI088。
- 遥控：FS-i6X + FS-iA10B，UART4 / PA1 接收 i-BUS，沿用上一任务接线。
- 电脑遥测：USART1 / PA9、PA10，115200 / 8N1。
- CAN1：PA11 / PA12；CAN2：PB12 / PB13。两条总线都需按实物协议重新配置和验收。

## 实施顺序

1. 先只接逻辑电源，实现统一保护状态机并通过遥控保护专项验收。
2. 核对四类驱动协议、两条 CAN 波特率、反馈 ID、反馈单位、方向和停机行为。
3. 分别完成 Yaw、Pitch 单轴低功率控制，校准零点、方向、软限位和反馈在线判断。
4. 调速度内环，再调角度外环；最后用真正的 ±30°目标阶跃做重复验收。
5. 实现摩擦轮 6000 rpm、速度稳定判定和同条件噪声对比。
6. 根据实际传动比和弹位数实现拨盘位置步进，依次验收单发和 20 Hz 连发。
7. 在同一套代码中开启所有模块，检查总线负载、任务周期、失联保护和遥控完整演示。

详细步骤见[云台调试实施规划](01_学习笔记/云台调试实施规划.md)，遥控门禁和功能映射见[遥控保护与功能映射](01_学习笔记/遥控保护与功能映射.md)，实机逐项记录见[实机验收记录](02_过程记录/实机验收记录.md)。

## 当前状态

本轮只完成分析、目录和验收模板，没有复制旧电机工程，也没有生成可烧录固件。上一任务的 i-BUS 解包、输入时间戳、故障后重新解锁、PID 数学模块、BMI088 驱动和双 CAN CubeMX 配置可以作为起点；电机协议层、双 CAN 传输层、统一安全输出和整机调度需要为本任务重写或扩展。
