# CAN 通信考核

## 考核目标

- 了解 CAN 通信协议与基本原理.
- 使用实验室提供的 STM32F405RGT6 云台板.
- 结合硬件资料确认 CAN1、CAN2 接口及相关电路.
- 实现板上 CAN1、CAN2 互发互收数据.

工程位于 `Output/CAN_FreeRTOS`，基于 FreeRTOS 实现 CAN1、CAN2 双向收发。两路均为 500 kbit/s，发送周期 100 ms；接收中断通过队列交给接收任务保存和校验数据。结果通过 Keil Watch 查看。

重构前已通过 Keil 截图核对双向收发：CAN1 收到 0x202/A2，CAN2 收到 0x201/A1，两路接收内容符合测试格式。当前分文件版本已通过 EIDE 构建及 Keil 完整重编译（0 错误、0 警告），重构后的硬件运行仍需重新烧录复验。

- [CAN 通信学习笔记](01_学习笔记/CAN通信学习笔记.md)：统一整理原理、配置、代码、Keil 调试与收发验收，开头突出五个重点；图片使用 GitHub 直达链接。

业务代码已拆分到 `Output/CAN_FreeRTOS/App`，可从 [App 模块说明](Output/CAN_FreeRTOS/App/README.md) 查看函数分工、阅读顺序和关键参数。
