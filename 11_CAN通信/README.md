# CAN 通信考核

## 考核目标

- 了解 CAN 通信协议与基本原理.
- 使用实验室提供的 STM32F405RGT6 云台板.
- 结合硬件资料确认 CAN1、CAN2 接口及相关电路.
- 实现板上 CAN1、CAN2 互发互收数据.

后续软件任务按之前要求基于 FreeRTOS 实现. 当前已建立目录并归档资料，尚未创建 CubeMX 工程或验证硬件连线.
