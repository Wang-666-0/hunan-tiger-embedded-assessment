# 15 · 遥控使用：富斯 i-BUS 控制 GM6020

## 考核要求

1. 解包 DR16 或富斯遥控数据，查阅厂家资料，并自行封装成库。
2. 用遥控器控制电机转动。

本次选择用户已有的富斯设备。图片中的接收机为 **FS-iA10B**，遥控器外观和型号标记对应 **FS-i6X**；以实物背面的铭牌为最终依据。接收机采用 **i-BUS SERVO** 输出。

已准备完整 `Remote_GM6020` 固件，封装独立 i-BUS C 库并接入 FreeRTOS 遥控速度控制。接收接口已迁移为 P1 上层 PA1 / UART4。ARM Compiler 5 完整构建49个C源与1个汇编源通过，0错误、0警告；6634项真实C模拟检查通过。VOFA 遥测已包含 I19~I24 接收诊断字段，并修复单字节错误完成回调提前清掉错误码的问题；VS Code / EIDE 已明确配置诊断版 HEX 的 ST-Link 下载路径。具体范围和限制见 [软件验证记录](02_过程记录/软件验证记录.md)。尚未替用户进行实机烧录或电机操作，任务是否通过以验收记录为准。

## 本次硬件分配

| 功能 | 配置 |
| --- | --- |
| 云台板 | Comet V4.7.4，STM32F405RGT6，外部晶振 25 MHz |
| USART1 | PA9 TX / PA10 RX，115200 / 8N1，连接电脑 VOFA |
| UART4 | P1 上层第4脚 / PA1 RX，115200 / 8N1，仅接收 FS-iA10B i-BUS |
| CAN1 | PA11 RX / PA12 TX，1 Mbps，连接 GM6020 |
| 电机 | 用户确认 ID 为 001，本工程按 ID 1 编码，反馈 ID 0x205 |
| 控制 | FreeRTOS，2 ms 控制周期，摇杆目标满量程 ±100 rpm |
| VOFA | FireWater，20 ms 遥测周期 |

本次使用用户圈出的 P1 六针中的**上层舵机三针**：接收机 i-BUS SERVO 的 S→P1 第4脚（PA1）、+→第5脚（5V）、−→第6脚（GND）。PA1 由软件复用为 UART4_RX，不经过反相电路。P1 下层第3脚经过 DBUS 反相电路，不能替代本次信号脚。

“上层”指原理图标注，不等于照片上边；断电辨认针脚，供电前核对极性。板图01左侧单独的 PWM/5V/GND 三针不是这里的 P1 六针。完整辨识方法见接线教程。

## 验收原则

先在电机动力关闭时核对遥控通道，再运行低转速，最后验证失联停机和恢复后的重新使能。软件构建和模拟通过不能替代实机验收；接线、烧录、摇杆方向、开关映射和电机响应由实际装置确认。

这是一份独立固件；烧录后该板执行遥控电机任务。此前 IMU 与 PID 工程仍保存在各自目录。
