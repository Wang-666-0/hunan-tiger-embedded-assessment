# 富斯协议手册与阅读顺序

核对日期：2026-10-11。设备为 FS-iA10B 接收机、照片对应的 FS-i6X 遥控器。本考核要解析的是接收机 **i-BUS SERVO 输出的有线串口数据**；无线链路 AFHDS 2A 和新一代 i-BUS2 属于其他资料范围。

## 1. 厂家正式使用说明书

优先打开本目录 `FS-i6X_官方使用说明书_中文_20250228.pdf`，已从[富斯官方 GitHub 原件](https://github.com/flysky-rc/FLYSKY-ProductInformationDownload/blob/master/Transmitter/FS-i6X/FS-i6X%20User%20manual%2020250228-CN.pdf)下载，30页。

| PDF 页码 / 纸面页码 | 阅读内容 |
| --- | --- |
| 第15页 / 14 | 5.5 Aux. channels：把 CH5/CH6 分配给开关 |
| 第22页 / 21 | 8.3 Failsafe：保存失联时的通道输出；Off 表示保持最后值 |
| 第24页 / 23 | 8.8 Output mode、8.9 i-BUS Setup：输出设置与舵机扩展用途 |

另保存了 `FS-i6X_官方使用说明书_中文_20171108.pdf` 和 `FS-i6X_官方使用说明书_英文_20160817.pdf`，供旧固件对照。使用说明书主要说明接口和菜单，没有列出我们所需的完整32字节帧规范。

[FS-iA10B 官方参数页](https://www.flysky-cn.com/ia10b-canshu)确认供电范围3.5–9V、10通道及i.bus接口。

## 2. 字节级协议公开资料

本次检索官网和官网指向的官方产品资料仓库，未找到可公开下载的旧 i-BUS 原始字节级协议 PDF。[富斯官方 FAQ](https://www.flyskytech.com/problem/)说明，i-BUS 协议等产品资料可联系厂家申请。若考核要求必须引用厂家原始规范，应向厂家注明“FS-i6X + FS-iA10B，i-BUS SERVO/OUT 舵机通道串口协议，供 STM32 学习解包使用”；不要把传感器 SENS 协议或 i-BUS2 当成同一份资料。

以下是作者公开的原始实现资料，**不标称厂家协议手册**：

- [STM32 HAL i-BUS 项目](https://github.com/mokhwasomssi/stm32_hal_ibus)：最适合结合 STM32 阅读接收和通道解包。
- [Betaflight 接收驱动](https://github.com/betaflight/betaflight/blob/master/src/main/rx/ibus.c)及[校验实现](https://github.com/betaflight/betaflight/blob/master/src/main/telemetry/ibus_shared.c)：交叉核对波特率、帧长、小端通道和校验和。
- [IBusBM 的 Failsafe 说明](https://github.com/bmellink/IBusBM#failsafe)：说明无线失联后仍可能有合法 i-BUS 帧，不能仅靠收帧次数判断无线在线。

## 3. 本次考核的学习入口

先读 `01_学习笔记/iBUS解包与遥控控制原理.md`，再读 `Output/Remote_GM6020/App/ibus.h` 与 `ibus.c`。本库是自行封装的独立 C 库，使用开源资料交叉核对协议事实，不直接复制第三方驱动。

需掌握的格式为115200、8N1、非反相；32字节，头部20 40，14个小端通道槽位，末尾小端校验和为0xFFFF减前30字节之和。该格式适用于本次常规舵机帧，不覆盖其他新版本的扩展通道格式。

对应代码已加入噪声和丢字节后的重新同步、残帧超时、通道范围检查。合法帧的新鲜度与接收机 Failsafe 通道值共同参与电机运行许可；实际遥控器关机停机必须实测。
