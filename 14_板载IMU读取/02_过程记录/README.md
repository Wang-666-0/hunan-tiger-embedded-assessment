## 待实机验收

- [ ] 使用本任务 BMI088_Read 工程重新编译，确认无编译/链接错误。
- [ ] 通过 ST-Link 下载本任务的新产物，确认活动工程和下载目标正确。
- [ ] USB-TTL 使用 3.3 V TTL，USART1 TX 接 RX、共地，未接入未经核对的 VCC。
- [ ] 每次复位后保持板子连续静止，等启动零偏校准完成。
- [ ] VOFA 串口 115200、8N1，协议 JustFloat，出现 I0/I1/I2。
- [ ] 三个数值和曲线正确响应 Roll/Pitch/Yaw，单位为度。
- [ ] Cube 采用 Euler、Degree，X/Y/Z 分别绑定 I0/I1/I2。
- [ ] 单轴 X/Y/Z、组合转动和模型方向经过真实核对。
- [ ] 记录静止 Yaw 漂移，说明其是相对航向，不是绝对北向。
- [ ] 验证重新复位会重新校准，校准时移动会延后开始发帧。
