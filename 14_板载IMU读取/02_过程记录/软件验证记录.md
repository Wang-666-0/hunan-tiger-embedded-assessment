# 软件验证记录

日期：2026-10-07。本记录仅表示本机软件构建和模拟结果，不表示已烧录或已在 VOFA 看见实物姿态。

## 完整构建

在 `Output/BMI088_Read` 目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\build.ps1
```

脚本从 Keil 工程的持久源文件列表生成 EIDE 临时构建参数，使用现有 ARM Compiler 5.06 和 EIDE unify_builder。进程内允许已有 .NET 7/8 运行构建器；不安装新的编译器、不改变永久环境、不烧录。

实际构建输出摘要：

```text
C Files = 42; Asm Files = 1; Total = 43
Program Size: Code=19416 RO-data=524 RW-data=160 ZI-data=15392
Total ROM Size = 20100 bytes
Total RW Size  = 15552 bytes
build successfully
```

完整重编译输出与 `compiler.log` 未出现错误或警告。App 六个 `.c` 都在 EIDE 和 Keil 分组中；正式源文件组不包含测试文件。

合并后 HEX 路径：`Output/BMI088_Read/MDK-ARM/build/BMI088_Read/BMI088_Read.hex`

2026-10-07 合并前固件 SHA-256：`E440D5DEDCAD3C61C6CF8BE5A8B3ABAA18970BD33EDB47B7E502A425EDB924A5`。合并后的构建与校验值见同目录的《合并记录》。

链接器调用图给出的 `ImuApp_Run` 已知静态调用链最大深度为 488 字节，但报告包含未知调用/汇编路径提示，不能把它当作运行时栈水位。当前任务栈为 2048 字节；真实任务与中断环境的栈余量仍需板上验证。

## 模拟检查

在 `Output/BMI088_Read` 目录运行：

```powershell
python -X utf8 .\Tests\run_selftests.py
```

使用已安装的 EIDE ARM GCC，以 C99 和 `-Wall -Wextra -Werror` 编译真实 App 模块。Unicorn 在 ARM 指令级模拟执行，HAL/板级 SPI/串口由测试替身提供；未打开真实 COM、ST-Link 或板卡。

| mahony | 2150 | 0 | 是 |
| bmi088_driver | 104 | 0 | 是 |

测试覆盖：重力初始化的水平/倾斜/倒放姿态、四元数归一化、真实 dt 和匀速 Yaw 积分、非法数据不破坏状态；加速度 SPI 模式切换/dummy byte、复位等待、配置字段读回、SI 单位、温度和坏 ID；连续 500 个静止样本、运动和窗口方差拒绝、JustFloat 三通道字节顺序、UART 超时后的半帧重同步。

运行器还打印每个被测源文件的 SHA-256；ELF 保存在系统新建临时目录，不替换正式 HEX。
