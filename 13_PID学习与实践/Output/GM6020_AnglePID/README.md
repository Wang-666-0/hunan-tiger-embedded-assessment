# GM6020 多圈角度—转速串级双环

独立于原 GM6020_SpeedPID 工程，沿用其已验证的 STM32F405、FreeRTOS、CAN1、USART1 和自己封装的 PID。外环控制角度，输出目标转速；内环控制转速，输出电机协议原始给定。上电不启动。

## 入口与构建

- VS Code/EIDE：`MDK-ARM/GM6020_AnglePID.code-workspace`，选 GM6020_AnglePID 再 Build / Flash。
- Keil：`MDK-ARM/GM6020_AnglePID.uvprojx`。
- CubeMX：`GM6020_AnglePID.ioc`；目前不用重新生成。

## 配置

| 项目 | 默认值 |
| --- | --- |
| CAN1 | PA11 RX / PA12 TX，1 Mbps，GM6020 拨码 ID 1，电压协议 |
| USART1 | PA9 TX / PA10 RX，115200，8N1，无流控，USB 串口和板子共地 |
| 双环控制 | 2 ms，500 Hz；按实际时间间隔积分 |
| FireWater 遥测 | 20 ms，50 Hz，默认 T1 21 通道 |
| 速度内环 | P=50，I=200，D=0.003，沿用最近实机截图 |
| 角度外环 | AP=4，AI=0，AD=0.05，未实机整定的起点 |
| 角度目标 | 相对于 Z 的绝对多圈位置，±7200°；A720 为两圈 |
| 角度模式限速 | V=100 rpm，可在线设为 1～100 |
| 速度模式目标 | S=-100～100 rpm |
| 电压原始给定 | ±15000；保持原速度工程限幅 |

命令均为大写 ASCII、无空格、以真实 LF/CRLF 结束。A30/A0 控制相对零点的角度；AP/AI/AD 调外环；P/I/D 调内环；V100 调外环限速；S20 切到单速度环；STOP 停机；Z 在 STOP 且 |实际转速|≤2 rpm、新鲜反馈时置零；T1/T0 切换遥测。

第一帧临时建立零点。正式测试应先 STOP、等停止、Z。多圈位置依赖连续编码器反馈，≥20 ms 间断、异常跳变等会锁定位置无效，角度控制立即退出，恢复后需重新 Z，不会猜测旧圈数。STOP 为零给定，不是机械抱闸；关闭 VOFA/拔掉电脑串口不自动停止。

## 软件验收与实物验收

软件测试覆盖双向跨零、±720°累计、故障锁定和恢复、双环限速/模式、STOP 和在线更新并发、严格串口命令、21 通道遥测及旧速度/PID/CAN 回归。结果见任务过程记录的 `角度双环软件自测结果.json`。

I18 表示在 ±0.5°内连续保持 50 ms；I19 在 I18=1 时表示该连续区间第一次入带的时间（从 A 命令起，毫秒）；I20 是沿阶跃方向越过目标的最大角度。指标使用实际反馈，不锁死或改写测量值。

编译和软件模拟通过不能证明实物达到“30°阶跃≤300 ms、无超调、静态误差≤0.5°”。需固定电机、完成两环整定，并保留正反 30°和 720°的 VOFA 曲线。详见教程中的验收表。
