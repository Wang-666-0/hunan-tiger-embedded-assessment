# GM6020 多圈角度双环软件模拟自测

selftest.c 与 mocks/ 替代 HAL、FreeRTOS 队列和串口，编译实际 App 的 C 实现，然后在 ARM 指令模拟器中执行。
它不加入正式固件，不连接 ST-Link/串口，不会驱动真实电机。

运行工具为已有 EIDE arm-none-eabi-gcc 与 Python Unicorn。
run_selftests.py 支持 --gcc-dir 和 --unicorn-dir。此次 Unicorn 仅装在系统临时目录 gm6020-unicorn-tests，不修改永久 Python 环境。

例如：
```powershell
python run_selftests.py --unicorn-dir "$env:TEMP/gm6020-unicorn-tests"
```

默认测试 ID1/电压模式、ID5/电流模式，涉及全部七个 ID 的槽位。输出角度双环软件自测结果.json 到本任务过程记录目录，不覆盖原转速工程的报告。记录各配置的检查数、失败数、首个失败阶段和行号、最多 32 条失败检查行号以及实际被测试文件的源码 SHA-256。
测试 ELF 放入新建系统临时目录，不替换工程 HEX/AXF，也不会执行烧录。

检查范围：

- PID：比例输出、积分按真实秒数累计、积分限幅、输出饱和时拒绝加重饱和的积分，以及反向误差消除旧积分。
- 微分：作用于实际值、目标阶跃无直接 D 冲击、一阶低通；NaN、无穷、零/负 dt 和浮点溢出返回零并清空历史。
- CAN：大端有符号转速、电流解析，反馈 ID/DLC/来源检查，排队时间与毫秒回绕，七个电机 ID 的报文组号和槽位。
- 在线调参：PID_SetGains 检查非法增益并保留原状态；修改或重复滑块参数均保留已有积分贡献、实际值及微分滤波历史。Ki 设置为 0 时明确清除积分贡献。PID_ClearIntegral 只清 I，保留配置、实际值及微分滤波历史。
- 控制：正转、反转、零速闭环、STOP、实际 dt、输出限幅、在线改参不禁用控制。直接正负方向切换、非零目标首次切至 S0 时清 I；同向增减速、重复相同目标和重复 S0 均保留积分。反转保留 D 历史，同一毫秒不消费清 I 标记、不重复积分、不发送旧方向输出；STOP 仍立即提交零给定。持续提供新鲜反馈，以 2 ms 周期连续运行超过三秒，无需 K；K 作为兼容命令不能启动停止的电机。
- 默认参数：每次创建测试 fixture 时先检查真实默认增益宏，再显式选择 P5/I0/D0 供旧基础用例使用；独立用例以默认 P50/I200/D0.003 验证首轮比例、积分、微分和限幅行为。外环默认 AP4/AI0/AD0.05、限速 V100 均与实际宏核对。
- 积分与输出权限回归：目标 20 rpm、固定反馈 12 rpm、P50/I20/D0 时，电压模式积分可超过旧上限 1000。总电压给定上限现为 15000，按该边界安排足够积分步数，验证给定与积分能超过旧限制 2000，且不突破新边界；电流模式仍保留总给定 1000，并在 P 项之外限制新增积分。随后将反馈设为目标，验证零误差能保持原积分偏置；再检查总输出抗饱和及反向误差退出饱和。固定反馈仅验证控制逻辑，不代表真实电机已消除误差。
- 并发请求：在数学计算后、结果发布前注入同向目标、改 P、重复目标、反转或 STOP。过期候选不可提交；同向目标和改参不能清掉旧积分，重复目标不会丢弃本轮输出；反转清 I、启动重建等已消费标记必须重排，STOP 不能被旧候选重新启用。计算被丢弃后仍按自上次成功提交以来的真实 dt 积分。
- 保护：反馈超时、80°C 阈值、控制间隔过大、挂起邮箱取消、发送失败及恢复后不自动重启。
- 多圈跟踪：8191/0 双向跨界，连续小增量准确达到 +720°、再反向到 -720°；首帧建立相对零点。20 ms 断帧、不可信编码跳变、超过物理速度、累计计数边界均锁存无效；恢复帧不猜测圈数，新鲜 Z 才重建。另测时间回绕、空指针、过期置零和编码范围。
- 双环：角度外环产生 V 限幅的目标 rpm、速度内环产生给定；A720 确实走两圈，360°中途仍有正误差，不折回最短路径。A/S 切换重建历史，角度无效或零位代次在运行期间改变触发停机，不自动恢复。
- 零位：运行拒绝 Z，STOP 后 |rpm|>2 仍拒绝，新鲜 |rpm|<=2 允许；过期反馈不能通过 Z 延长在线时间。
- 角度指标：反馈保持实际值，0.5°误差带保持 50 ms 才确认，报告首次进入误差带的时间；离开误差带撤销稳定状态；记录沿当前阶跃方向超过目标的最大角度。
- 双环积分：外环按真实 dt 累计，改 AI 保留旧贡献，新 A 清外环 I，重复 A 保留历史和稳定耗时；减速阶段入口只清一次旧驱动内环 I，同阶段制动 I 正常连续累积。
- 双环并发：数学计算后、发布前插入角度目标、外环 P、V 限速、A/S 模式或 STOP，旧候选不能发送旧方向给定、覆盖 STOP 或继续使用旧模式。另在计算期间注入 CAN 编码器失效、外部零位代次改变或 80°C 反馈，必须当轮停止并提交零；命令入场快照也拒绝刚发生的失效或过温。
- 串口：A/AP/AI/AD/P/I/D/S/V/Z/K/STOP/T0/T1，普通十进制小数、上下界、拒绝指数/NaN/无穷/空格/残缺，分段输入和 CR/LF，一次命令不会被 CRLF 执行两次。
- FireWater：angle: 前缀，默认 T1 固定 21 通道、T0 两个角度通道，以 CRLF 结束；逐通道对照控制快照。六个增益保留四位小数，D0.001 能显示为 0.0010，角度/rpm/V/超调保留两位小数，各增益上界不会导致截断；输入超时、队列满与 UART 错误后的停止及重新对齐。

模拟只验证逻辑和协议。反馈是测试脚本提供的数值，不能证明真实电机已经达到目标转速或角度，也不能证明 30°阶跃 300 ms 内、无超调、静态误差 0.5°内。三项动态指标与实际 720°运动、板上中断、实际 RTOS 栈、收发器和机械响应仍需实物及 VOFA 曲线验收。软件稳定/超调指标只作辅助证据。
