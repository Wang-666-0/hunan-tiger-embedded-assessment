# PID 学习笔记索引

建议按“先速度内环，再角度外环，最后重复验证”的顺序阅读。

| 顺序 | 笔记 | 重点 |
| --- | --- | --- |
| 1 | [转速单环 PID 与在线调参](转速单环PID与在线调参.md) | P/I/D、限幅、串口在线修改 |
| 2 | [20 rpm 实际调参步骤](20rpm实际调参步骤.md) | 从小目标开始做可控实验 |
| 3 | [100 rpm 与反转响应改进](100rpm与反转响应改进.md) | 输出余量、旧积分与反向制动 |
| 4 | [角度双环与 VOFA 调参](角度双环与VOFA调参.md) | 角度—速度串级结构、命令、通道和验收方法 |
| 5 | [角度双环 PID 调参过程与实测复盘](角度双环PID调参过程与实测复盘.md) | 本轮真实参数变化、超调与到位时间、重复性 |

注意区分两个工程：GM6020_SpeedPID 是速度单环，遥测为 10 通道、10 ms；GM6020_AnglePID 是角度双环，完整遥测为 21 通道、20 ms。不能直接套用另一工程的通道绑定。

实测复盘保留成功和失败结果，不把一次好曲线写成永久达标，也不把建议试验值写成已经验证的参数。
