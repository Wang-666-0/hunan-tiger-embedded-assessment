# GM6020 角度双环与 VOFA 调参

这份工程完成的是：**目标角度 → 角度外环 → 目标转速 → 转速内环 → CAN 电压给定**。P/I/D 专门调速度内环，AP/AI/AD 专门调角度外环，两套参数不能混着用。当前源码默认内环为 50/200/0.003、外环为 4/0/0.05；这不等于最新实机参数。

本文保留从接线、命令到调参的操作方法。本轮参数变化、实测结果和超调复盘，见[角度双环 PID 调参过程与实测复盘](角度双环PID调参过程与实测复盘.md)。

考核目标来自你提供的截图：可多圈角度控制、能够转动 720°、30°阶跃响应在 300 ms 内、无超调、静态误差在 0.5°内。代码提供这些功能与观测量，但物理指标必须实机调参后确认，不能仅凭编译通过判定达标。

## 1. 打开和烧录正确工程

打开：
`D:\Project\27电软正式批考核\13_PID学习与实践\Output\GM6020_AnglePID\MDK-ARM\GM6020_AnglePID.code-workspace`

在 EIDE 选择 **GM6020_AnglePID**，再 Build、Flash。不要误烧 GM6020_SpeedPID。当前已生成：
`Output/GM6020_AnglePID/MDK-ARM/build/GM6020_AnglePID/GM6020_AnglePID.hex`。

沿用原来的接线：CAN1 PA11/PA12，GM6020 拨码 ID1，电机外部供电；USB 串口 RX 接 PA9 TX、TX 接 PA10 RX，公共地，115200 8N1。电机内部协议设置保持与上一个速度实验一致。

实验前固定电机、清空转动区域；多圈实验不要让线缆缠绕，连接机构必须允许指定角度。STOP 只是发送零给定，不等于机械抱闸；停机后轴仍可能受负载或惯性运动。关闭 VOFA/拔掉电脑串口本身也不停止已锁存的控制。

## 2. VOFA 先接通，再配置面板

1. 数据引擎选 FireWater，选之前可用的串口，115200、8 位、无校验、1 停止位、无流控。
2. 底部发送框使用文本/Str，末尾追加选 `\n`；框里只输入命令正文，例如 `STOP`。不要输入两个普通字符反斜杠+n 来代替换行。
3. 逐条发送 `STOP`、`T1`，清空原速度实验数据，等出现 I0～I20 共 21 个通道。
4. **Δt 改成 20 ms**。新固件 50 Hz 遥测，双环仍以 500 Hz 控制；曲线的名义时间轴不是独立硬件时间戳。
5. 新建两张图：角度图只放 **I0 目标角度 / I1 实际角度**；转速图只放 **I2 目标转速 / I3 实际转速**。I4 是原始电压给定，单独看数值或单独画图，不与角度共用同一纵轴。
6. 确认 **I12=1**（在线），I16=1（多圈角度有效）。发送命令后检查 **I14=1**，再检查目标/参数是否变化。

旧图的 I0/I1 绑定虽然仍是目标/实际，现在单位变成度；参数绑定全变了。比如旧面板的 I3 不再是 Kp，而是实际转速，必须重新绑定。

完整通道及滑块配置见[角度 VOFA 面板](../04_VOFA角度双环/README.md)。命令绑定使用 Str 占位符 %f，再由控件提供数值，这与[VOFA 官方命令文档](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/)一致。

## 3. 先理解角度命令和零点

| 命令 | 实际含义 |
| --- | --- |
| `STOP` | 退出闭环，清除旧请求；不会自行机械抱闸 |
| `Z` | 把当前位置设为 0°；必须 STOP、新鲜反馈且转速绝对值≤2 rpm |
| `A10` / `A30` | 去零点之后的 +10° / +30°，同时启用角度双环 |
| `A0` | 回到当前零点，继续闭环保持位置；不是 STOP |
| `A-30` | 去当前零点的 -30° |
| `A720` | 去当前零点的 +720°，即正向两圈 |
| `S20` | 切到独立转速模式，目标 +20 rpm，暂时绕开角度外环 |
| `AP4` / `AI0` / `AD0.05` | 设置角度外环的 P / I / D |
| `P50` / `I200` / `D0.003` | 设置转速内环的 P / I / D |
| `V50` / `V100` | 限制角度环输出转速为 ±50 / ±100 rpm；不是电压 |

A 后面是相对于 Z 的**绝对多圈目标**，不是每次要追加的角度。连续发两次 A720，不会转四圈。从 A720 改 A0，会回退两圈；从 +720 改到 -720，是四圈位移，不要误当成一次两圈测试。

每次上电第一帧反馈建立临时零点。正式实验仍建议 STOP、等轴停稳，再 Z。位置靠连续反馈累计，没有上电绝对圈数记忆；反馈中断≥20 ms 或不可信跳变后，多圈角度锁定无效。重新供电/接线后应 STOP、停稳、Z、重新给 A，不能直接恢复旧零点。

## 4. 第一次运行：先小角度检查方向

在底部发送框**逐条**发送，每条都追加真正的换行：

```text
STOP
T1
P50
I200
D0.003
AP2
AI0
AD0.05
V50
```

确认 I5/I6/I7 是 50/200/0.003，I8/I9/I10 是 2/0/0.05，I17=50。等待 I3 实际转速接近 0，再发 Z；I14 必须为 1，I0/I1 应归零。

随后发 **A10**。应看到 I0 到 10，I1 向 10 接近；I11=1，I15=1。若角度往反方向越走越远或剧烈振荡，立即 STOP，检查方向和接线，不继续增大增益。

稳定后发 A0，观察回零。确认小角度正常，才开始 30°阶跃。AP2、V50 这一组用于初次方向检查，不作为 300 ms 考核参数。

## 5. 为什么要先调速度内环

角度外环负责“应该转多快”，内环负责“让它真的达到这个速度”。若内环几秒才能跟上，外环再激进也可能越过目标后才刹住。

你上一个截图证明 100 rpm 稳态能跟随，但不能证明速度内环动态足够快。首先用新工程的 S 模式测内环：

1. 暂时只看 I2/I3 转速图。保留 P50、I200、D0.003，发 S0，稳定后 S20；再做 S20→S0、S20→S-20；确认方向与主动减速正常。
2. 低速稳定后，按机械条件逐级试 S50、S100，而不是一开始长时间连续高速旋转。
3. 响应慢且 I4 没到 ±15000：先适度增大 P，例如从 50 到 60，再到 70；每次只改一个参数、重复同一个阶跃。这些是试探值，不是保证最佳参数。
4. I 太大时容易超调或慢摆，先减 I；稳态存在持续速度偏差且输出还有余量时，再逐步增 I。D 对速度量化敏感，先保留小值；若输出高频抖动可用 D0 与 D0.003 比较。
5. 如果 I4 长时间贴 ±15000，不要只靠增 I/P：先检查供电、负载和协议。**V 只管角度模式限速，不能提高电压输出限幅，也不影响 S100 的范围。**
6. 调好内环后发 STOP，等静止，再 Z。之后固定内环参数，开始调外环。

不要同时改内外两套增益，否则很难知道响应变化来自哪一环。

## 6. 角度外环：先 PD，再考虑很小的 I

在已确认方向和内环表现之后，将外环改为：

```text
AP4
AI0
AD0.05
V100
A0
```

A0 稳定后，再发 A30，观察角度图和 I18/I19/I20。AP=4 的单位是 rpm/度：30°误差先要求 120 rpm，再被 V100 限到 100。AD 对实际角度变化加阻尼，不会因为目标突然跳 30°直接产生微分冲击。

| 实际表现 | 优先做什么 |
| --- | --- |
| 接近目标很慢，I2 请求转速也很小 | 小幅增 AP，例如 4→4.5→5；每次重复同一 30°阶跃 |
| I2 已请求明显转速，I3 却长时间跟不上 | 回去调速度内环或检查 I4 限幅；不是继续盲目加 AP |
| 到达目标后越过或摆动 | 先减 AP，或小步增加 AD，如 0.05→0.06→0.07；AI 先保持 0 |
| 不超调，但末段很慢 | 可能 AD 过强；小步减 AD，重新比较，避免只靠增加 AP |
| 抖动/输出频繁快速反向 | 降低激进参数，检查反馈、固定方式与机械间隙；必要时 STOP |
| 稳定后仍有持续 >0.5°误差 | 内环与 PD 调稳后，再尝试 AI0.05、AI0.1 等小积分；若增加超调就减回 |

外环默认不加积分，因为内环已有积分提供维持转速的给定；无负载位置控制常可先用外环 PD。只有确认持续位置偏差时再加外环 I，不能一上来把内环 I200 照搬到 AI200（这还会越界）。

每次试验应从同一位置和相同负载做同一 30°阶跃。从 10→30 只有 20°，从 30→-30 是 60°，都不等同于 30°测试。

为比较参数，先保持同一个 Z 零点，采用 A0 稳定约 2 秒→STOP→确认轴静止且角度没有漂移约 1 秒→A30 的统一流程。角度模式中更换 A 只清外环积分，内环积分和滤波历史仍保留；STOP 后重新启动会重建两环，因此这种流程能减少起始历史差异。若负载在 STOP 后会滑动，不能直接套用这个流程，应保持闭环并统一起始条件。

清历史的流程用于参数对比，不能替代实际工况验收。最后仍要做不经过 STOP 的 A0→A30→A0 连续往返，检验正常运行中的减速和积分处理。不要每轮重新 Z，否则参考位置变化可能掩盖偏差。

代码在明显制动入口只清一次旧方向的内环积分，帮助减速；后续继续正常积分，不是一直把 I 清零。这个处理不代替实机整定。

## 7. 怎么判断考核达标

| 考核项 | 实物验证方式 |
| --- | --- |
| 多圈角度 | 零点后 A720：实际角度应连续经过 360 到 720，不跳回 0；目视确认两整圈 |
| 30°阶跃≤300 ms | 固定起点做真正的 30°变化；I18=1 时读取 I19，需≤300；同时检查曲线和末段保持，并验证连续往返 |
| 无超调 | 0→30 时实际角度不越过目标；检查 I20 和放大的角度图；反向同样检查 |
| 静态误差≤0.5° | 到达后继续观察数秒，目标与实际角度之差的绝对值≤0.5°，且没有持续摆动；不能只截一个相等瞬间 |

I18=1 表示连续在 ±0.5°内保持 50 ms，I19 回报这个连续区间**首次进入**误差带的时刻减 A 指令时刻，并非额外加上 50 ms。I18=0 时 I19=0 不能理解为“0 ms 到位”。随后出带会清除 I18/I19，指标不能代替长时间稳定检查。

I20 是本次角度阶跃方向上越过目标的最大角度。位置编码器分辨率约 360/8192=0.04395°，遥测保留 0.01°；很小的噪声与量化需要在报告中注明，但不能擅自把明显越过目标叫“无超调”。该最大值只覆盖控制采样，无法排除采样间的峰值。

推荐保留同一套参数的：

- A0→A30、A30→A0（各 30°）。
- A0→A-30、A-30→A0（各 30°）。
- 安全允许时 A0→A720、A720→A0；多圈项目没有要求 720°也在 300 ms 内。
- 每项记录六个增益、V、负载、曲线、I19 和 I20。观察数秒的静态误差。

注意 50 Hz 曲线每点间隔名义 20 ms，不能拿它宣称毫秒级测量精度。I19/I20 在 2 ms 控制步骤里计算，更适合辅助判断；若考核对“响应时间”有不同定义，按老师定义从原始数据复核。

## 8. 故障看哪些通道

- I14=2：命令格式错，检查大写、空格、%f 是否被替换，以及真正换行。
- I14=4：越界。A±7200°，V1～100，AP0～20，AI0～100，AD0～2；P0～200，I0～1000，D0～10。
- I14=5：未就绪。A 需在线且角度有效；Z 需 STOP、反馈在线、|速度|≤2。
- I13=9 / I16=0：多圈位置已失效，排查电源/CAN，再 STOP、静止、Z，不能只发 A 重启。
- I13=5/6/7/8：分别为过温、CAN 发送异常、串口输入故障、控制周期异常。修复原因后重新明确启动，不会自动续转。
- 如果手动 AP3 后 I8 不变，先查串口发送/换行；滑块不生效而手动有效，再查滑块绑定，不能靠调 PID 修通信故障。

## 9. 保存参数与结束实验

面板预设值、单片机 RAM 中的实际增益、App/app_config.h 中的上电默认值是三件不同的事。在线参数只在 RAM 中，复位会恢复源码初值；应以 I5～I10、I17 的回传确认参数实际生效。满意后先记录六个增益、限速、负载及重复实验结果，再决定是否更新源码默认值并编译烧录一次保存，不需要每次调参重编译。

结束先 STOP、确认 I11=0；再根据机械和电气条件断电。不要把 A0 当停机命令。

本轮已经出现 283 ms、最大超调 0°，以及最新 166 ms、最大超调 0°的实测截图；用户也反馈 720°控制没有明显问题。但期间另一次试验出现 1.11°超调和 3159 ms 到位，因此不能拿某一次好结果证明所有试验都通过。最新候选参数、完整的已知结果及重复验证方法见[实测调参复盘](角度双环PID调参过程与实测复盘.md)。
