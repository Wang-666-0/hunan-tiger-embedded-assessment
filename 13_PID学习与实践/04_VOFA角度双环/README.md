# VOFA+ 角度双环面板

用于 GM6020_AnglePID，不覆盖原速度实验布局。完整操作顺序见[角度调参教程](../01_学习笔记/角度双环与VOFA调参.md)。

## 1. 连接与图表

FireWater，115200、8N1、无流控；底部 Str 发送框选择末尾追加 LF。先发 STOP、T1，清空旧数据，确认 21 个通道，Δt=20 ms。

角度图 I0/I1；速度图 I2/I3；原始电压 I4 用单独图或数值。控制周期 2 ms，图是 20 ms 遥测抽样，不要沿用旧项目的 Δt10。

## 2. 添加 Str 命令并绑定控件

左侧命令面板新增 Str 命令，随后右键滑块→绑定命令。%f 由滑块当前值替换为普通十进制数；每条命令都必须以真正 LF 结束。[官方说明](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/)确认 Str 使用 printf 占位符，滑块数值来自控件本身。

| 控件 | Str 模板 | 建议面板范围 | 步进 | 显示小数位 | 数据绑定 |
| --- | --- | --- | --- | --- | --- |
| 目标角度 | `A%f[\n]` | -720～720°；首次只试10/30 | 1 | 2 | I0 |
| 内环 P | `P%f[\n]` | 0～200 | 1 | 2 | I5 |
| 内环 I | `I%f[\n]` | 0～1000 | 5 | 2 | I6 |
| 内环 D | `D%f[\n]` | 0～0.05 | 0.001 | 4 | I7 |
| 外环 AP | `AP%f[\n]` | 0～20 | 0.1 | 2 | I8 |
| 外环 AI | `AI%f[\n]` | 0～5；固件允许100 | 0.05 | 3 | I9 |
| 外环 AD | `AD%f[\n]` | 0～0.5；固件允许2 | 0.005 | 4 | I10 |
| 角度模式限速 | `V%f[\n]` | 1～100 rpm | 1 | 2 | I17 |

首次方向检查 AP2、AI0、AD0.05、V50；确认后再 AP4、V100，内环沿用50/200/0.003。不要把初始化到面板的显示值误认为固件已经接受，应查看数据绑定和 I14。

[\n] 是 VOFA 的换行标记，不是让 MCU 接收方括号；[官方更新日志](https://www.vofa.plus/docs/function/release_note/)说明了输入区换行标记与追加换行。最可靠方法是复制本目录对应 txt 的完整内容（含末尾真实 LF）粘贴，或在考核目录终端运行：

```powershell
& './13_PID学习与实践/04_VOFA角度双环/复制滑块命令.ps1' AP
```

把 AP 换成 A、P、I、D、AI、AD、V、S、STOP、Z、T1 均可。脚本只复制文本到剪贴板，不连接串口。若直接粘贴时换行被界面去掉，需要用 VOFA 换行标记补回，并核对 TX 最后一个字节为0A。

滑块关闭“移动时发送”，开启“鼠标弹起/数值框操作时发送”，关闭循环发送。[官方滑块文档](https://www.vofa.plus/docs/learning/widgets/slider/)说明范围和步进可设置，Str 参数就是滑块数值。D、AD 必须显示足够小数位，否则小数会被控件舍入，发送值可能变零。

新增两个按钮，分别绑定固定 Str：`STOP[\n]`、`Z[\n]`，只在一次选定的点击/释放事件发送。Z 不是启动命令，运行中会拒绝置零。精确考核阶跃建议底部输入 A30 或固定按钮，避免拖动途中变成许多小阶跃。

不要让旧 S 滑块或任何周期命令仍自动发送：S 会切到速度模式，破坏角度测试。无需 K 续期。

## 3. T1 通道

| 通道 | 含义 |
| --- | --- |
| I0 / I1 | 目标角度 / 实际多圈角度，度 |
| I2 / I3 | 内环目标转速 / 实际转速，rpm |
| I4 | 电机原始电压给定，当前 ±15000 |
| I5 / I6 / I7 | 内环 P / I / D |
| I8 / I9 / I10 | 外环 AP / AI / AD |
| I11 | 使能：1运行、0停止 |
| I12 | 在线：1新鲜反馈、0过期 |
| I13 | 停止原因 |
| I14 | 最近命令结果：1接受、2格式错、4越界、5未就绪、6输入过期、7接收故障 |
| I15 | 控制模式：0单速度、1角度双环 |
| I16 | 多圈角度有效：失效后需STOP、静止、Z |
| I17 | 角度模式速度上限，rpm |
| I18 | ±0.5°内持续保持50ms后为1，出带重新为0 |
| I19 | I18=1时，首次入该连续误差带的时间，毫秒 |
| I20 | 本次A阶跃方向的最大越过目标角度，度 |

停止原因：0运行、1上电、2STOP、3速度反馈过期、5过温、6CAN发送异常、7UART接收异常、8控制间隔异常、9多圈位置/零点代次失效；4为保留。命令结果与停止原因不是同一回事。

T0 只输出目标/实际角度两个通道；做完整在线调参保持 T1。切换遥测模式后清空数据。参数不回传或控件“改不动”时先手动发送 AP3 并查看 I8=3、I14=1，再排查控件。

## 4. 命令与布局文件

本目录 txt 是供粘贴的模板，不是导入布局 JSON。配置好后用 VOFA 自己的保存/导出功能保存一个独立角度面板，保留旧速度面板。

A 是相对于 Z 的绝对目标，支持固件 ±7200°；面板只先设置 ±720°。从零点 A720 转两圈，重复 A720 不追加圈数。首次测试 STOP、停稳、Z、A10。详细双环整定和 30°验收见教程。
