## 硬件与初值

| 项目 | 配置 |
| --- | --- |
| MCU | STM32F405RGT6，168 MHz |
| 电机 | GM6020，拨码 ID 1，外部供电 |
| CAN1 | PA11 RX / PA12 TX，1 Mbps，标准数据帧 |
| USART1 | PA9 TX / PA10 RX，115200，8N1 |
| 控制周期 | 2 ms，名义 500 Hz |
| VOFA 输出周期 | 10 ms，名义 100 Hz |
| PID 初值 | Kp=50，Ki=200，Kd=0.002，沿用当前实机调参值 |
| 目标范围 | -100～100 rpm；从 20～30 rpm 开始实验 |
| 输出限幅 | 电压协议原始给定 ±15000；新版协议上限为 ±25000 |
| 积分项限幅 | 跟随最终输出限幅；默认电压模式 ±15000 |

默认使用电压协议，电机内部的电流环设置应与上一项保持一致。初值只是开始调参的起点，最终响应需要实机测量。上电不会自动启用闭环。

当前改进针对 15→-10 rpm 反转慢和 20 rpm 以上给定不足：提高最终给定余量，反转及非零目标切到 S0 时只清积分，同向变速保留历史。控制仍以 2 ms 周期计算，T1 十通道顺序保持兼容。100 rpm 是否达标需要新曲线验证，按上面的当前验证步骤逐级测试。

## 串口命令

使用 ASCII 文本发送，勾选发送换行。真实 `\n` 或 `\r\n` 均可；输入框里不要把反斜杠和字母 n 当换行发送。大小写有区别，不带空格。

| 命令 | 功能 |
| --- | --- |
| `S30` / `S-30` | 设置目标转速为 +30 / -30 rpm，并启用闭环 |
| `S0` | 保持零转速闭环，可能输出反向控制量帮助减速 |
| `STOP` | 退出闭环，清空历史，控制任务发送零给定 |
| `P5` / `P10.5` | 在线修改 Kp，范围 0～200 |
| `I0` / `I0.5` | 在线修改 Ki，范围 0～1000 |
| `D0` / `D0.001` | 在线修改 Kd，范围 0～10 |
| `K` | 兼容旧命令：只检查是否运行，不需要循环发送，也不能启动 |
| `T0` | 简洁格式，目标与实际转速两个通道 |
| `T1` | 默认十通道格式，查看参数、输出和运行结果 |

**发送一次 S 后持续运行，不需要 K 续期。** 目标锁存在单片机 RAM 中，直到 STOP 或真实故障触发停机。关闭 VOFA 或拔掉电脑串口本身不会停机；实验结束发送 STOP。上电仍不会自动启动，故障恢复后也需要新的 S 命令。

参数修改保存到 RAM，下一轮控制生效；保留积分输出贡献、测量与滤波历史，重复相同参数不重置。I0 明确清除积分项。改变 P/D 本身仍可能改变输出，并不保证任意调参都无扰动。复位后恢复 `App/app_config.h` 的初值；确定最终参数后再修改该文件保存，不需要每次编译。

本阶段不再把 V/C 原始给定作为串口命令，S 后的数字明确表示 rpm。

## VOFA 设置与曲线

选择串口和 115200、8N1，数据引擎选择 FireWater。默认 T1 数据示例：

```text
speed:0.00,0.00,0,50.0000,200.0000,0.0020,0,1,1,0
```

每行末尾实际发送 CRLF。通道 0 为目标转速，通道 1 为实际转速，均为 rpm；波形只显示这两个通道，参数和状态用数值查看。波形的 **Δt 设置为 10 ms**，与固件遥测周期一致，否则横轴时间与实际时间不符。标准格式参见 [VOFA FireWater 文档](https://www.vofa.plus/docs/learning/dataengines/firewater/)。

`T1` 的通道如下；增益以四位小数显示，转速以两位显示：

| 通道 | 含义 |
| --- | --- |
| 0 | 目标转速 rpm |
| 1 | 实际转速 rpm |
| 2 | PID 输出原始给定，默认电压模式受 ±15000 限制 |
| 3 / 4 / 5 | Kp / Ki / Kd |
| 6 | 闭环使能：1 开启，0 停止 |
| 7 | 反馈在线：1 在线，0 过期 |
| 8 | 停止原因 |
| 9 | 最近命令结果：1 接受，2 格式错，4 超范围，5 未就绪，6 输入过期，7 接收故障 |

切换 T0/T1 会改变通道数量，清空 VOFA 旧数据后重新绑定；看阶跃时只显示通道 0 和 1。

停止原因：0 正常闭环、1 上电、2 STOP、3 反馈过期、5 温度超限、6 CAN 发送异常、7 串口输入故障、8 控制间隔过长。编号 4 为旧版保留，本版不会因不发 K 产生该停止原因。零给定不代表机械抱闸；断线时也无法保证零帧送到电机。

推荐建立四个 slider，分别绑定 `S%f`、`P%f`、`I%f`、`D%f` 加真实 LF。关闭循环发送；鼠标松开或数值框回车时发送即可。Kd 控件显示小数位设为 4，步进设为 0.001。详细菜单、范围及换行设置见[VOFA 调参面板](03_VOFA调参/README.md)。

## 从纯 P 开始学习调参

下列步骤会手动切回 P5/I0/D0，适合从头学习。当前已使用 P50/I200/D0.002 时，优先看[反转和 100 rpm 验证步骤](01_学习笔记/100rpm与反转响应改进.md)，避免误把教学小增益当作高速响应参数。

1. 电机固定，转动范围内无障碍。连接 VOFA，先发送 `STOP`、`T1`，确认通道 7 在线为 1。
2. 依次发送 `P5`、`I0`、`D0`，确认通道 3～5。发送一次 `S20`，或者用目标滑块设为 20。
3. 观察实际转速是否向目标靠近。若明显反向且偏差扩大，发送 STOP，先核对反馈与驱动方向。不要靠增大参数补偿方向错误。
4. 在 I=D=0 时，逐步尝试 P5、P10、P15，每次只改一个参数。响应慢可增加 P；出现持续振荡或明显超调则降低 P。达到输出限幅时，继续增大 P 也不会增加实际输出。
5. P 能稳定控制但实际长期低于目标时，再从小积分开始，例如 I0.5、I1、I2。这里的 Ki 按秒定义，数值仅为逐级尝试示例。每次观察稳定过程；超调或慢摆动加重则减小 I。
6. 速度环先争取用 PI 达到要求。若还有需要抑制的快速变化，再尝试很小的 D，例如 D0.001。转速反馈有 1 rpm 的量化，D 太大会放大抖动。
7. 保持 T1，仅显示目标和实际曲线。先发送 S0，等待零速稳定，再发送 S30，记录阶跃响应。每组实验保持相同目标和负载，改变参数后重新做阶跃。
8. 实验结束发送 STOP。记录最终 Kp、Ki、Kd、稳态转速、峰值及响应时间。

具体数值需要根据电机和负载调整；软件模拟通过不能证明电机的超调或响应时间已达标。
